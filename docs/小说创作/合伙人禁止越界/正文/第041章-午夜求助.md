# 第41章 午夜求助

“他找到我和孩子的新住址了。”

许棠说完这句话，电话里突然没了声音。

不是挂断。

林栀还能听见便利店冰柜的低鸣，以及小孩努力压住的抽泣。

“许棠，你现在不用解释他是怎么找到的。”她放慢语速，“先告诉我，储物间的门能不能从里面锁？店员知道你们在里面吗？”

“能锁。店长知道，是她让我进来的。”

“他本人现在在便利店附近吗？”

“我没看见。”

“有没有收到他说正在过来、已经看见你，或者会伤害你们的消息？”

“他发了很多。”

“先不要一条条念。最后一条有没有明确位置？”

许棠的呼吸又乱起来：“他说，别以为换到青蒲路十七号我就找不到。”

陆衍在纸上写下地址和时间，又推给林栀一行字：`是否立即报警，由当事人确认；若已迫近，优先紧急处置。`

林栀问：“青蒲路十七号是你刚离开的住处？”

“是。”

“你为什么离开？”

“楼下保安说有个男人拿着我们的照片问门牌。我从后门带小禾出来，走了两条街，才进这家店。”

“你女儿叫小禾？”

“对，七岁。”

“她现在有没有疼痛、呼吸困难、出血，或者需要医疗帮助的情况？”

“没有。她只是害怕。”

“你呢？”

许棠停了一下：“没有受伤。”

“今晚没有，还是近期也没有？”

“今晚没有。”

林栀没有追问近期伤情。

储物间不是做完整访谈的地方，孩子也在旁边。眼下第一目标是让两个人从可能暴露的位置安全转移，不是立刻获得一份叙述完美的证词。

“许棠，我建议现在联系警方，说明有人持续定位、寻找你和孩子，并已准确说出刚离开的住址。你愿意由我协助联系，还是你自己拨打？”

电话那头沉默了几秒。

“报警会不会让他更生气？”

“可能出现不同反应，我不能保证他不会生气。”林栀说，“但是否报警不该只由他的情绪决定。你现在担心人已经接近，警方可以处理现场危险、记录求助和协助安全转移。你也可以先告诉我，你最担心报警后发生什么。”

“他会说我抢走孩子，说我精神有问题。”

“这些说法可以之后分别处理。现在需要先判断你和孩子是否有迫近危险。”

“还有我婆婆。她会不停给我爸妈打电话。”

“亲属联系也可以纳入安全计划，不需要今晚全部解决。”

许棠又问：“如果警察觉得这只是家务事呢？”

“我不能替任何接警人员保证判断，但我们可以清楚说明持续定位、威胁内容、带孩子转移的原因，以及你当前的恐惧。也可以保存接警和处置记录，必要时再走其他保护路径。”

小禾在电话里很轻地问：“妈妈，我们还要回去吗？”

许棠的声音一下哑了。

“不回。”她说，“今晚不回。”

这句话像是她对孩子说的，也像第一次对自己作出决定。

“林律师，请你帮我联系。”

“好。你授权我们向警方提供你当前便利店位置、姓名、孩子同行情况，以及刚才那条定位消息吗？”

“授权。”

“是否授权我们联系店长，提醒她不要向任何询问者透露你在储物间？”

“授权。”

“转移地点由你决定。我们可以同时联系有安全接待条件的临时住所资源，也可以让警方协助去你信任的亲友处。你现在有不被对方知道地址的亲友吗？”

“没有。他认识所有人。”

“那我们先联系专业资源。地址只发给必要人员，不在这通电话里公开说。”

许棠答应。

陆衍已经拿起另一部手机，按照林栀写下的授权范围联络值班资源。他没有替许棠决定去哪，也没有因为时间紧直接把某个地址报进免提。每完成一项，只在纸上写状态：警方已联系、店长已确认、临时接待资源核验中。

林栀继续维持通话。

“现在看一下储物间里有没有第二个出口。不要开门，只问店长或者让她隔着门告诉你。”

“有后门，但通向卸货通道。”

“先不走。等现场人员确认路线，避免正好与寻找你的人碰上。”

“好。”

“手机还有多少电？”

“百分之三十一。”

“有没有充电器？”

“店长拿了一根。”

“保持充电。先不要恢复出厂设置，也不要为了找跟踪来源反复操作。安全优先，设备怎么处理等转移后再决定。”

“我已经关了定位。”

“什么时候关的？”

“离开新住处之前。手机、平板、孩子的手表都关了。”

“车辆呢？”

“没开。车还在地下车库。”

“你怎么到便利店？”

“走路。”

“有没有告诉过任何人这家店？”

“没有。我是随便进的。”

这些信息只先记录，不下结论。

共享账户可能同步位置，儿童手表可能有管理员权限，车辆或随身物品可能存在追踪设备，亲属也可能通过通话获得线索。更简单的可能是对方只知道青蒲路旧住址，并不知道便利店。

林栀没有把所有可能一口气告诉许棠。

一个已经躲在储物间的人不需要再被十种看不见的跟踪方式包围。排查由团队承担，许棠只需要知道眼下该做什么、每个选择会产生什么影响。

十二点零九分，辖区处置人员与便利店取得联系。

店长隔门确认前门暂未发现与照片相符的人，但十分钟前有陌生电话询问店内是否有一名带孩子的女性。店长没有回答。

“他连电话都打到店里了？”许棠声音发抖。

林栀没有说“一定是他”。

“目前只确认有陌生来电。请店长保存来电时间和号码，不要回拨。”

陆衍写下：`便利店电话线索，待核。`

临时接待资源很快给出回复，可以接收母女，但要求先完成身份与风险登记，具体地址仅通过现场安全人员转达。

林栀把选项告诉许棠。

“你可以去这个临时地点，那里能提供独立房间和基础安全管理；也可以请求警方协助到其他安全地点。临时点会登记姓名和紧急联系人，但不会向非授权亲属披露。你愿意去吗？”

“会不会抢走我的孩子？”

“它不是决定监护权的机构，也不会因为你求助就自动把孩子带走。具体登记内容可以先由工作人员向你说明，你不理解的地方可以问我们。”

“能住多久？”

“今晚能接收，后续期限要由你与工作人员确认。我们不会把它说成永久方案。”

许棠问小禾：“我们今晚去一个有锁、有阿姨值班的房间，好吗？”

孩子没有立即回答。

过了一会儿，她小声问：“爸爸找不到吗？”

“我们会尽量不让他知道地址。”许棠说。

“那我的书包呢？”

“以后再拿。”

“小兔子也在家。”

许棠吸了一口气：“以后也拿。”

她没有骗孩子说明早就能回去，也没有为了让孩子配合说爸爸绝对找不到。小禾最终说：“好。”

“我愿意去。”许棠告诉林栀。

十二点十九分，转移方案确认。

现场人员从卸货通道接出母女，先核对附近环境，再上没有公开标识的车辆。店长保存监控时间段和陌生来电记录，不在普通工作群转发母女照片。林栀与接待资源建立单线联系，所有人都只获取完成自己任务所必需的信息。

陆衍把车钥匙拿起来。

“去律所？”他问。

“去。”

私人台账还摊在茶几上，零比零旁边是刚写好的“长期有效”。林栀把它折起，放回抽屉。蓝色筹码留在原位。

不需要讨论是否冻结。

客户进入紧急状态，第三条公约自动生效。

陆衍把客厅边柜上的蓝色筹码收进抽屉，却没有带走。

“冻结到什么时候？”他只确认工作边界。

“至少到母女完成转移、危险等级初评和明早第一次会谈。”

“之后重新确认，不自动恢复。”

“对。”

“台账不带去律所。”

“对。”

三句话处理完私人部分。

没有谁因为刚拿到长期钥匙就需要获得今夜更多关注，也没有谁把“共同生活成员”变成必须共同出现场的理由。林栀问陆衍是否需要她独自处理初次求助，以减少知情范围；许棠已经明确授权双人协助，电子设备和跨区域资源又确实需要分工，他才一起去。

决定来自案件需要，不来自关系证明。

出门前，陆衍在白板便签上写下临时任务：林栀保持客户单线沟通；他负责现场资源与数字设备预判；周屿远程确认取证条件；沈念次日接管机构协调。每项任务都标明授权来源，没有“先做了再说”的空格。

林栀扫完：“报警联络由我统一。”

“明白。”

“任何新地址不进入普通群。”

“明白。”

“不要让周屿远程登录她的设备。”

“只提供保全建议，等本人授权和环境稳定。”

分工完成，他们才开门。

他们换衣服、拿电脑、确认值班人员。整个过程没有一句“又要一起熬夜”，也没有借深夜并肩制造任何私人暗示。陆衍只问设备固定需要谁联系，林栀只分配安全计划与法律材料。

出门前，她看到玄关两串同款钥匙。

长期有效刚生效不到半小时。

可真正的长期共同生活，不是永远有时间站在玄关讨论彼此。有时只是紧急电话响起以后，两个人都知道先拿哪一份材料、谁负责关灯，以及私人问题该在什么时候自动沉默。

十二点二十七分，他们到车里。

林栀负责继续与许棠通话，陆衍开车。电话免提只在许棠再次确认同意后打开，声音控制在车内。

母女已经上车。

小禾不再哭，仍紧紧抱着许棠的手臂。接待人员只告诉林栀预计到达时间，没有说具体路线。

“许棠，等你们到房间以后，我们先只做必要信息登记。”林栀说，“今晚不要求你完整回忆所有事情。如果身体有任何不舒服，告诉现场人员，我们安排检查。”

“我没有外伤。”

“没有外伤也可以求助。威胁、跟踪、控制和持续恐惧都需要记录。是否构成具体法律事实，要在后续材料里逐项核验。”

许棠低声说：“他没把我打进医院过。”

这句话显然被她重复过很多次。

像在替对方辩护，也像在提前说明自己可能不够资格害怕。

“严重外伤不是获得安全帮助的唯一门槛。”林栀说，“但我们也不会因为你害怕，就替你夸大任何没发生的事。发生过什么，按事实记录。”

电话那头安静了一会儿。

“好。”

十二点四十一分，母女到达临时接待点。

门锁、房间、值班联系和紧急出口逐项确认。许棠拒绝当晚联系父母，担心他们接到宋恺电话后泄露位置；她同意把林栀暂列为法律联络人，次日再决定其他紧急联系人。

丈夫的名字第一次进入记录：宋恺。

林栀请她只截取最近几条与位置、威胁和寻找有关的消息，不要删除原对话，不要为了整理而转发到多人群。完整设备固定等安全稳定后进行。

许棠把截图通过约定渠道发来。

第一条：`你带走小禾没有用，她总要上学。`

第二条：`青蒲路十七号不适合孩子，今晚回来。`

第三条：`别逼我去你爸妈家。`

语句里没有直接说“我要伤害你”。

却准确点出住址、学校和父母，把所有可能的退路都变成他能够抵达的地方。

“他总说这是关心。”许棠说，“他说我没能力照顾小禾，所以要知道我们在哪里。”

“关心不能自动替代你的选择，也不能让持续定位变得无需审查。”林栀说，“明天我们分别看行为、频率、方式和你表达拒绝后的反应。”

“今晚要关机吗？”

周屿已经被紧急叫醒，远程加入。他建议先记录设备型号、账户状态和当前时间，再由许棠自行决定是否关机；如果关机会影响求助联系，接待点提供独立电话。

许棠选择保留接待点电话，把自己的手机关机并交给自己保管，不交给陌生人操作。小禾的儿童手表也关机，装进单独封袋，袋口由许棠签名。

一点零三分，手机彻底断电。

接待点值班人员确认房门安全，母女准备休息。林栀约好早上第一次正式会谈时间，结束通话。

车刚驶入律所地库，接待点的独立电话又打了过来。

许棠声音比刚才更低。

“林律师，我手机已经关了。”

“发生什么？”

“值班人员用隔离终端帮我看了一眼原来的云端消息。宋恺又发了新的。”

手机关机只切断了设备连接，并不会让账号服务器上的新消息消失。接待点没有让许棠在普通办公电脑输入密码，而是按安全流程使用临时隔离终端；查看由她本人授权，屏幕没有同步任何新地址权限。

林栀握紧手机：“消息是什么时候发的？”

“就在我关机以后。”

“消息内容先不要转述给孩子听。你念给我。”

许棠停了两秒。

“他说，青蒲路二十四小时便利店的储物间很冷，让我别带小禾在那里过夜。”

那不是刚离开的住址。

是她们随机走进、从未告诉任何亲友的便利店。

宋恺仍然准确报出了店名、门牌号，甚至知道她们躲过储物间。
