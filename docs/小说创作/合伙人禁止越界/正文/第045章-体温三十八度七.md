# 第45章 体温三十八度七

林栀第一次打错许棠名字时，沈念就抬了头。

补充材料封面原本应写“许棠”，屏幕上却变成了“许唐”。

这不是严重错误，输入法也常把同音字放在相邻位置。林栀删掉重打，继续核对儿童手表管理员记录。

五分钟后，她把周五十五点零六分写成了周六。

沈念走到桌边：“你昨晚睡了多久？”

“两个小时。”

“前晚呢？”

“差不多。”

“现在头疼吗？”

“不影响工作。”

“这不是回答。”

林栀抬眼，才发现沈念手里已经拿着额温计。

“办公室什么时候配的？”

“从两位合伙人把连续熬夜当核心竞争力以后。”

“我没有不舒服。”

“脸红、眼睛发干，刚才打了两个平时不会出现的字。先测。”

“可能只是缺觉。”

“测完再判断。”

沈念没有直接把仪器按到她额头，而是把选择说出来：“你自己测，或者我帮你。拒绝也可以，但今天的文件会先转给唐澄复核。”

林栀看了她两秒，接过额温计。

数字跳出来：三十八度二。

她皱眉：“仪器不准。”

“可以换一支复测，也可以去附近门诊。”

“我先把申请目录——”

“唐澄已经接手。”

沈念把工作群转给她看。唐澄负责法院补充材料，周屿负责越州数据清单，沈念负责接待点和学校沟通。每一项都有负责人，没有哪一项必须由发热的林栀亲自守住。

“许棠的七十二小时节点不能等。”林栀说。

“所以更不能让错误进入材料。你现在去复测和就医，结果回来再决定是否继续。”

林栀想反驳，喉咙先涌上一阵干涩。她咳了两声，才意识到这种不适从早上就存在，只是被自己归类为睡眠不足。

身体不是可以无限延期的待办事项。

公约第三条写得清楚：健康永远优先。

起草人若自己不执行，规则就只是一张要求别人配合的纸。

“去门诊。”她说。

沈念已经预约好附近医疗机构，安排司机，没有让她自己开车。出发前，林栀向唐澄交接当前判断：后台协管账号存在，但账户归属未确认；法院补充只写服务商正在固定记录，不提前写宋恺操作。许棠学校方案由本人继续选择，不因她暂离改变授权边界。

“你可以走了。”唐澄说，“这个案子不是只能靠你一个人活。”

林栀拿起外套：“措辞不专业。”

“但有效。”

上午十点二十，门诊复测体温三十八度七。

医生询问症状、既往情况、用药和接触史，完成必要检查。现阶段不能仅凭发热确定具体原因，先按医嘱休息、补水、观察体温与其他症状；如出现医生说明的警示情况，及时复诊或寻求进一步医疗帮助。

林栀问：“下午能工作吗？”

医生看了她一眼：“休息。”

“线上看材料也不行？”

“你可以自行承担不休息带来的风险，但我的建议是休息。”

沈念在旁边把“休息”两个字记进手机，字号大得像法院裁定。

离开门诊后，她没有把林栀送回律所，直接送到栖云公馆。

“我的电脑还在办公室。”林栀说。

“故意留下的。”

“手机也能看文件。”

“我不能没收合伙人手机，但可以把所有工作通知转静音，并告诉团队非紧急不要找你。”

“七十二小时审查——”

“唐澄。”

“数据固定——”

“周屿和陆衍。”

“许棠——”

“我负责生活联络，法律决定由唐澄按既有授权处理。真正需要你本人判断的，我们会先问医生和你当时状态。”

每条退路都被堵住。

不同于宋恺替许棠安排一切，沈念的强硬建立在工作交接和医疗建议上，也保留林栀拒绝就医、拒绝陪同的权利。林栀已经选择接受，如今只是对自己不能继续掌控全部流程感到不适应。

回到家，玄关有两串同款钥匙留下的空位。

陆衍那串随他去了越州。

林栀第一次觉得屋子太安静。

过去一个人住时，安静是她主动选择的秩序。现在客房门开着，桌上有陆衍没带走的两本书，厨房第二只常用杯倒扣在沥水架上，安静便不再只是没有声音，而是某个已经进入日常的人暂时不在。

她不愿把这种感觉叫成想念。

至少不在体温三十八度七、判断可能受疲劳和不适影响的时候。

公约不仅约束陆衍不取证，也约束她不在状态不稳时强迫自己给情绪下结论。感受可以存在，命名等清醒以后。

沈念看她站在玄关不动：“头晕？”

“没有。”

“那为什么不进去？”

“在确认门锁。”

“你已经确认了三次。”

林栀终于换鞋。

她走到书房，习惯性打开电脑，屏幕还没亮就被沈念合上。

“这是你的私人设备，不在我的管理权限里。”沈念说，“所以我先问：你愿意把电脑关机，至少休息到下一次复测吗？”

“不愿意。”

“理由？”

“我需要确认紧急材料没有缺项。”

“唐澄已经发来签字确认。你可以看一条交接摘要，不打开正文。”

“让我看。”

沈念把摘要递给她：材料版本、提交状态、待办负责人、下一次更新时间，全都清楚。林栀看完，终于亲手关机。

“我不是想控制你。”沈念说。

“我知道。”

“你随时可以拒绝，但拒绝以后，团队也有权为了文件质量调整你的工作权限。”

“我也知道。”

制度保护客户，也保护一个不擅长承认自己需要休息的合伙人。林栀不喜欢失去控制，却不能因为不喜欢，就把所有协作写成对她自主权的冒犯。

林栀换鞋时看见冰箱上的三条公约，第三条就在最下方。蓝色筹码仍在抽屉，私人停战没有解除。

沈念给她倒水，按医嘱记录复测时间，并把药品和说明放在桌上：“我留到你第一次复测以后。你愿意吗？”

“愿意。”

“要不要通知姜阿姨？”

“先不要。她今天有展览布置。”

“其他照看人？”

林栀下意识想说陆衍。

他在越州，正进入服务商技术部门。这个名字在答案里出现得太快，快到她没有机会用“合伙人值班”解释。

“你先留。”她说。

“可以。”

中午十二点，体温仍在三十八度以上。

林栀按医嘱处理，喝了水，躺进主卧。她原本只想闭眼二十分钟，手机却在床头震动。

越州工作视频会议。

会议按原计划由周屿主持，她不需要参加。可屏幕亮起时，她仍伸手点开。

陆衍出现在画面里，身后是取证团队会议室。

“你为什么上线？”他第一句话不是数据结果。

“听进度。”

“镜头打开。”

“没有必要。”

“那回答三个问题。你在哪里，谁在身边，是否不舒服？”

林栀停了一秒：“栖云公馆，沈念在，轻微发热。”

屏幕另一端安静下来。

“体温。”

“不影响判断。”

“具体数字。”

“门诊三十八度七。”

陆衍的表情没有明显变化，手里的笔却停在纸上。

“是否就医？”

“已经去过。”

“医生建议？”

“休息、补水、观察，按医嘱处理。”

“是否有人继续照看？”

沈念从镜头外出声：“我在。”

陆衍点头：“谢谢。”

然后对林栀说：“退出会议。”

“你无权命令我。”

“那我问。你愿意退出会议、按医生建议休息吗？”

林栀被改口堵住。

“我只听数据固定结论。”

“结论由周屿写进工作群，唐澄使用。你现在即使听见，也不处理。”

“如果有重大判断？”

“由我、周屿和唐澄先处理；必须由你决定的，等确认你的状态允许，或者按律所应急权限走。”

“陆衍。”

“在。”

“汇报。”

他看着屏幕里的黑色头像，最后只说：“协管账号在过去三十天有位置查询记录，具体归属仍待服务商核验。材料取得路径完整，没有扩出授权范围。其余明天告诉你。”

“查询时间与便利店对应吗？”

“林栀。”

他很少连名带姓这样叫她。

不是威慑，也不是私人攻防。

只是明确提醒：她现在正把工作欲望放在身体状态之前。

“这个问题明天回答。”他说，“现在关会。”

林栀想说自己清醒。

可屏幕上的字已经开始轻微发虚，她也记不清刚才医生说下一次复测是几点。公约并不要求她等到完全失去判断才停止。

“好。”她说。

陆衍没有因为她终于听话露出胜利神色，只确认：“沈念，麻烦按医生建议观察。出现需要复诊的情况直接处理，不等我。”

“明白。”

视频退出。

私人战局继续冻结。

陆衍没有问她是不是想他，也没有把“你为什么上线”解释成她专门来看自己。即使事实可能包含这种成分，发热状态下也不适合提取。

越州会议室里，周屿继续讲数据字段。

陆衍却有短短几秒没有听见内容。

他的电脑旁放着一本私人便签。出发前，他曾写下返程后可能使用的三个问题：林栀看到空房会怎样解释；她是否已经为唱机留位置；钥匙从澜庭取走以后，哪一个地址才被她称作他的家。

每一个问题都能推进一场有效回合。

此刻却全部失去意义。

林栀发热，任何答案都不应进入台账。即使她主动说想他、要他回来、承认看见运输单以后心跳失序，也只属于需要照顾的当下，不属于可以保存的战果。

陆衍把便签翻过去。

背面重新写成四项：就医情况、照看人员、医嘱、异常复诊条件。

周屿结束一段汇报，问：“返程提前？”

“先完成交接。”

“当地律师可以接实名结果。”

“确认服务商接受替代接收人，再改。”

“你不马上走？”

“马上走会让取证链断在最后一步。”陆衍说，“她也不需要一个为了表示着急、把客户工作扔下的人。”

他很想回去。

这种想并未因克制而减少。只是关心若以破坏另一个客户的授权和数据完整为代价，便成了只服务于自己焦虑的表演。

陆衍把所有焦虑压进交接清单，逐项确认。

不是为了证明理性比感情重要。

是因为真正回去以前，先把该承担的责任留在正确的人手里。

林栀把手机交给沈念：“静音。”

“终于。”

她闭上眼。

睡眠并不安稳。走廊里有很轻的脚步声，可能是沈念去接水；窗外偶尔传来车辆经过；体温让梦和现实之间的边界变薄。林栀梦见自己还在澜庭，空书架不断延长，黑胶唱机放在尽头，运输单上的目的地却怎么都看不清。

她想走过去，腿却像被地面拖住。

“水放床头了。”沈念在现实里说。

林栀睁开眼，没有完全醒。

“陆衍呢？”

名字从她嘴里出来，没有职业前缀，也没有任何解释。

沈念停了一下：“他在越州，工作安全，按计划返程。”

“几点？”

“原计划明天下午。你要我把你的情况告诉他吗？”

林栀闭着眼，像没听见完整问题，只轻轻应了一声。

沈念没有把含混回应当成授权。她只按此前工作需要告知陆衍：林栀已就医，在家休息，有人照看；具体医疗信息不额外扩散。如需进一步情况，等林栀清醒后确认。

那句“陆衍呢”没有被录音，也没有被写进私人台账。

下午四点，体温仍未完全下降。

医生远程了解情况后继续给出观察与复诊建议。林栀醒过一次，喝水、配合记录，又睡过去。她没有再登录工作系统。

越州的固定工作在同一时间进入最后交接。

服务商导出了协管账号建立时间、权限变更、近三十日位置查询及安全区域通知触发记录。数据由取证团队按流程封存，原始载体和说明文件分别登记。协管账号绑定尾号需要通过服务商内部实名核验，预计次日上午出具初步结果。

陆衍原本订的是次日下午返程航班。

他看完沈念发来的状态更新，查了最早一班。

有一班清晨六点二十起飞，落地临川七点四十五。

他没有立刻改签。

先确认当地律师可以在次日上午代为接收实名核验结果，取证团队由谁完成原件封装，周屿如何远程复核校验值，若服务商临时要求本案律师到场由谁替代。每一项都有姓名、权限和联络方式。

晚上七点四十，交接清单由三方签字确认。

周屿远程复核全部文件，确认固定范围没有超出许棠授权，原始记录、工作副本和说明文件分别封存。当地律师书面接受次日上午的后续接收任务，服务商也确认无需陆衍本人继续在场。

直到这时，他才打开航班页面。

改签前，陆衍先给沈念发消息：`她现在需要我回去吗？请在她清醒时问，不用替她决定。`

沈念过了十分钟回复：`她在睡，无法确认。按共同居住与既有照看安排，你可以回家；不要把返程理解成她病中提出的私人要求。`

陆衍看完，没有要求叫醒林栀。

他回去是自己的选择，不需要一份发热状态下的邀请为行程负责。

随后，他把新航班、落地时间和取证交接人同时发进案件群。没有单独给林栀发送“我回来”，也没有让一条可能把她叫醒的消息承担安慰功能。

陆衍这才终于正式改签最早一班返程。
