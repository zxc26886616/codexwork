# 第19章 衡序附件

对方律师拒绝说明异议依据。

书面回复称，证券账户和车辆均已出现在申请方此前材料中，对可能追加措施作出判断属于正常代理工作，不存在获取林衍所内部信息的情形。至于“车辆权属尚未核实”，是从现有照片不具备登记证明力自然得出的结论。

这套解释成立。

至少在没有更多材料之前，团队不能因为对方判断准确就认定泄密。

“他们可以推出来。”周屿说，“匿名邮件也可以推。那我们是不是又回到零？”

“不是。”沈念把两份文件并排，“匿名邮件、正式异议和内部方案的重合点已经可以做信息路径核验。我们不必先证明是谁泄露，先查哪些内容在哪些环节可见。”

路径表被分成五层。

第一层是原始事实：车辆照片、证券转账、个人消费记录。顾念安、核心团队、法院及程序相关方依法可见。

第二层是法律方向：可能追查具体个人资产。对方可以从既有材料推测，担保和程序沟通也可能涉及。

第三层是策略顺序：证券优先、车辆暂缓。这一层只在核心组会议和方案B中明确出现。

第四层是停止条件：余额不足、权属不清或缺乏对应时自动缩减。目前没有对外提交。

第五层是工作节奏：何时等银行、何时复核、何时准备追加。它没有完整写在任何一份文件里，却散落在日程、电话和问询顺序中。

团队给每一层标出允许知悉者和客观记录。

第一层范围最大，因为基础事实已经通过顾念安授权或程序材料进入争议；第二层可能被对方从律师函、调查申请和媒体回应中合理推断；第三层只存在于核心会议，却可能通过提问顺序泄露；第四层明确写在方案B；第五层则最难追踪，因为它可能由一次“材料还没到”、一次担保预核或一次咨询问答拼出来。

“我们之前一直在找一份被拿走的文件。”沈念说，“但信息不一定以文件形式出去。”

“一句话也够。”周屿道。

“甚至不需要完整一句。”陆衍说，“只要知道我们先查什么、暂缓什么，对方就能反推出证据强弱。”

这让审查范围发生变化。技术日志仍要查，但不能只盯下载和外发。会议预约、咨询模板、担保沟通和公共区域谈话都要进入流程图。

林栀拒绝建立“可疑人员名单”。她要求每一条路径先回答三个问题：该环节是否客观接触信息，接触到第几层，有没有现成记录可以核验。只有路径出现无法解释的异常，才联系具体参与人说明。

“这样会慢。”周屿说。

“比先选一个人再搜证据慢。”

“但后者容易错。”

“也容易把团队毁掉。”

她说得平静。陆衍却知道，林栀最不能容忍的就是失控。匿名邮件精准利用了这一点：只要让她相信内部有人背叛，她就可能本能地收紧所有权限，把每个同事都放到审判席。

可她没有。

她把自己的本能也放进了限制范围。

“对方正式异议命中到第三层。”沈念说，“接近第四层，但措辞也可能是独立判断。先查第三层在哪些场景被说过。”

团队逐项回忆。

林栀和陆衍在会议室讨论过；唐澄在担保预核时只提可能追加明确资产，没有说车辆暂停；周屿曾在前台看移动端文件，但日志无外发；沈念在内部日程里使用过“方案B复核”标题，没有写内容。

顾念安是否知道？

她知道团队在追查车辆和证券，却不知道最终优先顺序。林栀与她通话时明确说，一切等待完整材料，不承诺追加措施。

“还有咨询流程。”沈念说。

周屿抬头：“跟新客户有什么关系？”

“暂时不知道。先审所有可能暴露办案节奏的流程。”

林栀同意：“私人攻防暂停，工作之外也不要在公共区域讨论本案。”

陆衍看她：“包括家里？”

“家里不属于公共区域，但方案B停止口头讨论，直到路径审查结束。”

“透明箱里的录音设备？”

“全部保持未启用。”

“接受。”

他没有借机追问昨天下午那句“因为你会先问”，也没有拿没有亮灯的谈话要求重赛。

林栀原本已经准备好防守，发现他直接停止，反而有一瞬不适应。

攻防暂停不是冷淡。他只是把职业风险放在私人游戏之前。

这使她更清楚地意识到，真正让人安心的从来不是陆衍会设计多少局，而是他知道什么时候一局都不该开。

上午，团队先审案件材料流转。

所有已提交文件都有版本和接收记录，没有发现异常下载。会议室打印机没有打印方案B，公共邮箱也没有收到内部附件。担保机构接触的只有目标资产类型和估值区间，不知道车辆暂停。技术路径暂时没有直接缺口。

接着审人员沟通，但不查看私人内容。

每个人只提交与案件有关的外部联系清单：何时、与谁、通过什么正式渠道沟通了哪些事项。无法回忆的标不确定，不要求写出与案件无关的聊天对象。

周屿问：“如果有人故意不写呢？”

“流程审查不是测谎。”林栀说，“先找客观记录能否对应。发现矛盾再给本人解释机会。”

“如果最后真是内部人？”

“那也要按事实和权限处理，不靠谁看起来最紧张。”

周屿点头。

他昨天就是最紧张的人。如果团队当时相信表情胜过日志，他现在已经很难继续参与调查。

中午，唐澄在旧材料里找到一页此前没有单独编号的附件。

它夹在程启明一方提交的公司治理资料中，位于一份三年前的组织调整方案之后。页面没有标题页、签名或盖章，只有页眉一行灰字：

“家庭风险隔离建议——股权外观、收益路径与信息分层。”

正文列出三项原则：登记外观与内部安排分别保存；家庭成员只接触必要信息；收益处理避免形成单一、持续、可直接对应的支付模式。

右下角有一个很浅的附件编号：`HX-FR-230627-04`。

六月二十七日。

与第十四章会议通知属性中出现的`FR_Control_230627_HX`一致。

“衡序附件。”周屿声音发紧。

“先叫无签名附件。”陆衍说。

页面上的确没有衡序名称。`HX`可以是任何缩写，文字也可能来自公司内部、外部顾问或多份资料拼接。公开论坛附件使用相似编号，只能形成比对方向。

团队逐句对照附件建议与已经发生的事实。

“登记外观与内部安排分别保存”，可以对应代持和赠与两套文件，也可以只是普通隐名安排的风险提示；“家庭成员只接触必要信息”，与顾念安长期不知道公司内部结构相似，却不能证明她被故意排除；“避免形成单一、持续、可直接对应的支付模式”，则与三年中不同金额、不同备注的关联转款高度接近。

周屿看着第三句：“这已经不是巧合了吧？”

“相似度提高。”唐澄说，“仍要回答谁拿到建议、是否采用、具体款项是否按它设计。否则我们只是在用后来发现的一页纸解释所有过去事实。”

附件还有两段被遮住的页脚，像是扫描时盖过客户名称。团队没有尝试用图像增强恢复遮蔽，因为对方提交的可见范围就是当前合法取得的材料。若遮蔽内容关系来源，应通过正式询问要求说明。

陆衍把编号拆成四段：`HX`、`FR`、日期、序号。

衡序公开论坛文件也使用四段式编号，`FR`常被解释为Family Risk，日期和序号位置一致。但公开样本只有两份，无法证明这是一套排他编码。其他企业服务机构也可能使用同样缩写。

“编号比对能做什么？”周屿问。

“找更多独立样本。”陆衍说，“如果以后不同案件、不同主体都出现同一结构，才能逐步排除巧合。现在只保存，不宣布。”

林栀把页面放进“来源待核附件”文件夹，与`WT-Consult`属性分开。一个是内容和编号，一个是编辑环境。两条线可能最终相交，也可能永远无关。

更重要的是，建议内容本身并非全部违法。区分登记和内部安排、限制家庭信息接触、设计收益路径，都可能服务于正常公司治理和隐私保护。只有当它被用于制造虚假外观、隐瞒依法应披露的婚内权益或规避程序时，具体行为和责任才需要判断。

“别把一页风险建议写成犯罪指南。”林栀说，“查形成时间、作者、授权和实际采用情况。”

唐澄检查常规属性。附件由扫描PDF合并，无法直接看到原始作者。页面底部有一串打印任务码，但没有对应设备信息。对方提交目录只把它归在“组织治理参考资料”，未说明来源。

“发函询问。”林栀说，“这页由谁形成，何时取得，是否提交给澄越或兄弟二人，哪些建议被采用。”

“如果对方说不知道？”

“记录不知道。”

“如果主张商业秘密？”

“可以依法提出保护方式，但不能既用治理资料解释权属，又拒绝说明资料来源。”

无签名附件第一次让`HX`编号不再只是属性角落的一串字符。它仍不足以把衡序拉进案件责任，却证明有一套关于股权外观、收益路径和信息分层的建议，曾经进入程启明一方提交的材料包。

下午，沈念开始审律所前端咨询流程。

林衍所的潜在客户可以通过官网填写基础问卷。问卷用于初步冲突检索和需求分类，不要求上传隐私材料。提交后，前台会安排十五至三十分钟初谈，再决定是否进入正式委托评估。

即使没有形成正式委托，潜在客户在咨询中提供的信息也不能被团队随意翻看或拿去服务其他案件。沈念先让唐澄做冲突与保密边界审查：只核对流程是否被异常使用、问询是否触及顾念安案策略，不把对方自述的婚姻和财产内容导入现案。

“如果这个人就是来套话的，也要保护？”周屿问。

“先不能把目的写死。”唐澄说，“而且即便存在滥用咨询，审查也要限于必要范围。不能因为怀疑对方不真诚，就把咨询系统里的所有个人信息变成我们的调查库。”

团队决定先看元数据和标准问答节点，不听完整录音。只有流程日志显示异常追问与本案内部判断高度重合，才在最小范围内核对对应片段。

这套限制让调查更慢，却避免林衍所为了证明自己被试探，先破坏自己对潜在客户承诺的边界。

常规问题包括争议类型、紧急程度、已知财产和对方身份。为了判断是否需要紧急保全，还会询问登记窗口、可能转移方式和已有证据。

“这套问题本身就能暴露我们先问什么。”沈念说。

周屿皱眉：“官网问卷是公开的。”

“字段公开，后续追问顺序不完全公开。”

前台会根据答案调用不同模板。涉及紧急股权变化时，系统提示先确认时间窗口，再问担保能力、财产线索和材料来源。一个完整走过流程的人，可以知道律所面对类似案件时会先补哪类信息。

这不是方案B内容，却是工作节奏。

“查近期相似咨询。”林栀说，“只看必要字段和流程日志，不打开与本案无关的个人陈述。”

沈念按条件筛选：最近七日、婚姻财产、股权变化、紧急申请。

系统出现两条记录。

一条是顾念安。

另一条提交于三天前，姓名和联系方式通过基础格式校验，自称配偶准备转让一家公司的少数股权。对方完整填写问卷，接受二十五分钟初谈，却在律师准备发送正式委托材料前突然表示“不考虑诉讼”。

“谁接的？”林栀问。

“前台初筛，周屿做了第二段专业问询。”

周屿愣住：“我一天接好几个咨询，记不清。”

“先不要求你回忆。”沈念调出流程日志，“记录显示，对方问了很多反向问题：你们怎么判断六小时窗口，什么情况下先查证券账户，车辆证据不完整会不会暂缓。”

最后一句出现时，会议室彻底安静。

车辆证据不完整会不会暂缓。

这正是方案B的内部停止条件之一。

“咨询录音呢？”陆衍问。

“按告知流程留存，权限正常。”

沈念没有立刻播放。潜在客户即使最终不委托，也有隐私和保密边界。团队先确认审查目的、参与人员和最小范围，只听与流程试探有关的片段，不扩散对方无关陈述。

她看着那条记录的创建时间。

三天前，匿名邮件到来之前，一名“新客户”已经完整走过林衍所的咨询问卷。

他没有拿走任何案件文件，也没有进入核心会议，却可能通过一连串看似正常的提问，听见团队面对紧急股权争议时最先做什么、最后放弃什么。

如果这条路径成立，被泄露的就不是一页方案。

而是林衍所习以为常的办案方法。

方法一旦被摸清，对方就能永远比他们的下一步早半拍。

这半拍，足以改变一场保全的结果。

甚至改变全局。
