# 第29章 调查材料落地

第一批调查材料在下午两点送达。

不是一个能让人立刻欢呼的文件夹。

电子包共三百八十七份文件，包含特定期间的会议通知、审批日志、付款凭证、权限配置和部分业务指令。另有一份遮蔽说明，列明哪些客户名称、员工隐私和无关项目被依法隐去。

团队先不看内容。

周屿核对文件数量和校验值，唐澄检查调查范围与交付目录，沈念设置只读原件和工作副本。任何批注、排序和格式转换都在副本上进行。

交付文件来自三个系统，时间格式并不统一。

会议平台使用本地时间，财务系统导出为协调世界时，审批日志则只标服务器时间。若直接按表面时间排序，同一笔付款可能出现“先批准、后申请”的假象。

周屿先建立时间换算表，保留原始时间和统一时间两列。夏令时不适用于临川，却有一份境外服务日志使用不同区域设置，也被单独标出。

“为什么不全部改成同一个格式？”他问。

“工作副本可以统一，原始值必须保留。”陆衍说，“否则以后无法判断差异来自系统还是我们转换。”

遮蔽说明也逐页核对。两处付款凭证把收款主体一并遮住，已经影响争议核验，唐澄提出补充；其他客户名称和员工联系方式与本案无关，继续保持遮蔽。

团队还发现十一份扫描件没有可检索文字。周屿原本想批量识别，林栀要求识别文本只作查找辅助，每个关键数字仍回到原图核对。

“三百八十七份材料，最容易犯的错就是相信搜索框比眼睛可靠。”她说。

前置处理持续近一个小时。

直到来源、时间、遮蔽和版本都能够追溯，团队才真正打开内容。

“三百八十七份，今天能看完吗？”周屿问。

“不需要看完所有字。”林栀说，“按四个核验问题走。”

谁发起会议。

谁拥有最终审批权限。

澄越为什么向启禾付款。

关联资金最终由谁实际使用。

“先看结构，再看异常。”陆衍说，“不要用关键词搜索替代上下文。”

第一组是董事会和管理会议流程。

十四份此前提交的会议记录里，程启明从未出席。新材料却显示，至少九次会议的议题由他的账号提前审核。行政人员在发出通知前，会把议程草案发送给`QCM`账号；其中五次，他删除或新增议题，三次修改预算上限。

正式记录仍不写他的名字。

其中一次产品预算会最能说明问题。

会议记录写程启川主持，决议将新项目预算控制在八百万元。会前议程草案原本写一千二百万元，程启明账号批注“先做一期验证，不批全额”；行政人员随后把预算改成八百万元。会后，程启川在系统中提交执行申请，最终仍由程启明账号确认。

另一次供应商更换则相反。程启川提出更换，程启明认为迁移风险过高，项目因此延后三个月。会议记录只写“经充分讨论决定暂缓”，没有出现否决者。

“他不在记录里，却能决定记录最后写什么。”周屿说。

“至少能决定事项结果。”唐澄说，“是否决定记录措辞，还没有材料。”

第三次是人事任免。程启川同意聘任一名技术总监，程启明账号以薪酬超预算为由退回；两天后候选人的薪酬方案降低，任命才通过。

三个例子分别涉及预算、供应商和高管，恰好对应权限配置中必须经QCM确认的三类事项。

这使“战略顾问偶尔建议”的说法不再完整。程启明不是随口提供意见，他在系统层面拥有能够阻止决定生效的固定权限。

“仍然不要写唯一控制。”林栀说，“日常经营大量由程启川完成。更准确的是核心事项存在持续最终确认权。”

白板上的第一条实线因此没有指向“全部公司”，只指向三类核心事项。

“顾问审核议题。”周屿说，“对方会这么解释。”

“所以看权限来源。”林栀道。

权限配置显示，程启明账号被标注为“战略顾问”，却拥有高于总经理的预算否决权限。系统说明栏写着：涉及单笔五十万元以上付款、核心供应商变更和总监级以上人事，必须经QCM确认。

设置时间早于赠与协议两年，最后一次更新就在股权转让申报前一个月。

程启川的账号可以审批日常经营，却无法绕过程启明完成三类核心事项。

“这不是一封偶然邮件。”陆衍说，“是持续权限结构。”

唐澄仍然提醒：“持续权限支持实际影响和部分控制判断，不自动等于争议股权全部属于程启明。公司治理权、收益权和登记权仍要分开。”

林栀在白板上画出第一条实线：核心审批权限。

第二组是人事和业务指令。

公开招聘邮件称程启明为董事长兼总经理，程启川为代总经理。新材料中的组织调整表解释了“代”字：程启川在程启明“外部事务集中处理期间”代行日常总经理职责，重大事项仍由程启明确认。

这份表没有签名，生成账号却属于澄越人力资源部，版本记录显示曾由程启明工作账号批注。

“外部事务是什么？”周屿问。

“没有定义。”

“持续多久？”

“表里写六个月，后来权限一直没撤。”

日常经营名义上交给弟弟，最终门槛仍掌握在哥哥手里。会议记录里的缺席不再是单纯空白，而成为一种治理安排：程启明不出现在会议桌上，却决定哪些议题可以上桌、哪些付款能够落地。

林栀画出第二条实线：经营决策接口。

第三组是澄越向启禾付款。

三笔大额咨询费均有合同和发票，形式完整。服务成果包却高度重复：每年报告沿用相同目录，修改的主要是日期、公司数据和几段建议。更关键的是付款审批链。

团队没有以“模板重复”直接否定服务。

长期顾问项目使用固定框架很常见，年度报告沿用目录也可能提高效率。真正需要核验的是，六百余万元费用对应了哪些具体工作、由谁验收，以及启禾是否具备完成数据治理和组织咨询的人员。

公开社保人数显示启禾规模很小，但公开人数并不等于实际项目能力，也可能使用外包。交付材料中确有三份会议纪要和一套供应商评估表，说明并非完全没有服务痕迹。

“服务不是零，价格就一定合理吗？”周屿问。

“不是。”陆衍说，“真实性、必要性和定价是三个问题。存在服务，不代表全部付款都能由服务解释；价格偏高，也不自动证明资金回流。”

林栀将服务成果按合同任务逐项对应。组织治理部分有两场会议，供应商协调部分有评估表，数据项目管理却只见进度摘要，没有底层交付。澄越内部审批意见里，程启明曾要求“按年度总额走，不拆细项验收”。

“谁提出年度总额？”

“QCM账号。”

“程启川是否回避关联交易审批？”

“没有。他先审，程启明终审。”

兄弟二人分别站在付款链两端，却都参与澄越内部批准。形式文件存在，独立决策过程却很薄。

团队申请补充验收底稿、启禾项目人员和外包合同。若材料能证明真实工作，咨询费应当按真实部分评价；若无法对应，超出服务的金额才可能进入回流判断。

这种拆分比把整份合同宣布虚假更慢，也更难被一张补充报告轻易推翻。

启禾提交发票后，程启川以总经理账号审核，财务负责人复核，最后由程启明账号批准。

也就是说，程启川控制的启禾向澄越收取咨询费，程启川先以澄越管理者身份审核自己的关联交易，程启明再作最终批准。

“关联交易披露呢？”林栀问。

“会议记录里没有。”

“财务系统？”

“标普通供应商。”

这不当然证明服务虚假，却使付款的独立性和定价依据需要更严格核验。

第一年三百八十万元付款后，启禾、程启川、程启明之间出现三段相邻转款；第二年也有类似路径；第三年路径发生变化，钱没有直接进入程启明已知账户，而是转向一家名为“北屿商务咨询”的主体。

林栀画出第三条线，暂时用虚线表示：关联付款与回款接口。

第四组是个人使用。

证券账户材料确认，程启明收到程启川一百九十万元后两日，转入个人证券账户一百二十万元。账户由他本人实名开立，后续投资收益也由他个人支配。

车辆权属材料则支持对方一部分解释：车辆登记在澄越名下，并非程启明个人所有。顾念安的照片只能证明他长期使用，不能把整辆车直接列为个人财产。

顾念安听到车辆结论时明显失望。

“他明明一直说那是自己的车。”

“日常口头说法与登记权属不同。”林栀说，“公司车辆长期由他使用，可以辅助说明经营地位和利益享受，不能因此把车辆价值全部列为他的婚内个人财产。”

“那我记的九十六万补款呢？”

“需要核对谁支付。现有材料显示车辆购置款主要来自澄越账户，你的家庭账本可能记录的是他当时向你描述的金额，不一定是个人付款。”

顾念安沉默了一会儿：“所以我也会记错。”

“任何人的记录都需要核验。你持续记账让我们找到方向，但不要求你当时知道每笔钱的法律性质。”

“这会不会让对方说我所有东西都不可信？”

“不会。一项解释被修正，不等于全部记录失效。相反，我们主动保留不利结果，能证明筛选不是只挑支持你的部分。”

顾念安慢慢点头。

证券账户的结果则更有力。转入一百二十万元后，程启明在同一周购买两项理财，赎回资金后来用于个人保险和另一笔投资，没有返还程启川或启禾的记录。

这仍不能证明最初一百九十万元全部属于澄越收益，却证明程启明至少以个人所有人的方式长期支配其中一部分。

一项线索被削弱，另一项被加强。

调查没有迎合客户，也没有为了维持主角正确而拒绝相反材料。

“方案B车辆停止条件触发。”陆衍说。

“暂停该方向。”林栀确认。

团队没有因为前期投入大量时间，就把公司车辆强行解释成个人资产。证券线得到加强，车辆线则按材料降级为经营支配的侧面事实。

周屿看着表格：“一边更强，一边撤掉。这才像调查。”

“本来就应该这样。”唐澄说。

下午五点，四条链第一次放到同一张图上。

顾念安的家庭日历和邮件，证明程启明在关键会议前后实际参与；公开招聘称谓，显示弟弟只是代行；系统权限，证明哥哥掌握核心否决；付款审批，则把澄越、启禾和兄弟账户连到一起；个人证券账户补上部分实际使用。

从生活细节，到岗位称谓，再到决策权限和资金路径。

证据不再依赖任何一张“致命截图”。

它们逐层互相支撑，也互相限制。

“可以庆祝了吧？”周屿问。

“可以吃饭。”林栀说。

“这不是一个意思。”

陆衍把白板上的核心权限图拍照归档：“至少证明对方‘程启明早已退出经营’的绝对说法无法维持。”

“不等于争议股权归属已经确定。”林栀看向他。

“我没说确定。”

“你的语气准备庆祝。”

“语气也受审？”

“阶段性证据增强，不是实体胜诉。保全小胜也不是全面控制。”

陆衍看了她两秒：“接受你的节奏。”

他没有把好消息夸大，也没有用新材料向顾念安承诺必赢。团队对外沟通仍然只写：部分核心权限和资金接口获得客观材料支持，需继续核验权属、服务真实性及最终用途。

“你今天很好说话。”林栀道。

“共同主办应当接受节奏校正。”

“没有私人解释？”

“攻防恢复，不代表每句话都必须进攻。”

“进步。”

“这句能计分？”

“不能。”

“那只是普通表扬。”

“你可以保留。”

两人都没有继续。

调查材料刚落地，客户结果仍未确定。真正的亲密不是把职业胜利拿来制造糖分，而是在最容易兴奋的时候，有人愿意和你一起把结论放回准确位置。

晚上七点，团队开始追第三年最大额付款。

澄越向启禾支付六百二十万元，启禾五日后向北屿商务咨询支付五百八十万元，摘要为项目协作。北屿随后替一个私人账户支付会所年费、旅行费用和多笔高端消费。

私人账户姓名在现有材料中被依法遮蔽，只显示末四位。

顾念安从未听说北屿商务咨询。

工商公开信息显示，北屿成立仅两年，注册地址是一处共享办公空间，股东与程家兄弟表面无关。

“最大额回款没有直接到程启明。”周屿说。

“先别叫回款。”陆衍道，“是启禾向第三方的项目付款，后续出现个人开支。要查合同、控制和受益人。”

林栀把北屿放进图中央。

三年资金链的最后一段，没有落在已知账户。

它流向了顾念安从未见过的咨询公司。

而这家公司，可能正是最后一层外观。

也可能是另一份真实业务。

必须继续核验。

到底。
