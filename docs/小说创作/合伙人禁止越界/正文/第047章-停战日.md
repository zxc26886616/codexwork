# 第47章 停战日

“别走。”

林栀说完，手指便失了力。

陆衍没有抽走袖口，也没有握住她的手。

“我不走。”他说，“留在这张椅子上，可以吗？”

她没有回答。

几秒后，呼吸重新变得均匀。

没有明确回答，就不把沉默当成新的同意。陆衍只维持原来的位置，没有把椅子往前移，也没有借她抓住袖口改变距离。那一小截布料仍留在她指间，直到她睡熟以后自然松开。

他才慢慢坐回去。

“别走”没有进入台账。

也没有被写在体温记录旁边。

上午十点半，林栀醒来一次。

陆衍仍在椅子上，电脑和手机都在门外。独立电话只亮着医生回访提醒，房间里没有任何录音设备。

“你一直坐着？”她问。

“中途换过姿势。”

“我是不是说了什么？”

“你让照看人留下。”

“原话。”

“等状态稳定后，由沈念在场说明。”

“你不是已经听见？”

“听见不等于现在适合复盘。”

林栀皱了皱眉，没力气继续争。陆衍先问她是否愿意测体温，再按医生建议记录。数字比早晨又低一些，却仍不作为恢复正常工作的凭证。

“粥还是面包？”他问。

“你昨天是不是也问过？”

“今天重新选择。”

“面包。”

“需要加热吗？”

“要。”

他出去准备早餐。

林栀看着门外密封的录音盒，第一次没有因为设备存在而产生防备。封条完好，盒子与私人手机都放在她一眼能看见的位置。陆衍若真想保存病中言语，根本不需要把所有可能性主动排除到这个程度。

她心里却生出另一种不安。

不是怕他取证。

是怕他真的什么都不取。

如果她昨晚说过比“留下”更直白的话，如果那些话完全不被追问、不被记分，是否意味着陆衍根本不在意？

这个念头刚出现，林栀就意识到它不讲道理。

她曾要求病中不计分，如今对方严格执行，她却本能地把尊重解释成撤退。仿佛只有陆衍抓住机会追问，才能证明他仍然想赢。

可克制不是欲望消失。

真正难的恰恰是很想要，仍不拿。

陆衍端着早餐回来，发现她一直看门外：“担心封条？”

“不担心。”

“那在想什么？”

“私人问题，停战期不回答。”

“接受。”

他连试探都没有。

林栀心里那点不讲道理的不满又增加了一点。

“你就不能问第二次？”

“你刚明确不回答。”

“可以确认是不想回答，还是暂缓回答。”

陆衍看着她：“你希望我继续问？”

反击来得很快。

林栀把面包拿过来：“我希望早餐不要凉。”

“收到。”

他没有宣布得分，甚至没有笑。只是递杯子时，耳尖出现一点很淡的红。

原来没有撤退。

只是所有进攻都被他压在健康优先之后。

中午，医生再次回访。

林栀体温趋于稳定，症状没有加重。医生结合实际情况，确认此前可能影响清醒程度的用药已经不需要继续，仍建议休息、补水和观察；是否恢复工作应根据精神与身体状态，不以一次体温数字作为唯一标准。

“下午能看文件吗？”林栀问。

“短时间处理必要信息可以，但不建议立刻恢复高强度工作。”

“多久算短时间？”

医生给出原则，让她避免连续用脑和长时间屏幕工作，出现不适立即停止。

回访结束后，陆衍把唐澄发来的案件摘要打印成一页。

“只看摘要。”他说，“二十分钟后停止。”

“医生没有给二十分钟这个数字。”

“这是团队工作控制，不是医疗结论。你可以提出其他方案。”

“半小时。”

“二十五分钟，中间喝水。”

“成交。”

林栀坐到客厅，不进书房。

摘要只有四项：法院进入七十二小时补充审查；许棠母女安全地址未暴露；儿童手表数据初步固定；协管账号实名核验待回函。唐澄已补交拒绝联系记录、伤情照片来源说明和孩子现实反应观察，不需要林栀立即作出新决定。

“宋恺有没有新联系？”

“通过许棠母亲转过一句‘孩子不能一直不上学’，未提新地址。团队已经询问许棠是否愿意保存和回应，她选择只保存，不回复。”

“亲属间接接触要进补充材料。”

“唐澄已处理。”

“学校方案？”

“小禾暂时线上联系班主任，不公开背景。是否回校由许棠等保护措施结果后再决定。”

每一项都有人完成。

二十五分钟到，陆衍把纸抽走。

林栀没有争。

“我再休息半天。”她说。

这是她主动提出，不是被沈念强制，也不是陆衍替她决定。

“好。”

“沈念什么时候来？”

“她说病中内容由她在场说明。你现在要听？”

“我体温稳定，医生确认不再受那种药物影响。要。”

陆衍没有自己复述，先给沈念发消息。十分钟后，三人通过视频连接。

沈念按时间说明，没有评价。

林栀第一次半醒时问“陆衍呢”，又问他几点回来；第二次在陆衍已经回家后，抓住袖口说“别走”。前一句发生在体温仍高、睡眠断续时，后一句发生在用药与困倦影响尚未排除时。两次均未录音，没有进入工作记录和私人台账。

“我有没有说别的？”林栀问。

“与案件无关的只有这些。”沈念说，“我没有向陆衍转述你的语气，也没有把含混应声当成允许披露更多医疗信息。”

“他什么时候知道第一句？”

“返程前。我提醒不构成授权、不计分。”

“他的反应？”

沈念看了一眼屏幕另一侧的陆衍：“这已经是评价性内容。你要我回答观察到的动作，还是由本人在有效回合里回答？”

“观察动作。”

“手指停了一下，随后继续核对体温记录。”

林栀耳尖轻轻发热。

动作不说明爱，也不说明得意。却足以证明陆衍并非毫无反应，只是没有把反应变成追问。

“说明完成。”沈念说，“如果你认为我披露超出范围，可以现在指出。”

“没有。”

“那我退出。你们今天都不许回律所。”

“陆衍没有发热。”

“他连续夜航，睡眠不足。健康优先双方适用。”

陆衍答：“接受。”

林栀只好也说：“接受。”

视频结束。

“现在满意？”陆衍问。

“我只是恢复事实控制。”

“事实已经完整。”

“私人解释仍冻结。”

“对。”

陆衍把体温记录放回原处，没有问她是否记得拉住袖口时的感觉，也没有借沈念的中立叙述逼她承认那不是梦。

“晚上如果体温稳定、医生建议不变，停战条件是否解除？”

陆衍看了她一眼：“健康优先不是按时钟自动到期。”

“我问的是重启标准。”

“睡眠足够，体温稳定，不再受药物影响，你本人明确确认清醒和愿意。仍有明显疲劳就延后。”

“由谁判断明显疲劳？”

“先由你陈述。若客观状态明显矛盾，另一方可以拒绝开始。”

“也就是说，即使我想开局，你可以拒绝。”

“任何一方都可以。”

林栀点头。

她没有现在要求开始。

下午两点，她回主卧继续睡。陆衍去了客厅，不再坐床尾。门按她的选择留出一条缝，独立电话仍在床头。两个人不需要用整天处在同一个房间证明照顾。

四点，体温维持稳定。

林栀醒来洗了澡，换掉睡了一天的衣服。站在镜子前时，她脸色仍不如平常，思路却已经清楚。昨晚和上午的片段逐渐接回：她抓住陆衍袖口，让他别走；他没有趁机靠近，只问能不能留在原位。

记忆回来以后，她第一反应不是羞耻。

而是去看台账。

私人台账在客厅抽屉。

她打开时，零比零仍停在原处。

没有“病中挽留一分”。

没有旁注，也没有用铅笔写下待清醒确认。

甚至连日期都没有增加。

林栀翻到背面，那里写着禁止事项：客户危机、发热、用药、极度困倦不计分。陆衍只在“发热”旁边打了一个小勾，表示规则已经被实际执行。

她盯着那个勾看了很久。

他最容易得分的时候没有取分。

不是因为“别走”不够明确，也不是因为他没听见，而是他把她的状态放在自己的胜负前面。尊重没有让他离开这场赌局，只让他拒绝从一场无效回合里拿走答案。

林栀终于理解那句话：尊重不等于撤退。

她过去常把克制理解成一种高级战术。

陆衍不立刻追问，是为了让下一次问题更难回避；不给答案，是为了保留更多解释空间；不靠近，是为了让她主动缩短距离。这样的理解让她始终安全，因为只要所有善意都是战术，她就可以用更好的战术回应，不必承认自己被触动。

可这一次不同。

病中证言若被放弃，未必能在清醒后重新出现。她完全可以醒来后否认，陆衍也不能证明。他承担了永久失去这一分的风险，没有换取任何后续优先权。

这种克制无法只用“为了赢得更漂亮”解释。

它的核心不是收益。

是即使得不到，也不能拿错。

林栀指腹轻轻压在“发热”旁边的小勾上。

她忽然想给陆衍加一分。

不是因为他逼出她的私人意图，而是因为他没有逼。

笔拿起来以后，她又放下。

尊重若被奖励成分数，也会变成下一次可以计算的战术。陆衍不利用她，不是为了让她感动后补偿一分；她也不能用得分把这件事重新塞回胜负体系。

于是台账仍是零比零。

什么都没有增加。

两人之间却有一件比数字更重的事实生效：当她最不能防守时，他不会进攻。

陆衍仍然想赢。

所以才要一个她清醒以后仍愿意说的版本。

“看完了？”他从厨房出来。

林栀合上台账：“为什么只打勾？”

“规则测试通过。”

“病中说的话全部作废？”

“不叫作废。它可能是真实感受，但不能用于计分或要求确认。”

“如果我清醒后撤回？”

“按撤回处理。”

“你不会追问？”

“除非你主动重启。”

“如果我不撤回？”

陆衍目光微深：“那也需要你在有效状态下重新表达。”

“要求很高。”

“总赌注值得。”

这次，他没有隐藏进攻意图。

“那你为什么把设备全搬到门外？”林栀问。

“确保不是只有我知道没录。”

“可以只拿出一支。”

“你知道总共有七支，剩余设备继续在房间内会让排除不完整。”

“手机和手表也放出去？”

“同理。”

“你连工作都没处理。”

“已经交接。”

“如果案件突然紧急？”

“独立电话可以联系，唐澄与周屿会先处理。”

每一步都不是临场表态，而是事先把他可能利用的工具、借口和职责全部移出房间。

林栀看着他：“准备得这么完整，说明你预判过我会说什么。”

“没有。”

“一句都没猜？”

“猜过，但不允许任何猜测影响照看。”

“猜的是什么？”

“停战期。”

“你很喜欢这三个字。”

“因为它现在保护双方。”

“等重启以后呢？”

陆衍目光落在她脸上，停了片刻：“重启以后，我不会撤退。”

语气平静。

威胁意味却很明确。

林栀心跳又快了一下。

她终于确定，尊重与进攻从来不是两个相反方向。陆衍停得越干净，清醒后的每一步便越无法被她用“乘虚而入”驳回。

他把无效证言全部放弃，等她自己把有效版本送上桌。

林栀的心跳轻轻快了一拍。

“你在等我重新说？”

“停战期不回答私人问题。”

轮到他用规则挡回来。

林栀笑了：“很会学。”

“起草人教学质量好。”

她没有继续。

五点半，林栀正常吃完晚饭，喝水，完成体温记录。医生确认继续休息观察即可，不再有药物影响判断的问题。她仍能感觉到身体尚未完全恢复，于是没有要求立刻开局。

“再休息半小时。”她说。

“可以。”

“七点重新评估。”

“双方重新确认。”

“对。”

陆衍去书房处理许棠案更新。

林栀回主卧，把床头小桌清空。水杯、温度计和药品记录分别归位，门外的录音设备密封盒仍没有拆。

六点五十八分，她检查自己的状态。

体温稳定，头脑清楚，没有继续使用影响判断的药物，能够完整复述案件节点和刚才的对话，也能明确说出自己为什么想重启。

不是为了补偿病中一句“别走”。

不是因为陆衍照顾了她，所以欠他一个回合。

是她清醒以后仍然想知道，他会怎样处理那句被主动放弃的证言。

七点整，林栀拉开抽屉。

她取出蓝色筹码，走回卧室。

客厅原本是他们约定的普通回合场地，空间开阔，退出路径也最明确。林栀却选择床边桌，不是要复刻病中的靠近，而是要在同一个曾经失效的情境里重新作出有效选择。

门仍保持打开。

椅子停在原来的距离，密封盒在走廊，任何人都可以先拒绝。她把水杯放在自己一侧，确认没有不适，又给陆衍发了一条消息：`状态已复核。愿意重新确认是否开始。`

这不是偿还。

也不是允许他追溯使用“别走”。

只是她清醒地把决定权拿回来以后，仍然选择把同一个人叫进来。

然后把它放在床边桌正中。

真正的红灯此刻还没有亮起。
