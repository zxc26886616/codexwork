# 第8章 丢失的回流链

上午九点十七分，对方把《股权及收益赠与确认协议》全文发了过来。

扫描件共六页，签署日是三年前四月二十六日。赠与人程启明，受赠人程启川。协议称，澄越科技早期创业资金主要由程启川提供，程启明只是基于兄弟信任代为持有部分权益；为“恢复真实财产秩序”，程启明自愿将相关股权、分红及其他收益无偿赠与程启川。

最后一页有两个人的签名、手印，还有一名见证人的名字。

周屿盯着屏幕：“这不是自己把代持写出来了吗？”

“注意主语。”陆衍说。

“他们说程启明替程启川代持。”

“所以在他们的版本里，股权从来就不属于程启明，赠与只是纠正登记。两个说法放在同一份协议里，法律关系并不干净，但对他们很有用。”

林栀把协议打印出来，先在“代为持有”和“无偿赠与”下面各划一道线。

如果程启明只是名义持有人，理论上需要说明原始出资、委托持股、实际控制和收益归属；如果股权原本属于程启明，再由他赠与弟弟，则又要回答处分标的、赠与时间以及婚姻关系存续期间的权益影响。

对方没有选择其中一条，而是把两条都写进协议。像一扇同时装了两把锁的门，推不开时可以说上锁，锁被拆掉时又可以说门本来就不属于你。

“先查形式。”林栀说。

唐澄核对签名页，沈念联系顾念安确认是否见过这份文件，周屿查见证人与相关公司的公开关系。陆衍把协议中的每一个事实陈述拆开，放进待验证栏。

十分钟后，顾念安回电。

“我没见过。”她说，“程启明以前从来没说替他弟弟持股。他跟我说过，程启川没有做生意的能力，只适合拿固定工资。”

“这句话有文字记录吗？”

“可能有。我记得他在家庭群里说过，但要往前翻。”

“先别急着找评价。”林栀说，“你想想协议签署那天前后发生过什么。有没有出差、住院、家庭聚会，或者你能确定他人在什么地方的记录？”

顾念安沉默片刻：“四月二十六日……那天是我爸做手术。他应该在医院。”

周屿的眼睛立刻亮了。

林栀没有跟着兴奋：“应该，还是确定？”

“我确定他上午来过，但不知道待到几点。”

“把你合法持有的就医材料、当天照片和聊天记录保留。不要去医院私下找人调监控，也不要联系医生替你证明签约不可能。”

“可如果能证明他在医院——”

“临川市区从医院到协议写的签约地点，开车四十分钟。人在医院不等于当天不能签字。我们只固定事实，不制造不在场证明。”

顾念安深吸一口气：“好。”

电话挂断，周屿把刚准备写的“签约日行踪冲突”改成“签约日行踪待核”。

“跟你们工作，最容易戒掉感叹号。”他说。

“职业健康收益。”陆衍答。

见证人的公开信息很快查到。邱志成，三年前任启禾管理咨询财务顾问，现在已经离职。工商公开信息里没有他的联系方式，也没有证据显示他参与澄越经营。

协议本身不是公证文书，扫描件的形成时间也无从判断。对方律师只说原件会在后续程序中出示，并未说明为何签署三年后才第一次被提及。

这些都可以质疑，却不能仅凭可疑就宣布虚假。

真正锋利的仍是日期。

唐澄把协议翻到第二页：“还有收益范围。这里写‘自始归受赠人所有’，后面又约定‘协议生效后由赠与人协助交付’。如果自始属于程启川，就不存在程启明在协议生效后再交付的问题。”

“起草人给两个故事都留了出口。”林栀说。

“也给我们留了问题。”陆衍将两段话截进审查表，“要求说明究竟是隐名持股关系，还是对程启明自有权益的赠与。基础关系不同，需要核验的出资和收益事实也不同。”

周屿问：“能不能主张他们自相矛盾，所以协议无效？”

“不能把措辞矛盾直接等同无效。”林栀说，“而且即便协议在兄弟之间成立，也不当然回答顾念安对婚内投入、收益或者相应价值有没有权利。我们要防止对方把所有争议压成‘这张纸真不真’。”

她在白板中央写下三个并列问题。

第一，谁实际投入澄越的初始及增资资金。

第二，谁持续行使股东权利、承担经营风险并取得收益。

第三，即使程启川享有某种真实权益，程启明及婚姻共同财产为公司形成所作投入应如何核算。

“这三个问题不能互相替代。”她说，“对方证明弟弟出过钱，不等于丈夫没有出钱；证明协议真实，不等于所有历史收益都按协议履行；证明登记要调整，也不等于可以在离婚财产尚未厘清时按一元价格完成处分。”

唐澄点头：“保全申请继续围绕紧迫性和可控制范围，不提前把实体争议写死。”

陆衍把三项问题转成材料目录。原始验资与增资凭证、历年股东会及董事会文件、分红决议、公司向股东或关联方付款的会计凭证、程启川和启禾向程启明回款的银行流水，每一类后面都标注取得途径。

顾念安能够合法提供的，列为当事人材料；公开登记和公告，列为公开信息；需要银行、公司或登记机关配合的，列为调查申请。没有一项写着“想办法拿到”。

周屿看着那张表：“缺的刚好都是最关键的。”

“所以叫丢失的回流链。”林栀说，“我们现在只有入口附近的脚印和出口处的一张照片。中间谁开门、钱怎么走，不能靠想象补。”

“那补正期限为什么只给到明天？”

“因为紧急程序只判断现阶段是否有采取措施的必要与条件，不等我们把实体案全部查完。”陆衍说，“我们要做的是把已知、未知和申请调查的理由分清。材料少不可怕，拿推测冒充材料才可怕。”

周屿望着他：“你和林主任今天说的话可以合订成《如何让年轻律师失去侥幸》。”

林栀在白板上补了一行：“副标题：同时保住客户。”

这一次，唐澄也笑了。

三月十二日，程启川向程启明转账三百六十万元，备注“分红”；四月二十六日，兄弟二人才签署协议，声称股权与收益此前就属于程启川。

“如果三百六十万是程启川自己的分红，他为什么把钱付给程启明？”周屿问。

“对方可能解释为代持期间的结算。”唐澄说。

“那协议为什么晚四十五天？”

“补充确认、统一手续、税务安排，都可以解释。”

“也就是说，我们抓到矛盾，但矛盾不能自动赢。”

“欢迎进入诉讼。”

唐澄语气平静，周屿却觉得自己被这五个字收取了一笔无形学费。

十一点，团队完成第一份协议审查意见。

林栀在结论页只写三点：第一，协议同时使用代持恢复与赠与处分两套法律叙事，需要对方明确基础关系；第二，协议签署前已存在程启川向程启明支付并备注“分红”的转款，收益归属说法存在时间冲突；第三，现有材料仍不足以证明三百六十万元的真实性质，应申请调查付款账户来源、澄越分配记录及相应会计凭证。

她没有写协议伪造，也没有写恶意转移。

陆衍看完，在最后加了一句：“不因协议外观直接否定顾念安对婚内出资、收益及对应价值的审查请求。”

“这句留下。”林栀说。

“主任批准？”

“合伙人正常协作。”

“我以为昨晚已经升级为同声传译。”

周屿在对面抬头：“那是我说的。”

陆衍淡淡看他：“你的著作权主张需要举证。”

“我撤回。”

办公室里的紧绷松了一瞬。

中午十二点，顾念安补发来一批家庭群记录。其中果然有程启明评价弟弟的聊天，但内容只是家庭争吵中的气话，证明力有限。更有价值的是一张三年前四月二十六日上午的医院照片，程启明站在病房门外，手里拿着顾父的检查袋。

照片原始信息显示拍摄于上午十点零九分。协议首页却写着签约地点为城西启禾办公室，没有具体时间。

两处地点相距二十八公里。

“能赶过去。”林栀说。

“也能先签后去医院。”陆衍说。

两人再一次把可能出现的戏剧性证据降回普通事实。

周屿已经习惯了。他给照片贴上“辅助核验签署过程”的标签，没有再期待一张照片把六页协议当场击碎。

下午一点四十分，法院工作人员电话询问申请材料中的财产线索是否能够进一步明确。紧急申请已经进入审查，但目前争议股权登记状态、婚内资金去向和担保范围仍有空缺。

林栀说明团队正在补充，并再次确认所有材料通过正式渠道提交。

电话结束后，她看向墙上的时间线。

现在他们有三次会议后的关联转款，有一笔写着“分红”，有一份晚于首次转款四十五天的赠与协议，还有程启明在签约日上午出现在医院的照片。

线索越来越多，证据链却仍缺中间最重要的一截：澄越究竟向谁形成分配义务，款项从公司到程启川或启禾后，又基于什么原因流向程启明。

这段链条不能靠私人截屏补齐，只能等银行流水、财务账簿、会议记录和税务资料进入合法调查范围。

“今天晚上不能都留。”沈念说，“你们已经连续工作超过二十四小时。林栀和陆衍回去睡四小时，唐澄接第一班。拒绝也没用，我已经把轮值表发进群了。”

林栀想反对，屏幕上的字却在她视野里短暂重影。

陆衍先合上电脑：“执行。”

“你什么时候这么听运营总监的话？”

“她的决定目前比你的视力可靠。”

林栀看他一眼。陆衍神色镇定，眼底也有明显倦色。他不是想把她赶回家，而是承认自己同样需要离开。

“四小时。”她说。

“四小时。”

回公馆的路上，两人没有谈案件。陆衍开车，林栀坐在副驾驶闭目养神。车里没有音乐，导航也被关掉，仿佛整座城市终于从证据材料里退回普通下午。

进门后，林栀第一眼就看见厨房杯架。

白、灰、白，三只杯子还挤在那里。

早上离开得急，她甚至忘了这件事。如今它们在日光里比清晨更显眼，像一份没人签字却已经开始履行的共同生活附件。

陆衍径直走进厨房，准确拉开第二层抽屉，拿出茶包。

“你怎么知道在那儿？”林栀问。

“昨晚找纸巾时看见的。”

“昨晚？”

“你在书房给顾念安打电话。”

“垃圾袋呢？”

“水槽下方右侧。”

“备用电池？”

“电视柜第二格，透明收纳盒。”

“创可贴？”

“玄关抽屉最里面。”

陆衍每答一个，林栀的眉梢就抬高一点。

她忽然意识到，这个人只用了不到两天，已经掌握了她家多数应急物品的位置。更可疑的是，他回答得毫无停顿，仿佛不是昨晚偶然看见，而是早就在脑内给这套房子做过一份风险地图。

“你对家里的东西记得这么清楚。”她说。

陆衍把茶包放进灰杯：“我只记与风险有关的。”

“杯子有什么风险？”

“拿错。”

“百叶帘呢？”

“影响屏幕阅读。”

“纸巾？”

“基础物资。”

他回答得严密，几乎没有缝隙。林栀却从“家里”两个字里捕捉到了另一个事实——她刚才说的是家里，不是我家。

陆衍显然也听见了，但他没有抓住用来得分。

这比追问更像追问。

林栀转身走向玄关，从抽屉最里面取出一个小木盒。陆衍说对了位置。木盒打开，里面躺着一把银色备用钥匙，钥匙环上没有任何标记。

她将钥匙拿到餐桌边，放在陆衍面前。

金属碰到桌面，发出一声轻响。

“这个呢？”她问。

陆衍的视线落在钥匙上。

“这算风险吗？”

他端着灰杯的手停在半空。

停顿不长，也许只有一秒。但对一个能在对方律师突然提交赠与协议时立刻拆出两套法律关系的人来说，一秒已经足够构成异常反应。

林栀看着他，耐心等答案。

陆衍把杯子放下，没有碰钥匙：“取决于授权范围。”

“你可以申请。”

“申请期限？”

“你先说用途。”

“夜间案件值班、紧急物资取用、共同地址风险处置。”

“没有私人用途？”

“私人用途需要另行确认。”

答得滴水不漏。

但他刚才停过。

林栀本可以记一分。她已经让陆衍在完全清醒、没有案件危机的时刻承认钥匙需要私人授权。可她忽然不想把这个停顿变成比分。

钥匙不是一句可以撤回的玩笑。把它递出去，意味着他无需再由她开门；意味着这套房子的边界里，会出现第二个被长期承认的进入者。

她可以设局，却不能假装这个后果只是游戏。

林栀伸手，将钥匙往自己这边收回半寸。

“申请材料不完整。”她说。

陆衍眼底那点极淡的紧绷也随之松开：“等待补正。”

“你似乎并不着急。”

“紧急申请不等于降低审查标准。”

他把早上他们说过的话原样还给她。

林栀想笑，又觉得笑出来会让钥匙显得更像某种默认。她拿起它，准备放回木盒，手机却在这时震动。

律所公共邮箱转发提醒，标题只有一行：补充材料通知。

她点开附件。

法院要求申请方进一步明确拟保全财产范围，补充婚内资金流向、争议股权价值基础和担保材料。最迟提交时间：次日上午十点。

睡眠计划当场失效。

陆衍已经拿起外套：“回所里。”

林栀把银色钥匙攥进掌心。

金属边缘在掌纹里留下清晰的压痕。她看了一眼空下来的桌面，最终没有把钥匙递给他，也没有放回玄关。

她将它塞进文件袋侧层，与法院的补充材料通知放在一起。

授权暂缓。

补正先到。
