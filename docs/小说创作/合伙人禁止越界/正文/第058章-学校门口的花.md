# 第58章 学校门口的花

林栀没有去碰桌上的蓝筹码。

她只是按灭了录音设备的红灯，把手机屏幕转向陆衍。

私人回合不是结束，是自动停战。

他们制定规则时没有专门写过这一条。可在许棠的电话打断第一次回合以后，这条规则已经被执行过太多次：客户出现现实危险，所有没有说完的话原地封存，不追问，不借题发挥，也不把未得到的答案算成任何一方的逃避。

陆衍看了一眼熄灭的红灯，起身拿外套：“我先下去。你在这里联系周屿，确认接收流程。”

“一起。”

“访客身份还没核完。”

“所以一起。安全接待区有物业和监控，不上楼，不单独接触。”林栀已经打开律所的证物固定表，“你负责看东西，我负责问人。”

陆衍没有坚持。他把玄关柜上的一次性手套、口罩和两个证物封签装进文件袋，又取走了她随手放在餐桌边的保温杯。

“拿这个干什么？”

“你晚饭只喝了半碗汤。”

“现在是证据时间。”

“证据时间也不禁止喝水。”

他说得平静，手上却已经把杯盖旋紧。林栀望见餐桌中央那枚没有被拿起的蓝筹码，心里那根方才绷到发热的线被迫撤回原位。

不是消失，只是收束。

她关上门前，陆衍把室内监控切到离家模式。两把长期钥匙同时在玄关感应区亮了一下，一前一后，像两项已经公开却仍未命名的事实。

电梯下降时，两个人都没有提刚才的问题。

林栀给周屿打电话，开免提：“第二束同类花，已经进入物业安全区。学校老师亲自送来，暂未开箱。”

周屿那边响起键盘声：“先别把‘同类’写成‘同源’。拍整体、封口、卡片位置，问清谁发现、什么时候发现、谁碰过。原包装如果还在，单独封。物业导出进门到交接的监控，老师陈述只记她亲见的部分。”

“明白。”

“还有，别让老师把手机里的照片直接发群。原图保留，传输路径另记。”

陆衍问：“你能在线见证封存？”

“能。五分钟后进加密会议。”周屿停了停，“你们不是刚准备处理私人危机吗？”

林栀面无表情地挂断电话。

陆衍看着跳回桌面的手机：“私人危机？”

“周屿明天的绩效危机。”

电梯门正好打开。

安全接待区被玻璃隔在大堂一侧，物业管家守在门外，班主任坐在最靠门的位置，透明箱放在另一张空椅上。她没有再抱着它，双手却仍保持着刚才用力托举后的僵硬姿势。

林栀先核对姓名、工作证和学校预留号码。陆衍与物业确认登记记录，要求保全从老师进入大堂到此刻的全部公共区域监控。

身份核验完成，他们才进入房间。

“不用道歉。”林栀在老师开口前说，“您按流程送到这里，是正确的。现在请只讲您亲眼看见和亲手做过的事，不需要推测是谁送的。”

老师点头，呼吸仍有些急：“下午五点二十左右，保洁在学校侧门里面的花坛边发现的。那时候学生都走了。她来叫我，我拍了照片，没有拆卡片，也没碰花。后来保安拿来透明箱，他戴了手套，把整束花连包装放进去。我联系沈老师，她把这个地址和转交规则发给我。”

沈老师是沈念。她发的不是住址，而是物业安全接待点编号，访客端看不到楼栋和房号。

林栀问：“花是在校内还是校外？”

“侧门铁栏里面，靠近花坛。那个门下午四点以后就锁了，但栏杆不高，花可以从外面放进来。”

“您看见放花的人了吗？”

“没有。”

“保洁看见了吗？”

“她也没有。”

“卡片上的字，谁先看见？”

“我。卡片压在包装带下面，正面朝外，没有封住。”

陆衍已经架好手机，接入周屿的加密视频。他没有打开箱子，只隔着透明表面拍摄六个方向，逐一记录花束包装、绑带、卡片位置、箱体封口和经手人。

“当前能确认的事实有四项。”他对镜头陈述，“第二束白色洋桔梗在临时学校侧门内被发现；发现时间约十七点二十分；卡片内容涉及小禾原接送时间；现场无人目击投放者。花束品种、包装外观与前一束近似，但是否来自同一购买人、同一花店或同一投放者，尚未确认。”

班主任听到最后一句，像终于知道自己该怕什么、不该替什么下结论，肩膀慢慢放松一点。

林栀把纸巾推给她：“第一束的订单付款人是孩子祖母，这一点已经核实。但第二束没有订单信息，不能因为外观相同就认定仍是祖母，也不能据此认定是宋恺。我们会查来源，学校现在要做的是把明天的接送风险降下来。”

“那孩子明天还来吗？”

“这要由许棠在得到完整信息后决定。”

班主任迟疑：“学校是不是应该直接停课？或者我们替她把孩子藏到别的班？”

“不要替她决定，也不要临时创造只有少数人知道的新安排。”林栀语气温和，却没有留下模糊空间，“越临时、越依赖口头传递，越容易出现新的泄露点。我们先把选择和对应风险列清楚，再让许棠选。”

陆衍抬眼看了她一下，没有插话。

他负责让证据不丢，她负责让当事人的决定不被恐惧夺走。这不是临时分工，而是他们合作久了以后形成的本能。陆衍看见风险，会本能地把所有出口关上；林栀看见被围困的人，会先确认哪一扇门仍由她自己选择。

过去她总担心他的保护会越过边界。

现在她更清楚，真正让她放心的不是他没有那种冲动，而是他会在行动前停下来，把决定权递回当事人手里。

证物封签完成后，陆衍在交接表上签字，把笔递给老师。全程没有碰花，也没有越过林栀询问许棠的权限。

回到楼上，他们没有恢复私人回合。

蓝筹码仍留在餐桌中央，旁边多了三台同时亮着的电脑。陆衍把录音设备收进防火柜，连同那句没得到答案的问题一起锁住。林栀把冷掉的汤倒回锅里加热，等许棠接入视频。

水汽升起来，遮住厨房玻璃上的两道人影。

“你先吃两口。”陆衍说。

“许棠上线还有三分钟。”

“足够。”

林栀端着碗坐下。他没有像平时那样坐到对面，而是把电脑放在斜侧，既能共同看屏幕，又不挡她拿筷子的手。桌上的私人物件和案件材料被严格分开：蓝筹码靠窗，证物表靠门，两只杯子留在中间。

她忽然发现，共同生活最麻烦的地方不是留下多少痕迹。

而是一个人太熟悉另一个人的运行方式。他知道她在高压时会忘记吃饭，知道她不喜欢被命令，于是只给出“三分钟足够”这种无法反驳的事实；她也知道他越沉默，脑子里越可能已经排出最强硬的处置顺序，所以会在通话前把权限边界先放到桌面上。

“等会儿只给选项。”她说，“不替许棠选。”

陆衍把学校平面图缩小：“我列执行后果，不给倾向性排序。”

“如果她坚持正常到校？”

“执行正常到校方案。”

“如果她想停一天？”

“保留学籍和学习资料，不向无关人员解释原因。”

“如果她现在很乱，选不出来？”

陆衍看着她：“先把明早以前不可逆的风险关掉，其余延后。由你确认她同意哪些临时措施。”

林栀点头。

视频接通时，许棠背后是一面空白墙。她显然刚哄睡小禾，声音压得很低。林栀没有先展示卡片，而是确认她现在是否独处、孩子是否会听见、是否需要让支持人员在线。

许棠说：“我可以听。”

“学校今天十七点二十分左右发现第二束白色洋桔梗，位置在侧门栏杆内。卡片提到明天按原时间接孩子。现在没有证据确认投放人，也没有证据确认它和第一束花来自同一人。”林栀停了一下，“这意味着风险信息出现了，但责任人仍需调查。你可以决定明天是否让小禾到校，也可以决定她知道多少。”

许棠脸上的血色一点点退下去。

“他知道学校。”

“能够确认的是，有人知道学校和原接送时间。”林栀说，“我们怀疑旧通知链路、家庭联系人或设备权限仍可能泄露信息，这是调查方向，不是已经证明的来源。今天后台管理员换设备查看旧手表状态，也只能证明权限仍被使用，不能单凭这条记录确认具体是谁操作。”

陆衍坐在一旁，没有用“就是他”替她的恐惧寻找一个过早的落点。

许棠闭了闭眼：“我不想让小禾再去。可她这两天刚敢跟同学说话。如果突然不去，她会问是不是爸爸找到我们了。”

“有三个方案。”林栀把写好的页面共享出去，“第一，明天暂缓到校一天，学校只记录为家庭安排，不对班级说明；第二，正常到校，但更换入校通道和校内接收人，取消固定放学时间，由你在安全确认后决定离校；第三，上午远程参与，下午再评估。没有绝对零风险的选项，我们会把每个方案需要的人数和信息暴露点告诉你。”

许棠问：“你们觉得哪个最好？”

林栀没有躲开她的视线：“如果只看即时暴露，暂缓到校更低。但你和小禾要承担的不只是一天的安全，也有她对生活秩序的感受。我可以给风险判断，最后的选择应该是你的。”

这句话说完，她胸口微微发紧。

她知道“自己选择”对于长期被控制的人并不总是礼物。有时它像一道突然撤去栏杆的台阶，让人更害怕摔下去。可替许棠决定会更快，也更像宋恺一直以来做的事：把“我是为你好”放在所有选择之前。

许棠沉默了很久，最后说：“明天上午远程。中午我再看她的状态。不要告诉她花的事，只说学校调整课程。”

“好。”

“旧手表呢？”

“已经停用并隔离，后台令牌冻结，保留访问记录。”陆衍只陈述已经执行的措施，“替代设备不接入旧家庭账户。是否进一步注销原管理员、何时向平台和有关部门提交记录，仍按你授权的范围进行。”

许棠看向他：“学校名单都删干净了吗？”

“还在逐项复核，不能现在告诉你‘都干净了’。”陆衍说，“目前已停止旧监护人邮件自动转发，冻结原家庭联系人查看接送时间的权限。接下来需要你确认三类名单。”

林栀把名单念给她听。

第一类是可接触孩子的人，暂时只有许棠本人和一名经过核验的支持人员；第二类是只在医疗紧急情况下联系的人，孩子祖母是否保留，由许棠选择；第三类是绝对不得获得在校、课程、接送和位置消息的人，宋恺及其代办人员列入其中。

“祖母留在医疗紧急联系里。”许棠声音发哑，“但不能接孩子，也不能知道她几点走。”

“记录。”林栀说。

“如果有人自称你授权临时接送，”陆衍补充，“学校不通过电话和聊天截图确认，必须由你在新设的双重验证渠道完成。任何未经验证的人到校，孩子不离开校内安全区。”

“我同意。”

他们又确认了明早远程课程的登录方式、班主任的单线联系窗口、紧急暗语和报警触发条件。每增加一项措施，林栀都会问一次许棠是否理解、是否同意；陆衍则把同意的时间、范围和执行人记入表格。

没有谁说“我们替你安排好了”。

通话结束时已过十一点。

林栀把耳机摘下来，才发现汤又凉了。陆衍起身去热，这一次她没阻止。

蓝筹码依旧安静地待在原处。

“今晚不恢复。”她说。

“知道。”

“不是我回避刚才的问题。”

陆衍按下微波炉按钮，转身看她：“停战期间不要求自证。”

林栀心里一顿。

她原本准备了三句解释，用来证明门铃不是她借机逃开、许棠的事也不是一个可以被滥用的挡箭牌。他却先把她从证明责任里放了出来。

微波炉发出低沉的运转声。隔着厨房与餐厅不到三米的距离，他们谁也没有靠近。可那句没有说完的话并未因此变轻，反而像被妥善保存的证物，清楚标着时间、边界和下一次开启的条件。

陆衍把热汤放到她手边：“我去和周屿看学校监控。”

“一起。”

“你可以休息。”

“共同生活不等于共同熬夜，”林栀喝了一口汤，“但共同代理可以。”

“这句适合放采访澄清里。”

“你敢提采访，我就把你今晚所有私人问题移送明年。”

陆衍终于有了一点极淡的笑意：“停战期间不威胁对方。”

“职业风险提示。”

笑意只停留了一瞬。周屿发来消息，学校已经导出侧门、正门和周边公共区域的监控。三个人进入加密会议，按时间线从花束被发现前两小时开始核看。

侧门画面角度有限。十七点十三分，一道戴帽子的身影从栏杆外经过，停留不到十秒。身高、性别和面部都无法辨认，只能看见手臂有一次越过栏杆的动作。十七点二十一分，保洁出现在画面里，随后叫来老师。

“确认事实：有人在对应时间向栏杆内放入物品。”周屿说，“调查方向：追投放者来路、花店包装、周边更清晰镜头。未证结论：投放者身份以及是否受任何人指使。”

陆衍把那十秒单独标记，没有放大后凭模糊轮廓猜人。

他们继续向前倒查。

正门摄像头覆盖了半条街。画面里家长车辆不断进出，四点四十分以后渐渐稀疏。林栀逐一核对已登记的车牌，看到一辆深灰色车时，手指停在触控板上。

那辆车没有驶入接送区。

它停在校门斜对面的树影下，位置刚好能看见正门，却避开了保安登记镜头。车型和颜色都出现在许棠此前提交的家庭车辆关联表里，车牌后两位被树枝遮住，暂时不能完成唯一识别。

“先别说是谁的车。”林栀说。

“我只记可见特征。”陆衍回答。

他们把三个角度的时间轴对齐。

花束被放进侧门后，那辆熟悉的车没有立刻离开。

监控显示，它在学校门外整整停了四十分钟。
