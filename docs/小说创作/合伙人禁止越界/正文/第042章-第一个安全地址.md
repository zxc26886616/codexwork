# 第42章 第一个安全地址

知道便利店，不等于知道新的临时接待点。

林栀先把这句话告诉许棠。

“目前消息只证明他掌握了你在青蒲路便利店停留的信息。接待点地址没有出现在消息里，也没有证据表明已经暴露。”

许棠问：“那我们今晚还安全吗？”

“现有信息下，接待点的地址控制没有发现异常。值班人员会加强入口确认，也会准备备用转移方案。是否立刻再次转移，需要看你和孩子的状态、地址暴露迹象以及场所建议。”

“小禾刚躺下。”

“你愿意先留在房间，由值班人员提高警戒吗？”

许棠看了一眼已经缩进被子里的孩子：“愿意。”

“好。任何人敲门都先联系值班人员，不自行开门。宋恺如果提到新的地址、发送现场照片，或者入口出现异常，立即打这个独立电话。”

“明白。”

电话结束后，林栀在风险表上把“便利店位置已被掌握”和“接待点地址是否暴露”分成两项。

陆衍已经调出一张排查树。

第一支是人：保安、店长、亲属、学校、出租方和可能看见母女路线的路人。

第二支是设备：许棠手机、孩子手表、平板、车辆、无线耳机、随身标签与家庭智能设备。

第三支是账户：共享云空间、家庭定位、家校平台、邮箱、支付账号、叫车和外卖记录。

第四支是行为推断：宋恺是否只知道旧地址，是否通过沿街寻找发现便利店，是否从保安或监控之外的人获得消息。

没有哪一支被提前定成答案。

“先调一个安保团队去接待点外圈，另外准备备用车辆。”陆衍拿起手机。

林栀按住他的任务表：“先问。”

他动作停住。

“地址已经可能暴露。”

“可能暴露的是便利店，不是接待点。安保进入外圈会增加知情人员，也可能让许棠觉得自己又被别人接管。”

“至少备用车辆要有。”

“可以作为选项，不是直接调度。”

两人对视一秒。

陆衍很快放下手机。

“是我越过授权。”

没有争辩紧急情况下先做更安全，也没有用好意替代许棠的选择。

他重新拨通独立电话，请值班人员把两种方案转达给许棠：一是维持现有内部安全，外部不增加人员；二是由经过核验的安保在不进入住所的情况下待命，同时准备备用车辆。安保需要知悉接待点外围位置，会增加最小范围的信息接触。

许棠听完，选择第二种，但提出一个条件：“不要穿制服，也不要让小禾看见很多人。”

“可以。”陆衍问，“你希望我直接协调，还是由林律师决定我做哪一段？”

这句话比第一通电话慢了一步，却仍及时改正。

许棠说：“你协调车和外面的人，地址让接待点直接给他们。我不想再转发一次。”

“授权范围确认：只处理外圈观察和备用车辆，不接触你和孩子，不保存室内信息。”

“确认。”

陆衍这才开始调度。

林栀看着他在任务表上补上“许棠00:17授权”。

控制与保护有时外形很像。

都是安排路线、调动资源、预判风险，甚至都会说“我是为了你好”。区别不只在结果，也在对方是否知道、是否选择、是否能拒绝。陆衍最擅长先把所有漏洞堵上，今晚却必须在每一次好意前停下来，把方向交还给真正承担后果的人。

他没有因被提醒而不满。

只把“先问”写进了后续任务首行。

林栀看见那两个字，心里并没有胜过他的轻松。

她知道陆衍为什么会先拿手机。

当危险存在时，他的第一反应永远是把资源推到最前面，宁愿事后解释，也不愿承担来不及的后果。在很多职业场景里，这种反应救过项目，也替她挡过风险。可放到许棠身上，“我已经替你安排好”恰好与宋恺最常用的话只差一个意图说明。

意图当然重要。

陆衍想保护，宋恺想控制。

但仅靠“我是好意”还不足以划清全部边界。许棠是安保是否进入她周围、哪些人知道地址、孩子会看见什么的直接承担者。保护若剥夺了她的知情和拒绝，仍可能让她再次失去对生活的控制。

陆衍自己也明白。

“以后紧急资源先做预案，不实际发送地址。”他说，“除非存在无法等待的现场危险。”

“无法等待时也要尽量说明。”

“能说明就说明。不能说明的，事后立即告知动作、范围和撤回方式。”

“对。”

“这条是否适用于你？”

林栀抬眼：“当然。”

“以后你认为我需要休息、回家或退出工作，也先问。”

“我什么时候替你决定过？”

“庆功宴后直接把我带回栖云公馆。”

“你装醉，不适用正常授权分析。”

“但你当时知道。”

林栀被自己的第一章证据反过来堵住，停了半秒：“客户紧急，私人旧案冻结。”

“同意冻结。”

陆衍没有借题展开，只把这条对等原则也写进工作页。成熟合作不是一方持续纠正另一方，而是两个人都接受：擅长照顾别人，不等于天然拥有替别人决定的资格。

凌晨两点，外圈待命完成。

接待点没有发现可疑车辆或人员。宋恺没有再发新位置，只连续发送“我担心孩子”“你这样会毁掉她”“回家谈”等消息。团队保留原始时间和账号来源，不逐句与他交涉。

“现在不能直接回他，警告不得联系吗？”沈念远程加入后问。

“可以讨论，但先问许棠是否愿意、由谁发送、内容会不会暴露已经寻求法律帮助。”林栀说，“今晚她需要休息，不急着为了展示强硬立即回应。”

团队把非紧急排查移到早上。

三点，林栀和陆衍分别在办公室沙发休息。私人赌局仍冻结，蓝色筹码留在家里。没有人拿同处一夜开玩笑，也没有人说“你睡我办公室”。陆衍设了两小时轮值提醒，林栀确认值班电话转接，然后关灯。

五点十二分，接待点发来“无异常”。

七点半，许棠主动要求开始排查。

小禾仍在睡。许棠用独立电话参加视频，只拍摄自己，不显示房间背景。她先确认设备均由自己合法持有或共同使用，也授权团队在不登录宋恺私人独立账户、不尝试绕过密码的前提下，检查自己可以访问的家庭与设备设置。

“我们先列设备，不立即开机。”周屿说，“你告诉我有哪些，不需要说密码。”

许棠身上有一部手机、儿童手表、一副无线耳机和钥匙。平板留在青蒲路住处，车辆也在那里。孩子书包没带出，里面有学校卡和一只智能学习机。

“昨晚从住处到便利店，随身物品只有这些？”

“还有小禾的外套和一个布娃娃。”

“布娃娃是普通玩具？”

“会说话，能连家里无线网，但昨晚没开。”

周屿把它列入待核，不建议当场拆开。

“车辆没动，可以暂时排除它解释步行路线。”他说，“但不能排除宋恺通过车辆位置先找到青蒲路住处。”

许棠点头。

第二项是账户。

手机使用许棠个人云账号，但家庭相册和日历曾与宋恺共享；小禾的儿童手表由许棠购买，激活时宋恺帮忙设置。家庭定位功能表面已经关闭。外卖账号改过密码，支付软件退出了其他设备，叫车记录昨晚没有使用。

“新住址怎么租的？”林栀问。

“我自己联系，押金从新银行卡付。没有告诉父母。”

“租房平台账号以前在家庭平板登录过吗？”

许棠想了想：“可能有。我看房时用过家里的平板，后来删除了软件。”

删除软件不等于清除账号同步记录。

团队把租房平台列为可能路径，但不在没有记录的情况下直接认定。

第三项是人。

青蒲路保安承认宋恺出示过结婚照和孩子照片，自称妻子情绪不稳定、带孩子失联，询问母女是否住在楼内。保安没有提供具体房号，但说了一句“刚搬来不久，住高层”。宋恺可能借此缩小了范围。

便利店店长则确认，母女进店后没有人跟随。陌生电话在母女进入储物间七分钟后打来，来电者准确描述许棠衣着，问她是否带着一个穿黄色外套的女孩。

沿街发现仍有可能。

但宋恺随后知道“储物间”，单靠从店外观察很难解释。

“店长有没有对电话里的人说储物间？”林栀问。

“她说没有，只回答不便透露顾客信息。”

“店内其他员工？”

“当时只有店长和一名理货员。理货员知道母女去了后面，但没有接电话。”

人员路径暂时没有闭合。

上午九点，许棠同意先检查手机的可见账户设置。

接待点提供只读记录条件。许棠本人开机，先拍摄设备外观和系统时间，再关闭网络自动连接，避免未经评估的同步覆盖现有状态。周屿全程只口头指导，由她操作；屏幕录制范围避开与本案无关的私人内容。

共享云账户中，家庭相册已退出，日历共享仍保留一个旧家庭组。组成员显示宋恺，但位置权限为关闭。

“表面上看不出昨晚路径。”周屿说，“先固定页面和账户成员信息，不要尝试登录对方账号。”

无线耳机的“查找”功能绑定在许棠个人账户，未共享。

手机系统定位总开关确实在昨晚十一点四十二分关闭。应用权限记录中，没有一款软件在关停后继续读取位置。

许棠盯着屏幕：“那他怎么知道？”

“暂时不能回答。”林栀说。

“是不是有人告诉他？”

“可能，也可能还有我们没检查到的设备或账户。不要因为技术页面没显示，就立刻怀疑亲友。”

她想起第一卷里差点被怀疑的内部团队。

当一个解释缺失时，人最容易抓住身边的人填空。可怀疑一旦公开，关系损伤不会因后来找到真正路径自动消失。

许棠把几个可能知情的人念了一遍。

父母知道她准备离开，却不知道青蒲路；大学同学帮她看过租房信息，只见过三个备选小区；学校班主任知道小禾暂时请假，不知道母女住哪。新房东只通过平台沟通，保安是在入住当天见过她。

“我妈会不会说了？”她问。

“你有具体信息吗？”

“宋恺昨天给她打过电话。”

“电话内容知道吗？”

“不知道。我妈只说他很担心，让我别把事情做绝。”

“这能证明他们联系过，不能证明她提供地址。”林栀说，“如果你愿意，我们之后可以设计不暴露新地点的询问方式。现在先不直接质问，避免对方意识到我们在排查哪条路径。”

许棠按了按额头：“我现在觉得每个人都可能告诉他。”

“这种感觉很正常，但不用现在选一个人相信或怀疑到底。安全计划可以先按信息最小化运行，不必等到找到泄露者。”

“那我以后谁都不能联系了吗？”

“不是。完全隔离也会让你失去支持。我们可以把信息拆开：愿意联系谁由你决定，但不提供地址、路线、学校安排；必要见面选中立地点；对方如果追问，就用统一回应。”

“什么回应？”

“例如，‘我们目前安全，具体位置暂不提供，需要联系请通过约定渠道。’你可以按自己的语气修改。”

许棠想了一会儿：“我想告诉父母我和小禾安全，但不告诉他们在哪。”

“可以。要现在发吗？”

“等手表查完。”

“好。”

她没有因为一次可能的泄露就被迫切断所有亲属，也没有被要求继续信任任何人。控制信息的同时保留支持关系，本身也是安全计划的一部分。

周屿又请她回忆手表初次设置过程。

设备是小禾入学时买的。宋恺负责拆封和绑定，说孩子安全功能复杂，许棠只要当日常联系人就够。后来夫妻争执加重，许棠曾在手表上关闭家庭定位。宋恺当晚就知道，质问她为什么“拿孩子安全赌气”。

“当时你有没有想过他通过后台看到设置变化？”

“他说系统会通知所有家长，我就信了。”

“这个说法先记录，等服务商规则和后台日志核验。”

“如果真有另一个账户，是不是就能证明他一直监控？”

“能证明到哪一步，要看账户归属、权限、登录和查询记录。”周屿说，“仅有账户存在，不自动证明是谁操作，也不证明每次位置都被查看。”

许棠点头，神色仍紧绷。

林栀提醒：“今天的目标不是一次把所有责任证明完。先确认设备是否继续构成风险，再固定不会被后续设置覆盖的记录。”

十点，轮到儿童手表。

许棠先确认小禾醒来、吃过早餐，并以孩子能理解的方式说明：“我们要看看手表为什么会让爸爸知道位置，可能需要暂时不戴。里面和同学的聊天不会给不相关的人看。”

小禾抱着杯子问：“爸爸说手表是保护我的。”

“手表可以保护你。”许棠说，“但谁能看你在哪里，要重新检查。”

“我可以不给爸爸看吗？”

“我们先弄清楚怎么设置，再告诉你。”

孩子点头。

团队没有把她带进成人争议，也没有让她当场评价父亲。手表由许棠操作，周屿只检查管理员、家庭成员和定位权限。

设备主界面显示定位已关闭。

第一管理员是许棠的手机号。

家庭成员列表里，宋恺显示“已退出”。

表面上与她昨晚的操作一致。

周屿却注意到一个入口：“设备服务账号。”

许棠点进去。

页面要求二次验证。验证码发到她的手机，她本人输入后，后台账户列表出现。

除了当前主账号，还有一个标注为“设备协管”的管理员。

账号昵称是一串普通字母，绑定尾号不是许棠，也不是她记得的宋恺号码。

权限详情显示：可以查看设备最后位置、接收安全区域通知、管理紧急联系人。

许棠脸色一点点白下来。

“我从来没见过这个账号。”

定位开关确实关了。

可另一个管理员，始终留在后台。
