# 第40章 长期有效

林栀一眼认出了那枚钥匙扣。

不是款式相似。

皮面压纹、银环宽度，甚至边缘那道不明显的深灰缝线，都与她用了两年的钥匙扣完全一致。

“什么时候买的？”她问。

陆衍把钥匙扣放在玄关台上：“庆功宴之前。”

“具体时间。”

“三个月前。”

又是三个月。

行李箱在那时准备，装醉方案在那时成形，这枚与她完全相同的钥匙扣也在那时被买下。

“你那时连门都没进。”

“所以只是钥匙扣，没有钥匙。”

“准备给什么用？”

“如果计划成功，给你签发的钥匙。”

“如果失败？”

“继续放着。”

“放多久？”

“直到用途出现，或者我决定不再等。”

陆衍的回答没有戏剧性的保证。

三个月前，他并不知道林栀会不会接住那个装醉倒下的人，不知道她会不会带他回栖云公馆，更不知道一宗突然到来的婚内股权案会把七天观察期延伸成共同生活。

他只先买了一枚钥匙扣。

不是伪造结果，也不是默认获得权限。只是在所有不确定里，为一个可能出现的位置提前留出形状。

林栀拿起来。

皮面还是新的，几乎没有使用痕迹，只有银环内侧有一道很浅的划痕，像被反复取出又放回。

“一直随身带着？”

“庆功宴当晚带了。之后放在行李箱内层。”

“为什么今天才拿出来？”

“钥匙期限一直与案件绑定。”

“现在呢？”

“由签发人决定。”

陆衍没有用这枚三个月前买好的东西换取同情，也没有说自己从第一夜就认定永远。他把事实完整交出，决定权仍停在林栀手里。

玄关台上，现有钥匙旁还贴着那张旧便签。

`有效至本案结束。`

顾念安案已经完成首期履行，进入后续评估与分期跟踪。按他们最初的定义，紧急共同值班结束，案件期限条件已经触发。

林栀揭下便签。

纸胶在台面留了一点痕迹。她用指腹擦了两下，没有立刻写新的。

“你第一夜就认为我会给钥匙？”

“认为存在可能。”

“概率？”

“初始百分之二十。”

“这么低还提前买？”

“成本可控，结果价值高。”

“后来呢？”

“你拿出合适尺寸的拖鞋，升到百分之三十五。”

“让我睡客房？”

“降到三十。”

“第二天给七天观察期？”

“百分之五十。”

“顾念安案需要共同值班？”

“不计。职业事件不能用于提高私人结果概率。”

“透明箱固定格位？”

“七十。”

“共同地址登记？”

“八十。”

“我撕掉搬离标签？”

陆衍看着她：“不再计算。”

“为什么？”

“结果已经不是会不会得到一把钥匙。”

“那是什么？”

“你会不会主动取消临时。”

林栀的手仍压在旧便签上。

这人把得到钥匙当成一个可计算事件，却在真正接近答案时停止概率分析。因为概率可以帮助他决定是否准备一枚钥匙扣，却不能替她决定要不要留下他。

“现在结果出现了吗？”她问。

“标签改了，期限取消了。”

“仍然没回答。”

“需要签发人作最终登记。”

林栀拿起笔。

她没有写“永久”。

永久是一种无法由当下诚实保证的承诺，也会与任何一方随时提出停止的公约冲突。她同样没有再写案件、七天或待评估。

只写四个字：

`长期有效。`

陆衍的目光落在笔尖。

“长期如何定义？”他问。

“没有预设失效日。任何一方提出终止时，按公约和共同生活交接规则处理。”

“不是不可撤销？”

“不是。”

“不是因顾念安案继续？”

“不是。”

“不是为了奖励我提前准备钥匙扣？”

“不是。”

“理由？”

林栀看着他：“我想让你继续拥有进门权限。”

一句足够明确的选择。

陆衍没有再问是不是需要，也没有把它逼成告白。他伸手接过新便签，指腹在“长期有效”上停了一下，然后把自己的钥匙从旧扣环拆下，装进那枚深灰色钥匙扣。

两串钥匙并排放在玄关台。

一串用了两年，皮面柔软，边缘已有磨痕；一串刚开始使用，颜色更深，银环仍亮。

款式相同，却不是为了让谁取代谁。

只是从今天起，同一扇门有了两份长期有效的进入权限。

林栀打开物业住户系统，把此前因案件设置的临时访客权限调出来。

系统询问是否延长七日、三十日或自定义日期。

她没有选择任何一个。

而是在“共同居住成员”栏提交长期登记，保留双方随时撤回的确认项。系统需要被登记人本人再次验证，陆衍的手机很快收到推送。

“是否接受？”林栀问。

“接受。”

“系统会显示你的姓名和联系方式，不显示私人关系定义。”

“够了。”

“紧急情况下物业可以联系你，门锁、消防和停水通知也会同步。”

“明白。”

“退出时，你本人也可以申请注销，不需要经过我批准。”

陆衍看着确认页面：“这条保留。”

“本来就保留。”

他完成验证。

页面上的“临时到访人”消失，替换成“共同居住成员”。没有伴侣、朋友或合伙人的选项，也不要求他们向系统解释关系。它只确认一个生活事实：陆衍住在这里，拥有与居住责任相匹配的通知权和退出权。

林栀把手机锁屏。

“现在才算登记完成。”

陆衍问：“为什么钥匙扣要选同款？”

“这是我的问题。”

“你一直没问。”

“现在问。为什么？”

他拿出自己的钥匙，与她的并排比较：“你用了两年，说明耐用。颜色不会在办公场合过于显眼，尺寸适合放外套口袋。”

“只有功能理由？”

“同款物品放在玄关，不需要区分谁是临时客人。”

后一句终于越过功能。

林栀的钥匙扣是搬进栖云公馆时买的。那时她结束上一段长期合作关系，重新建立律所和生活秩序，钥匙只属于她自己。陆衍没有要求共享她的那一枚，也没有复制任何权限。他只是准备了一件并排时不会显得突兀的东西，等她决定是否把真正的钥匙交过去。

“你连并排效果都算过。”她说。

“基础审美。”

“如果我换了钥匙扣？”

“我也换。”

“为什么不是让我配合你的款式？”

陆衍看她：“因为是我申请进入你的既有生活。”

林栀心口轻轻一紧。

这句话本可以被理解成迁就，却没有自我牺牲的意味。他不是要消失在她的秩序里，而是承认进入别人已经建立的空间，应先看见原有边界，再共同决定哪些地方改变。

“以后不是只配合我。”她说。

“什么？”

“共同居住成员有权提出调整意见。灯光、收纳、采购，包括钥匙扣，都可以谈。”

陆衍的目光停在她脸上。

“这是共同决定权？”

“有限范围。”

“先接受，再逐步扩大。”

“不承诺扩大。”

“但保留可能。”

林栀没有否认。

“登记完成。”林栀说。

“是否需要拍照留档？”

“不需要。”

“我也认为不需要。”

陆衍把钥匙收进口袋。

金属轻响落下时，林栀心里某个持续七天、又像持续了很多年的倒计时终于停了。

她没有失去退出权。

只是主动取消了自动结束。

晚上十一点二十分，两人回到客厅。

冰箱上的公约仍只有三行。林栀把旧钥匙便签折好，放进厨房抽屉，与第一局记录放在一起。蓝色筹码则重新摆到茶几中间。

“外号问题还没解决。”她说。

陆衍坐在沙发另一侧：“钥匙登记与外号无关。”

“你准备了三个月的同款钥匙扣，仍然不肯作明确陈述。”

“行动已经明确。”

“行动可以解释成概率投资。”

“刚才的计算只是帮助你理解准备过程。”

“恰好进一步证明你善于绕开语言。”

“所以？”

林栀拿出那张过程计分便签，在两列名字上方写下总赌注：谁先明确告白。

第一局无人得分。

更早的亮灯回合里，陆衍得到一分，但那发生在正式公约之前，是否计入仍需重新确认。

“我建议从现在开始建正式台账。”她说。

“亮灯回合的一分呢？”

“历史试运行数据，不计正式总分。”

“你怕我领先。”

“我反对规则生效前的追溯适用。”

“理由成立。”

“第一局平局，当前零比零。”

“同意。”

“总赌注保持不变，过程分只记录明确私人意图，边界确认、创伤、疾病、客户危机不计分。”

“同意。”

“任何一方可以停止整场赌局。”

“停止后呢？”

“诚实处理现有关系，不以停局等于拒绝对方。”

“同意。”

“告白以后不得为了维持游戏否认已经发生的关系变化。”

“同意。”

林栀把便签放到茶几上：“是否接受长期赌局？”

陆衍没有立刻回答。

“怎么，装醉敢，正式开始不敢？”

“我在确认一件事。”

“什么？”

“你提出这场赌局，是想让我先说，还是想保证自己不用先说？”

林栀心跳一顿。

第一场正式建账尚未开始，他已经找到总赌注里最危险的歧义。

“两者不冲突。”她说。

“真实答案？”

“我想赢。”

“赢的结果是听见我告白。”

“你的理解能力没有退化。”

“所以你想听。”

“这是结果，不是动机。”

陆衍看着她，唇角慢慢有了一点弧度：“暂不追问。”

“你还没回答是否接受。”

他拿起蓝色筹码。

没有推向她，也没有留在自己一侧，而是放回两人正中。

“接受。”他说，“现在开始。”

林栀拿笔在两个人名字下各画一个零。

“开始以后，第一项禁止行为。”林栀说，“不得把‘陆无说’解释成我催你告白的证据。”

“但你确实用外号发起过整改回合。”

“那是验证准确性。”

“并且给出告白标准。”

“公约本来就有标准。”

“并且表示由你判断是否有效。”

“为了避免你用模糊陈述蒙混。”

陆衍点头：“记录为起草人高度关注告白质量。”

“删除。”

“私人记录不需要单方批准删除。”

“那就记上你的外号。”

“已经存在。”

林栀拿笔，在陆衍名字上方写下小小三个字：陆无说。

又在自己名字上方留出空白。

“为什么你没有外号？”他问。

“目前没有形成传播。”

“林不承？”

“修辞质量更差。”

“栀不答？”

“生硬。”

“签发人零续期？”

“事实已经失效。”

陆衍看了一眼玄关那张“长期有效”：“确实。”

他没有继续给她起外号。

不是因为找不到，而是他知道“陆无说”好笑的前提，是当事人能够接受。林栀把它带回家，陆衍便认了；她对自己的外号没有表现出同样意愿，他就停在尝试阶段。

“台账保存在家里。”林栀说，“不能带去律所。”

“同意。”

“不能为了制造公开见证故意泄露。”

“同意。”

“周屿他们如果自行猜到？”

“不确认，不否认，不利用。”

“为什么不否认？”

“虚假陈述影响职业信誉。”

“你可以说与工作无关。”

“采纳。”

林栀在台账背面写下保存规则。两个人对着一张零比零的纸讨论了五分钟，严肃程度像在建立重大项目制度，实际总资产只有一枚蓝色筹码和一个新外号。

“长期作战的资源配置是不是太少？”陆衍问。

“真正的资源是双方诚实。”

“这句接近宣言。”

“一般原则。”

“记录。”

“不计分。”

第一场正式争议在零比零上结束。

“请陆无说做好长期作战准备。”

“请起草人先熟悉正确示范。”

第一卷的私人赌局终于从临时试探变成双方明知、可停、长期有效的共同选择。

没有人告白。

但也没有人再假装这只是一场关于住宿和钥匙的风险管理。

十一点四十三分，林栀手机响了一声。

顾念安发来第一份完整履行确认。

监管银行已经按约完成首期款释放；明川专项披露归档；评估机构确认接受委托；程启明一方没有在中性说明之外发布额外内容。顾念安在确认末尾写：`我知道后面还有评估和分期，但我今天第一次觉得，事情真的开始往前走了。谢谢。`

林栀把消息给陆衍看。

“是否回复阶段结果，不说圆满。”他说。

“我知道。”

她回复：首期节点已完成，后续事项仍按清单跟进；如果出现新遗漏或履行异常，随时联系。最后没有加“恭喜结束”，只写了一句：今天可以先好好休息。

顾念安回了一个“好”。

案件与关系在同一夜各自取得一个有限结果。

顾念安没有拿回全部过去，却拿到了可以执行的现在。

林栀和陆衍没有承诺永远，却取消了自动到期的临时安排。

两者都不是童话式终点。

却足够真实，足够让人从明天继续。

十一点五十八分，陆衍去厨房倒水。

林栀把台账折好，正准备关灯，律所紧急值班电话忽然接入她的手机。

来电号码陌生。

背景里有便利店提示音、压低的哭声，还有小孩急促的呼吸。

“请问是林律师吗？”

女人说话很轻，像生怕墙外有人听见。

林栀立刻坐直：“我是。你现在安全吗？”

“我不知道。”

“先告诉我，你和谁在一起，是否有人受伤，需不需要立刻报警或叫救护车。”

电话那头停了两秒。

“我和女儿躲在便利店的储物间。她没有受伤，我也没有。”女人努力压住声音，“我们换了住处，关了定位，连孩子学校都请了假。”

陆衍听见动静，从厨房出来，没有问私人台账，直接拿起纸笔。

林栀没有直接打开免提，先征得同意：“我身边有另一位律师陆衍，可以一起听、帮你安排安全资源，可以吗？”

“可以。”

“好。你叫什么名字？”

“许棠。”

“谁在找你？”

女人的呼吸骤然乱了一下。

便利店门外似乎有人经过，储物间里的孩子很轻地叫了一声妈妈。

几秒后，许棠压低声音：

“林律师，他找到我和孩子的新住址了。”
