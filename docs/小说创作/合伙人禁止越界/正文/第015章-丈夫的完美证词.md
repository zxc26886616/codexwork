# 第15章 丈夫的完美证词

程启明的书面说明在次日上午送达。

正文二十六页，附件目录四页，几乎回答了团队此前提出的每一个问题。

他解释自己为何出现在供应商审批中：受聘担任无固定报酬的战略顾问，只对重大预算提供意见；解释自己为何审批差旅：公司系统沿用旧账号，实际决定由管理团队形成；解释三百六十万元“分红”：那是程启川委托他代为管理部分收益后的结算；解释一元转让：登记恢复所需的形式价格；解释股权质押：为公司正常融资提供增信，与离婚无关。

每一段都对应一个疑点。

每一段都把疑点放进一个表面合法的抽屉。

周屿看到第十页，评价只有四个字：“滴水不漏。”

“先别夸。”唐澄说。

“我不是夸。我是觉得一个人能把三年前每次审批的性质都记这么清楚，很可怕。”

林栀没有立刻说话。

她把说明从头读到尾，又倒回第一页，第二次只看问题顺序。

程启明没有按时间讲述。他按法律争点讲述：先说明权属基础，再说明登记外观，然后处理收益，最后处理紧迫性和主观目的。连“我记不清”的位置都非常准确——忘记的都是不影响主叙事的细节，记得的则恰好能填补每一个程序缺口。

“不像自然回忆。”她说。

陆衍问：“像什么？”

“问答训练后的完整输出。”

“理由？”

“真实记忆通常按事件、人物或者情绪组织。这个版本按我们会提出的法律问题组织。程启明记得自己为什么有审批权限，却不记得顾问关系何时开始；记得三百六十万元是结算，却不记得结算依据是哪份文件；记得质押是正常融资，却不写质权人和基础债务。”

“只保留结论，不保留结论形成过程。”唐澄说。

“对。”

这仍不证明说明虚假。一个当事人在律师帮助下整理事实，本来就可能比口头回忆更有结构。接受专业协助也不是问题。

问题在于，谁帮助他整理，整理时依据了什么，以及那些精确回答能否被客观材料支持。

“做双栏。”林栀说，“左边原话，右边验证载体。没有载体的不要写假，只写待核。”

团队开始拆解。

“无固定报酬战略顾问”对应的聘任、权限和期限文件：未提供。

“旧账号仅为流程沿用”对应的后台权限配置和实际审批人：未提供。

“收益结算”对应的委托管理、账目和税务处理：未提供。

“正常融资”对应的基础合同、资金用途和第三方关系：以商业秘密为由未提供。

二十六页说明很完整，真正能让结论落地的材料却仍然稀薄。

第一处需要核验的是“旧账号沿用”。

程启明称自己只是应管理层请求代为点击系统节点，从不改变实质决定。可现有导出记录里，他至少两次修改预算，一次把付款节点后移，还驳回过一项已经由程启川同意的差旅。

“如果只是代点，为什么能改内容？”周屿问。

“可能是系统界面由他操作，线下决定仍来自程启川。”唐澄说。

“那就需要线下指令或流程说明。”林栀在右栏写下：实际指令来源、账号操作人与权限配置。

第二处是“收益结算”。

说明把三百六十万元定义为程启川所有收益的内部结算，却没有解释为什么付款备注是“分红”，也没有解释启禾取得相关款项时按咨询收入还是投资收益入账。若是咨询费，需要真实服务与税务凭证；若是分红，需要说明启禾或程启川凭什么取得；若只是代管资金，又需要账目证明程启明如何代管、何时返还。

一个“结算”词把三种不同关系叠在一起，读起来完整，核验时却必须重新拆开。

第三处是“多年个人积蓄”。

程启明列出车辆、腕表和证券投资，承认均属个人安排，却否认与关联转款有关。他没有提供转款前后的账户余额，也没有说明所谓积蓄长期存放在哪里。

“这部分不要倒置举证。”陆衍说，“我们不能因为他没主动证明积蓄，就直接推定消费来自那三笔钱。申请完整流水，比较资金进入、余额变化和实际支出。”

林栀点头，把原本写着“虚假来源”的一条批注删掉，改成“来源待银行流水核验”。

第四处是股权质押。

说明称融资谈判早在离婚争议前启动，却只附一封日期较早的商务接洽邮件。邮件证明双方讨论过融资，不证明最终基础债务、担保范围和在此时提交登记的原因。

团队把融资接洽、股权转让申报、赠与协议提出和质押登记申请放进同一条时间线。越接近顾念安正式委托，财产外观变化越密集。但时间接近仍只是紧迫性和调查必要性的线索，不自动等于恶意串通。

“他每一段都给了答案。”周屿说，“可每个答案后面都要再问三个问题。”

“这就是标准结论和真实记忆的区别。”林栀说，“标准结论追求封口，真实材料允许别人看到它怎么形成。”

陆衍把说明中的绝对词全部标出来：从未、始终、仅仅、全部、完全无关。

“这些词不是错误。”他说，“但它们提高了核验要求。只要出现一个反例，对应段落就必须重新解释，不能再靠模糊范围维持。”

团队没有寻找华丽的致命漏洞，而是给二十六页说明制作了一张更长的验证表。每个结论后面都有材料状态：已提供、部分提供、拒绝提供、需要调查、与现有材料不一致。

到表格完成时，那份看似密不透风的证词终于恢复了真实尺寸。

它是一方经过专业整理的主张。

不是判决，也不是事实本身。

周屿把表格拉到最下方：“像一栋装修完美的房子，打开门发现承重墙还在图纸上。”

“这个比喻可以保留。”林栀说。

“终于有一次不用加脚注？”

“需要。房屋比喻不代表工程质量结论。”

周屿把笑憋回去：“我就知道。”

上午十一点，顾念安到所核对说明中的家庭事实。

程启明称三年前四月二十六日签署赠与协议当天，已提前告知妻子自己要处理家族股权。顾念安看见这段，第一反应是摇头。

“他没有告诉我。”

“有没有可能提过家里或公司的事，但没有说协议？”林栀问。

顾念安想了很久：“那天我爸手术。他在医院待到中午，下午说公司有事先走。晚上回来很晚。我问他，他只说启川又惹麻烦。没有提股权。”

“你能确定的是这些？”

“对。”

“那就按这些确认。不写他绝对没有在其他时间说过。”

顾念安点头。

说明还称，高额腕表和车辆支出均来自程启明个人多年积蓄，与三次关联转款无直接对应。这个说法理论上可能成立，恰恰需要完整流水核验。

顾念安看到“多年积蓄”时笑了一声，笑意很冷：“他以前跟我说，钱都压在公司里，家里现金紧张。给我爸做手术时，我卖了自己的基金。”

“基金赎回有记录吗？”

“有。”

“医疗支出呢？”

“也有。”

“保存。它不能直接证明那几笔钱的来源，但能核验他当时向家庭呈现的资金状况。”

顾念安把说明合上：“他怎么能把每件事都解释得这么合理？”

林栀没有说因为他在撒谎。

“合理是一项需要验证的主张，不是材料看起来专业就自动成立。”她说，“我们一项一项查。”

顾念安离开后，程启明一方先一步向媒体发布了企业经营声明。

声明没有披露案件具体材料，只称近期因“个别家庭成员与代理机构的过度主张”，公司正常股权调整和融资受到影响，将依法维护企业、员工与投资人的权益。

半小时内，律所前台接到六家媒体电话。

问题从保全是否影响员工工资，到林衍所是否鼓励当事人借离婚干预公司经营。还有人直接问，林栀和陆衍是否利用个人关系共同炒作案件。

沈念统一回复：涉及客户隐私和未公开程序，不作评论；可以在获得授权后说明一般法律常识，但不讨论具体当事人信息。

团队先征求顾念安意见。

她不愿公开个人经历，也不同意披露具体金额、家庭账本或父亲手术信息，但授权律所纠正“申请保全等于恶意冻结企业”“配偶无权审查登记在公司体系内的婚内利益”两类普遍误导。

“如果我什么都不说，会不会像默认他们说的是真的？”她问。

“沉默不等于承认。”林栀说，“是否回应要看能不能保护你的程序权利，而不是为了赢舆论把隐私交出去。”

“那就只讲程序。我的事不要讲。”

“好。”

沈念据此划出对外边界：不确认双方关系细节，不公布具体资产与措施范围，不评价程启明主观动机，不展示任何客户聊天或账本；只说明保全的一般性质、争议财产需要分别审查，以及律所依法接受委托。

周屿看着问题清单：“记者如果一直问顾念安是不是为了离婚抢公司呢？”

“重复边界，不用新事实换取对方停止追问。”林栀说。

“如果问我们是不是炒作？”

“说明今天回应的范围由公开声明造成的普遍误解决定，不讨论客户策略。”

“如果问你和陆律师？”

林栀的笔停了一下：“与案件无关。”

陆衍在旁边说：“各自决定是否回答，不拿客户场合计分。”

这句补充很必要，也过于了解她。林栀没有反对，只让沈念写进采访规则。

陆衍看完媒体问题清单：“我处理。”

林栀抬头：“谁授权？”

“避免他们把问题集中到你身上。”

“这不是授权。”

陆衍停住。

他想替她挡掉最消耗人的部分，这个动机没有恶意，甚至很熟悉。过去他们面对职业风险时，总有人更快一步站到前面。可顾念安案刚刚反复提醒他们：保护和替代决定之间，只隔着是否询问。

林栀看着他：“按正确流程重来。”

陆衍沉默一秒。

“要我处理，”他说，“还是只陪你？”

问句落下后，他没有加任何倾向。

林栀原本已经准备好反驳。如果他说“我替你处理”，她会指出自己不是需要被隔离风险的客户；如果他说“你不用管”，她会让他重读共同主办权限。

可他真的问了。

选择权干净地回到她手里。

她心里那套用于防御的完整论证突然失去对象，只剩一个比反驳更难说出口的答案。

“陪我。”

陆衍眼神很轻地变了一下。

没有得意，也没有趁机要求她定义“陪”的范围。他只问：“位置？”

“采访区侧后方。对外说明由我说，你只补充一般公司程序问题。任何客户事实都不增加。”

“明白。”

“不替我挡话筒。”

“除非出现人身风险。”

“可以。”

“不代答私人关系。”

林栀看他：“有人问，你可以自己决定答不答。”

“这是新增授权？”

“这是你的权利。”

陆衍没有再问。

下午三点，律所在小型采访区作简短说明。

林栀只讲三件事：财产保全是依法申请、由法院审查的程序措施，不等于实体权属已经认定；企业经营、登记股权、婚内收益与共同投入对应价值需要分别核验；律师不会披露当事人隐私，也不会用媒体代替程序裁判。

记者追问：“程先生一方称你们的申请已经影响融资，这个损失谁负责？”

“任何程序措施都有法定条件和相应责任机制。”林栀说，“具体案件中是否存在损失、原因和责任，需要依据证据判断，不适合由任何一方在镜头前先作结论。”

“你们是不是利用离婚争议逼企业让步？”

“当事人的合法财产请求不会因为涉及企业就自动失去审查资格，企业利益也不会因为对方是配偶就自动不受保护。我们的工作是把两者都交回法律程序。”

陆衍始终站在她侧后方。

他没有抢过话，也没有在记者连续追问时向前一步。只有一支话筒几乎碰到她肩侧时，他抬手示意对方保持采访线，动作停在公共空间，没有触碰她。

林栀知道他在。

这种知道没有削弱她，反而让她可以把全部注意力留给问题本身。

最后，有记者问：“陆律师为什么全程陪同？你们只是业务合伙人吗？”

采访区安静了一瞬。

陆衍看向林栀。

他没有等待她替自己定义，也没有借镜头发动私人回合。

“今天我以共同承办律师身份在场。”他说，“其他问题与客户程序无关。”

答案完整、克制，没有退回，也没有越界。

说明结束后，两人一前一后离开采访区。直到会议室门关上，林栀才问：“只陪我，感觉如何？”

“比替你决定难。”

“后悔？”

“没有。”

“为什么？”

“因为你选了我留下。”

林栀的呼吸轻轻停了一拍。

陆衍说完便去整理采访记录，没有追问这句话是否构成得分。真实选择不该被立刻兑换成战果，他显然明白。

晚上，团队回到程启明的书面说明。

对方同时提交了PDF和可编辑文档，称后者便于核对引用。周屿按流程保存原件，在检查文档常规属性时发现，“最后保存者”不是程启明，也不是对方代理律师。

账户名称是`WT-Consult`。

文档公司字段写着“恒策企业服务”。

周屿检索公开信息。恒策企业服务正是衡序供应商名录中的合作机构之一；其负责人温拓，多次以“衡序合作顾问”身份出席公开论坛。

文件属性只能证明某个使用该账户的环境编辑过文档，不能确认编辑者本人，更不能证明衡序指示程启明作出虚假陈述。

可“完美证词”的整理过程，第一次与衡序合作网络产生了直接文件痕迹。

周屿把属性页面投到屏幕上。

最后保存时间，是程启明提交说明的前一晚十一点四十八分。

二十六页滴水不漏的回答，显然不只来自丈夫一个人的记忆。
