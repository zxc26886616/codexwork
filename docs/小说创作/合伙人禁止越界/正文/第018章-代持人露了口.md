# 第18章 代持人露了口

周屿的移动端访问没有异常。

第二天上午，在他确认检查清单并由一名不参与顾念安案的同事见证后，技术支持只核验了工作应用的登录、文件缓存和外发记录。七分钟访问期间，方案B在案件应用内停留，没有截屏、下载、复制或切换到通讯软件。工作手机也没有连接陌生投屏设备。

“可以证明不是我了吗？”周屿问。

“可以证明这次移动访问没有发现外发行为。”沈念说，“不能把一个窄检查包装成对你所有行为的全面清白证明，也没有必要。”

周屿沉默两秒：“听起来不够痛快。”

“但准确。”

“我知道。”

他把手机拿回去，没有要求团队给自己出一张“无泄密证书”。被怀疑的感觉仍然不好，可所有人都按事先划定的范围检查，没有翻他的私人聊天，也没有用匿名邮件迫使他交出整个生活。

这种不够痛快的准确，至少让他仍愿意坐回同一张桌边。

匿名邮件被标记为“来源不明、内容部分可由外部材料推测”，暂不作为泄密结论。方案B继续保留，新增访问需由沈念审批。

沈念同步调整了会议规则。方案B不再出现在开放会议室的大屏，讨论时使用事项编号，不在公共日程标题里写目标财产。调整不是为了营造秘密行动，而是把尚未成形的策略限制在必要范围。

“会不会显得我们已经认定有人偷听？”周屿问。

“不是针对某个人。”沈念说，“匿名邮件提醒了一个客观问题：以前我们默认会议室、移动端和日程标题都属于同一安全层级。现在把层级重新划分。”

“前台还能知道我们在开顾念安案的会。”

“案件名称不是秘密，客户身份和具体策略是。”

“那夜宵订单呢？”

“不需要代号。”

陆衍看了一眼林栀：“固定口味也不需要？”

林栀把会议规则翻到下一页：“职业双关限频。”

“这是生活事实。”

“不属于本次审查。”

周屿发现他们还能为粥的口味争一句，心里的紧张反而减轻。真正的信任不是所有人假装没受影响，而是在受影响后仍能把规则说清，不让每一次沉默都变成怀疑。

“接下来查什么？”周屿问。

林栀把程启川会谈纪要放到屏幕上：“重新看他说过的话。”

“我们已经复核两遍。”

“前两遍在找他答不出的内容。这次只找他主动使用的时间词。”

会议纪要共十二页。程启川无法准确说明主营、董事和收益数额，却对代持、结算和家族安排给出过一套反复练习的解释。团队此前注意力都集中在这些明显矛盾上，几句过渡话因此被当成普通口语略过。

林栀从第一页开始读。

“一直”“早就”“后来”“每年”“现在”。

每个时间词都被单独标出。

读到第九页时，她停住。

那一段发生在会谈后半程。程启川解释三百六十万元转款时说，兄弟之间每年都会根据公司情况结算，前几年怎么处理，今年也会照旧，只是顾念安突然申请措施，把正常安排复杂化了。

当时对方律师紧接着把表述修正为“历史资金往来仍需财务核对”，团队便把注意力转向凭证，没有继续追问“照旧”具体指什么。

“今年也会照旧。”林栀把这句话放大。

她让周屿调出那段会谈的完整前后文。

在这句话之前，程启川先说三年前的三百六十万元不是给程启明的个人分红，而是家族内部对历史收益的处理；对方律师补充，具体性质以财务材料为准。林栀随后问，后两年为什么仍在公司会议后出现相似转款。

程启川的原话是：“每年都要算，前几年怎么处理，今年也会照旧，本来就是我们兄弟内部的事。”

对方律师紧接着说：“程先生所称照旧，是指双方仍会根据实际经营情况协商，不代表存在固定支付义务。”

纪要同时保留了两句话。

“他不是被突然问出一个‘照旧’。”林栀说，“前面有明确对象：每年计算、前几年处理、今年继续。律师当场已经做过限定，但没有否认存在重复处理。”

唐澄把三个层级写到白板上。

第一层，程启川承认兄弟之间存在跨年度的收益计算或协商；第二层，是否形成固定回款义务不明；第三层，历年实际怎么付，必须看账户和会计凭证。

“我们能用第一层申请第二、第三层材料。”她说，“不能跳到‘弟弟承认替哥哥回流分红’。”

周屿把自己刚写下的“持续回款口误”删掉，改成“持续处理安排的口语表述”。

“标题一下不爽了。”

“正文可以爽，结论要准。”林栀说。

“那真正的爽点是什么？”

“对方准备了代持、赠与和咨询三套解释，最后是一个普通时间词把它们同时拉进历年核验。”

周屿想了想：“这个确实更爽。”

他们又把三次关联转款逐年对照。第一年备注“分红”，第二年备注为空，第三年后续进入证券账户。金额不固定、间隔天数也不同，却都落在澄越重大会议后的短期窗口。

如果对方所说“每年都要算”属实，就应当存在计算依据；如果只是不定期协商，就应当存在协商结果；如果钱与澄越无关，就需要解释为何时间长期重合。

无论选哪一种，都会留下相应的材料类型。

周屿皱眉：“这能证明什么？”

“先不说证明。问它预设了什么。”

陆衍看向时间线：“预设存在一个跨年度重复行为。”

“而不是三年前一次性的赠与交付。”唐澄说。

如果三百六十万元只是协议签署前后的一次历史结算，“今年也会照旧”便没有明确对象；如果兄弟之间一直按某种方式把澄越相关收益转到程明启一侧，这句话才自然。

“程明启？”周屿看了一眼屏幕，“是程启明。”

林栀手中的笔停住。

她刚才在便签上把名字写颠倒了。连续工作和注意力高度集中让这个极少出现的错误暴露得很快。

陆衍把她的笔拿走：“先休息五分钟。”

“不影响结论。”

“影响姓名。”

“我可以纠正。”

“五分钟后纠正。”

林栀想反驳，看到周屿也在看她，只得起身去接水。

陆衍没有趁机接管问题。他把屏幕停在原句，等她回来。

五分钟后，林栀重新坐下，把错误便签撕掉，完整写下：程启川使用“今年也会照旧”，可能指向持续、重复的结算或回款安排，具体含义需由本人说明并结合历年流水核验。

“不能直接写承认持续回款。”唐澄说。

“对。先问‘照旧’指什么，再把回答和三次关联转款对照。”

团队给对方发出书面核验问题：程启川所称“今年也会照旧”的对象、频率、计算方式、履行主体及相关凭证分别是什么。

问题发出后不到二十分钟，对方律师来电。

“程先生的口语表达不严谨，所谓照旧只是指家族内部继续协商，不构成对固定回款安排的承认。”

林栀开着免提：“我们接受你方补充解释，请书面确认。仍请说明历年协商结果和相关资金处理。”

“你们是在从普通措辞里制造不利口供。”

“我们引用完整上下文，并允许当事人说明。最终意义由材料核验，不由单句决定。”

电话结束。

周屿说：“他们回得太快了。”

“快不是问题。”陆衍说，“重点是他们没有否认存在历年协商，只是否认固定回款。”

“那我们赢了？”

“我们得到一项更具体的核验对象。”林栀说。

陆衍看着她：“这场证词战，你赢了。”

会议室安静一瞬。

他说得平静，没有把功劳分散成“团队共同发现”，也没有因为自己先指出时间预设就抢走判断。最早决定换角度重读的人是林栀，抓住那句话并限定证明边界的人也是她。

“你再说一遍。”林栀道。

“需要进入复盘？”

“私人回合预演。”

陆衍眼底很轻地一动：“案件可以，其他免谈。”

“为什么？”

“避免你提前适应胜利措辞。”

“你这是预防性防御。”

“不计分。”

“我还没说要计。”

“所以提前说明。”

林栀拿起笔，在自己的便签角落写下“被观察人对私人认输存在预防性反应”，没有记入《非业务风险台账》。案件紧张期，正式比分仍然冻结。

“你写了什么？”陆衍问。

“内部数据。”

“是否允许申请查阅？”

“不允许。”

“那我保留异议。”

这段对话只持续了不到一分钟，却把匿名邮件带来的阴影推开一点。周屿低头整理材料，假装没有听见两位合伙人讨论如何为未来认输做预演。

中午，银行第一批正式反馈终于到达。

材料仍不完整，却确认了三年前三百六十万元转账前，程启川账户曾收到启禾同额资金；启禾此前数日又收到澄越一笔金额接近的咨询服务付款。因手续费、税费和其他往来，金额并非完全一致，不能简单画成一条直线。

但上游第一次出现了可核验接口。

澄越到启禾，启禾到程启川，程启川到程启明。

团队把三段账户分别编号，不在表格上用箭头直接连接。

澄越向启禾付款发生在三月五日，金额三百八十万元，摘要为咨询服务；启禾三月九日向程启川转入三百六十五万元，摘要为股东往来；程启川三月十二日向程启明转入三百六十万元，备注分红。

金额每一段都减少，间隔分别为四天和三天。

“很像同一笔钱拆过去。”周屿说。

“像，但启禾同期还有其他收支。”陆衍打开余额表，“三月九日前后，公司账户里不只这三百八十万。无法做一一对应。”

唐澄核对咨询合同。合同约定年度顾问费上限四百万元，服务内容包括组织治理、供应商协调与数据项目管理，签署日期在付款前一年。形式上并非临时补出的空白合同。

“有服务成果吗？”林栀问。

“目前只交了两份月报，内容很薄，但不能因为薄就认定没有履行。”

“发票？”

“有，与三百八十万元对应。”

“税务处理？”

“等待正式材料。”

这条资金链因此比想象中更难。上游付款有合同和发票外观，中游被记为股东往来，下游又被个人备注成分红。任何一段都可以提出合法解释，三段连起来却需要一个能够同时容纳业务服务、股东资金和个人收益的故事。

“不要写资金洗转。”林栀说，“先申请核验启禾同期账目、服务成果和程启川股东往来依据。”

“方案B可以启动吗？”

“先核证券账户。”陆衍说，“一百二十万元转入有单独截图，确认来源和余额后再决定。车辆继续停。”

这一次，停止条件真正发挥作用。团队没有因为上游接口出现，就把所有消费都纳入申请；反而把证据最弱的车辆暂时留在调查区。

三段时间紧密相邻，款项名称却依次变成咨询费、股东个人资金和“分红”。

“要看咨询合同是否真实履行。”陆衍说，“也要看启禾同期有没有其他资金，不能默认同额就是同一笔。”

唐澄列出服务成果、发票、记账凭证和同期余额四类核验材料。

林栀则把“今年也会照旧”放到链条旁边。如果这样的路径不只存在一年，程启川的口误可能指向一种持续安排；如果今年没有相同付款，则对方“只是继续协商”的解释更合理。

下午三点，方案B进入可提交性复核。

现有材料对证券账户的接口最清楚，车辆仍缺权属和现状，其他高额消费只能支持调查。团队决定如果后续余额和风险条件满足，第二方向先聚焦证券及明确账户，不扩大到所有个人财产。

这是只有核心组知道的最新调整。

下午四点十一分，对方律师发来一份书面异议预告。

标题是《关于贵方拟就证券账户及车辆申请追加措施的意见》。

正文不仅准确写出证券账户和车辆，还写道：“贵方试图以一百二十万元历史转入记录为由，将正常个人投资包装为所谓收益回流，并拟在车辆权属尚未核实前申请控制。”

会议室里没人说话。

一百二十万元、证券优先、车辆尚待核实。

前两项可以从已提交材料推测，最后一项却与方案B的停止条件和内部讨论高度接近。

这仍不能证明文件被复制。对方可能从法院沟通、担保核验、客户转述或团队问询顺序中拼出方向，也可能有人只泄露了一句“车辆证据不够”。信息路径不只经过案件系统，任何过早锁定个人的做法都会错过真正入口。

但与匿名邮件相比，这份正式文件提供了可核对的发送主体、形成时间和具体措辞。团队终于拥有一个能够反向询问“你方依据何种材料提出该项异议”的程序节点。

匿名邮件也许只是虚张声势。

这封由对方律师正式发来的文件，却准确踩中了他们尚未公开的第二套方向。

周屿慢慢抬头：“现在还只是推测吗？”

林栀看着邮件发送时间。

“现在，”她说，“可以正式审查信息路径了。”
