# 第37章 公约只写三条

陆衍站在冰箱前，把三条公约从头读到尾。

全文不超过四十个字。

没有得分标准，没有回合时长，没有靠近距离，也没有对“越界”作出一百种可以被律师争论的定义。

蓝色筹码被磁贴压在正中，像一个暂未启用的按钮。

“起草人解释一下。”他说。

林栀靠在岛台边：“字面解释。”

“‘开始’由谁确认？”

“双方。”

“如何确认？”

“当场问。”

“没有预先授权？”

“没有。今天愿意，不等于明天愿意；上一分钟同意，也不等于下一分钟不能停止。”

陆衍点了一下第一条：“自愿是否包括不因害羞主动逃离？”

“不包括。”

“为什么？”

“害羞不是义务。任何人都可以因为不想继续、不能判断或者单纯觉得气氛太糟而离开。”

“那私人攻防会长期停在开场。”

“你对自己的能力这么没信心？”

“我对对手的规避能力有客观判断。”

林栀笑了一下：“可以增加一项原则，不写进正文。”

“说。”

“不能把害羞伪装成拒绝，也不能把拒绝解释成害羞。听见停止信号时，先停；是否只是紧张，等双方退出当下情境以后再谈。”

“接受。”

“还有，不许故意用含混动作测试底线。”

“例如装醉？”

“那是既往违法样本。”

“尚未认定违法。”

“既往高风险样本。”

“可以。”

陆衍的视线落到第二条。

“说停以后，多久可以重启？”

“不能在同一情境里追问。先退回正常距离，等停止方主动提，或者至少等情绪和身体状态恢复稳定后再确认。”

“停止是否需要理由？”

“不需要。”

“是否影响计分？”

“不影响。停止不是输。”

“也不能被当成欠下一次继续？”

林栀抬眼：“当然不能。”

陆衍看着她：“建议把这句说完整。”

“停止不产生解释义务、补偿义务，也不构成下一次的预先同意。”

“接受。”

这场对话听起来像合同磋商。

却不是为了把亲密变得冷硬。

恰恰相反，只有退出权被说得足够清楚，靠近才不必依赖猜测。欲望不是许可，熟悉不是许可，曾经发生过也不是许可。任何一次停下都不会被记入失败，下一次开始也不会因过去而自动成立。

陆衍读第三条：“客户与健康永远优先。”

“顾念安案已经验证过。”林栀说，“客户发生紧急情况，私人回合立即冻结。酒后、发烧、药物影响判断、极度困倦，都不开新局。”

“一方只是普通疲劳？”

“主动说明。另一方不能替他判断‘还能继续’。”

“情绪受客户创伤影响？”

“同样暂停。不能拿客户经历影射、刺激或逼迫对方回答私人问题。”

陆衍想起她曾在顾念安决定是否调解时说“调解不是认输”。那句话只在客户离开、职业决定完成后才被她轻轻借用。即便如此，他也没有顺势把顾念安的选择套进他们之间。

“客户故事不作为情感论据。”他说。

“对。”

“职业权力也不作为私人筹码。”

“展开。”

“不能用主办权限、客户分配、公开评价或团队资源换取私人让步。”

林栀点头：“这条包含在自愿里，但单独确认。”

“共同地址、钥匙和居住资源呢？”

“不能以收回或保留作为得分奖惩。”

“所以我赢了也不会自动得到主卧权限？”

“你今晚可以先得到玄关外的公共走廊权限。”

“威胁居住资格，疑似违反刚确认的原则。”

“纠正，是指出物理边界。”

陆衍唇角扬了一点。

严肃规则在他们手里仍然可以有笑意。笑意不削弱边界，反而让确认不必像一次危机处置。

林栀拿出手机，打开备忘录：“要不要把补充解释写进去？”

“不要。”

“理由？”

“写得越多，越容易把未列举的情况误解为允许。正文保留原则，实际情境当场确认。”

“与起草人意见一致。”

林栀还是把几个容易混淆的场景拿出来测试。

“一方主动靠近，但没有说话，算同意吗？”

“只证明主动靠近。下一步仍要确认。”

“一方没有后退？”

“不等于同意。可能是没反应过来，也可能是不想制造冲突。”

“笑了？”

“更不能单独解释。你在庭上听见对方说错法条也会笑。”

“耳尖红？”

陆衍看了她一眼：“属于生理反应，不能替代语言。”

“回答很有针对性。”

“问题也很有针对性。”

“如果一方嘴上反驳，身体却没有离开？”

“先听嘴上的。”

“如果说‘你猜’？”

“按没有同意处理。”

“如果说‘随便’？”

“同上。”

“如果明明想继续，却故意让对方猜？”

“猜错的风险由含混表达者承担。不能事后指责对方不够了解自己。”

林栀点头。

最后一句很重要。

他们认识太久，熟悉到可以从杯柄方向、邮件标点和呼吸停顿里读出对方情绪。可越是熟悉，越容易把判断当成授权。读懂一个人不是越过确认的许可证，判断正确也不能证明未经询问的下一步合理。

“还有一种。”陆衍说，“一方主动发起，进行到一半突然安静。”

“暂停，问是否继续。”

“对方说没事。”

“‘没事’不等于‘继续’。要得到明确回答。”

“如果对方嫌反复确认破坏气氛？”

“气氛不比安全重要。”

“确认方式可以自然，不必像宣读权利告知。”

“例如？”

“问‘可以吗’，或者停下来等对方主动。”

林栀挑眉：“你准备得很充分。”

“基础常识。”

“基础常识不包括把装醉设计成入住方案。”

“所以需要公约修正行为。”

他认得过分坦然，林栀反而没法继续追责。

她把那张曾准备写七条的草稿折起来，扔进碎纸箱。规则不是替他们制造更多话术，而是保证任何漂亮话术都不能绕过当下意愿。

“那为什么还问？”

“测试你是否想利用规则漏洞。”

“结论？”

“暂时合格。”

陆衍把视线移到蓝色筹码。

“它代表什么？”

“停止信号。”

“说‘停’已经足够。”

“有时人不想说话，或者需要更快结束。筹码放在两人都够得到的位置，任何一方拿起、推远或者敲桌，都视为停止。”

“颜色为什么是蓝色？”

“律所开业桌游剩下的。”

“我以为有心理学依据。”

“没有。红色太像警报，黄色像警告，蓝色库存最多。”

“理由非常务实。”

“而且显眼。”

陆衍取下磁贴，蓝色筹码落进他掌心。

林栀的视线跟着那枚筹码移动。

“你现在拿起，代表停止。”

“公约尚未生效。”

“签署方式呢？”

“还有待协商。”

“不需要签名。”林栀说，“口头确认即可。任何书面签署也不构成长期授权。”

“那现在确认？”

“先谈赌注。”

终于到了真正危险的部分。

前面三条是如何开始与停止，赌注则决定这场延续多年的攻防要走向哪里。

林栀把一张新便签放在岛台上：“总问题只有一个。”

“谁先告白。”

“谁先在清醒、自愿、没有外部压力的情况下，说出明确且不可被解释为友情、合伙或风险管理的爱意。”

“必须是‘我爱你’三个字？”

“不限定字面，但意思必须明确。”

“‘想和你长期共同生活’算不算？”

“不算。可能只是租住体验良好。”

“‘你是我唯一考虑的人’？”

“可能是合伙人遴选。”

“‘我所有未来安排都有你’？”

“遗嘱和紧急联系人也能做到。”

陆衍看着她：“解释权都在你？”

“双方均可提出异议，由说话者承担澄清责任。”

“也就是说，如果一句话有两种解释，就不算。”

“对。”

“胜者得到什么？”

林栀停了一下。

“败者承认先告白，不得通过‘口误’‘引用’‘案例讨论’撤回。胜者可以提出一项不违反公约的要求，对方有权拒绝。”

“有权拒绝的奖品，约束力很低。”

“人不是奖品。”

陆衍眼里的笑意慢慢沉下来，变得认真：“同意。”

“也不能要求对方公开关系、改变职业安排、共享财产或作任何不可逆承诺。”林栀补充，“这些必须另行决定。”

“不能要求同住？”

“已经同住，不属于奖品。”

“不能要求继续同住？”

“继续与否由双方持续选择，不能通过一次胜负锁定。”

“不能要求一个吻？”

林栀看着他。

陆衍的语气没有变，手指却在岛台边缘停住。

“不能。”她说，“可以提出，但对方当场重新决定。拒绝不影响胜负，也不欠补偿。”

“明白。”

“你把高风险选项问得很全面。”

“排除歧义。”

“还是预先评估收益？”

“两者不冲突。”

林栀耳尖一热，拿起水杯喝了一口。

陆衍没有继续。他问到边界，得到答案，便把视线重新放回筹码，像刚才那两个字只是一项普通示例。

可空气已经不再普通。

他们从大学认识到现在，曾在无数比这更近的距离里并肩看材料、交换座位、在人群中为对方挡路。那些靠近都有职业或环境理由。第一次把一个吻作为可能的未来选项说出来，即使下一秒就明确了拒绝权，也足以让身体比语言更早意识到危险。

林栀听见自己的心跳。

一下，两下，快得不符合一场规则讨论应有的节奏。

她没有把水杯当成掩护离开，也没有嘲笑他把问题问得越界。

因为他问的是“能不能要求”，而不是把某个结果当成已经获得。

她给了完整答案。

他完整接受。

欲望被放在边界之内，反而比含混试探更清楚。

“还有禁止事项。”林栀放下杯子，“不许为了逼对方告白，制造嫉妒、假装遇险、利用第三人或散布关系传言。”

“同意。不把无辜者当道具。”

“不许故意失联。”

“合理工作静默不算失联。”

“超过日常习惯且明知对方会担心，算。”

“可以。”

“不许装病。”

“我只装过醉。”

“同类行为一并禁止。”

“既往记录不应推定未来必然发生。”

“这是预防条款。”

“接受。”

“不许以输赢否定真实感受。先告白的人只是先说，不代表更爱，也不代表输掉关系。”

陆衍沉默了一瞬：“这句应该确认。”

“现在确认。”

“无论谁先说，另一个人都必须诚实回应，不能为了赢故意拖延。”

“同意。”

总赌注到此才真正安全。

他们赌的是谁先交出语言，不是谁更能让对方受伤，也不是谁更有资格获得爱。输赢可以成为笑点，诚实不能成为代价。

“另外，每一个有效回合可以记录一分。先让对方主动承认在意、想念、嫉妒、想靠近或其他明确私人意图，得一分。”

“分数决定最终胜负？”

“不决定。只做过程记录。”

“避免有人输掉告白后试图用总分翻案。”

“主要避免你。”

“我还没开始就被作出不利人格评价。”

“基于长期行为模式。”

“可以申辩吗？”

“下一回合用行动申辩。”

林栀在便签上画了两列名字。已有的亮灯回合中，陆衍让她承认害怕“把已经留下的都当成临时”，计一分；今晚她让陆衍承认装醉、想进门和想一起生活，是否计分仍有争议。

“三项陈述，至少一分。”她说。

“装醉是事实自认，不是感情攻防。想进门已在第一夜通过行为表达。想一起生活，是对你提问的事实回答。”

“全部试图排除？”

“我建议今晚不计分。”

“为什么？”

“这是把知情、居住和退出权说明白的基础确认。拿边界沟通计分，会鼓励人为了不输而继续含混。”

林栀的笔停在表格上。

她本来已经准备在自己名字后画一笔。

可陆衍说得对。

承认装醉、确认想留下、建立无期限居住安排，都不应该被变成谁赢了谁的战果。安全与真实是入场条件，不是得分项目。

她划掉空白记号：“今晚不计。”

“第一场正式回合从公约确认后开始。”

“同意。”

“私人记录不进律所系统，不让团队承担裁判职责。”

“同意。”

“未经双方同意，不在公开场合使用回合内容。”

“同意。”

“分数有争议时？”

“暂不记，不能为了取证重演。”

“同意。”

这些补充仍没有被写上冰箱。

它们只在两人清醒、无压力的夜里被逐项说出。陆衍甚至没有打开手机记录。林栀也没有拿出那七支录音设备中的任何一支。

“最后确认。”林栀说，“你理解三条公约，接受总赌注，也知道任何时点都可以退出？”

“理解，接受。”

“是否自愿开始？”

“是。”

“我也确认。”

公约生效。

蓝色筹码仍在陆衍手里。

他把它放到岛台上，用一根手指缓缓推向林栀。

蓝色圆片越过两人之间的中心线，停在她手边。

“什么意思？”她问。

“你离停止信号更近。”

“你不需要？”

“需要时，我会说。”

林栀看着筹码：“这是开局前示弱？”

“这是让退出权优先。”

她伸出指尖，把筹码推回去。

陆衍抬眼。

“放中间。”林栀说，“对等。”

筹码停在两人正中。

陆衍的手指没有立刻收回，指腹压在蓝色边缘。林栀的手也还停在另一侧，两个人的指尖隔着一枚筹码，没有相碰。

“现在要开始第一回合吗？”他问。

“你可以叫停。”

“我不叫停。”
