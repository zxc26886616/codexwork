# 第31章 模板编号

凌晨九分，周屿把两份文件投到会议室屏幕上。

左边是三年前那份没有签名的《家庭风险隔离建议》，页脚编号`HX-FR-230627-04`；右边是程启明一方刚发来的调解附件，编号`HX-FR-230627-09`。

相同的前缀，相同的日期，只差最后两位序号。

乍看之下，它们像一把钥匙的两个齿口，稍一转动，就能打开衡序藏在门后的东西。

周屿却没有转。

“我先说结论。”他把手从键盘上拿开，“能确认同属一套编号规则，不能确认同属一个具体项目，更不能仅凭编号证明衡序参与了程启明现在的谈判。”

唐澄抱着刚泡开的速溶咖啡，眉毛先皱起来：“这么谨慎？”

“不谨慎的话，明天对方只需要证明这是一套通用模板，我们今天说的所有话都会变成过度推断。”

林栀看着屏幕，没有催他给更刺激的答案。

周屿从公开信息讲起。

衡序家族事务中心过去四年参加过十几场行业活动，其中三场留下公开课件。课件里能找到`HX-FR`前缀，释义大概率是家族风险类文件；年份与日期的排列方式也一致。另有两份来自过往案件合法归档材料的文件，一份结尾是`02`，一份是`06`。内容并不相同：一份是合法的婚前财产清单，一份是家族企业授权建议。编号本身既不等于隐匿资产，也不等于违法方案。

“换句话说，”唐澄总结，“刀具厂生产了同一批刀，我们不能因为两把刀编号接近，就说它们都用来伤人。”

“比喻勉强及格。”周屿说。

“扣分点在哪儿？”

“刀具编号通常能对应生产批次。现在这组编号连批次能不能唯一对应都没有证据。”

唐澄端起咖啡：“我决定以后不在证据组面前使用比喻。”

沈念坐在靠门位置，低声提醒：“你上周也这么决定过。”

会议室里短暂地笑了一下。

连续多日绷紧的证据线终于允许人呼吸，但笑意没有越过客户的处境。林栀把两份文件各自缩小，露出周屿整理的比对表。

表格分成三栏。

第一栏是已经确认的事实：编号格式一致；日期相同；旧建议与本案资金隔离思路存在结构相似；调解附件保留了第09号页脚；恒策的温拓曾编辑程启明提交的说明文件，而恒策与衡序存在公开合作关系。

第二栏是合理待查的方向：04至09之间是否还有五个版本；版本由谁起草、向谁发送；调解附件为什么沿用三年前编号；程启明一方是否持续接受同一套服务。

第三栏只有一排红字：目前不能证明。

不能证明衡序指使转移二千四百万元。

不能证明启禾、北屿和明川均由衡序安排。

不能证明假委托来自衡序授意。

不能证明编号相连就意味着共同责任。

那一栏比前两栏更长。

林栀看了很久。

做律师最容易被外界误解的一件事，是“找到线索”与“得到答案”常常相隔很远。人天然喜欢闭环，尤其在已经看见一个足够像反派的名字之后。只要再把几处空白用动机填上，一张令人满意的全景图便会出现。

可证据不是为了让故事好看。

证据是为了让一个结论在对方最猛烈的质疑里还能站住。

她过去几天始终担心陆衍会追得太快。他对结构性漏洞有近乎本能的兴趣，一条设计精密的资产隔离链，对他而言比任何直白挑衅都更值得拆。贺闻川又恰好把话递到他面前，像故意在棋盘外摆了一枚新棋子。

林栀甚至提前准备好了阻止方案。

她会冻结与衡序有关的对外动作，会把所有未经核验的推论压回“待查”，必要时也会以案件负责人身份要求陆衍停止延伸调查。

陆衍却把屏幕上的比对表翻到最后一页。

“单独建档。”他说。

林栀抬眼。

“编号、公开合作关系、温拓编辑痕迹、假委托的技术来源，各自保存原始材料和取得路径。”陆衍说，“只记录事实，不画组织图，不把没有证据的线连上。”

唐澄问：“不继续追04到09？”

“留检索提醒。等新的合法材料自己进入视野。”

“这不像你。”

陆衍靠进椅背：“我平时是什么形象？”

“看到一扇锁着的门，会先论证撬锁行为的法律边界，然后站在边界外想办法让门自己倒。”

“评价基本客观。”

“所以这次为什么停？”

陆衍把顾念安的谈判清单移到主屏幕：“因为我们现在代理的人姓顾，不姓衡序。”

会议室安静下来。

“长期对手最擅长的，不一定是把证据藏干净。”他继续说，“也可能是让你看见一点刚好足够诱人的东西，逼你把时间、人力和判断全押在它身上。顾念安现在最需要的是补偿到账、价值披露和违约保障。我们若为了追一套模板，把她的执行窗口拖进衡序的叙事里，输的人不是衡序。”

他说完，点开归档命名栏。

项目名称没有写“衡序资产隐匿体系”，也没有写“系统性协助”。

只有八个字：关联模板线索，待核。

权限设为案件合伙人和证据负责人可见；材料与顾念安主案分别保存，交叉引用但不混同结论。

周屿当场生成校验值，登记来源。

“归档完成。”

一扇门仍然锁着。

他们没有假装自己已经进去。

林栀低头划掉笔记本上那条尚未开口的阻止方案。笔尖在纸面留下一小截墨痕，像一句准备得太充分、最终没有机会说出的反驳。

她本该只觉得省事。

可另一种更复杂的感觉先浮上来。

陆衍不是缺少赢下大局的欲望。他只是把客户的利益放在了自己想赢之前。这种克制比冲动更难，因为冲动可以归咎于性格，克制却意味着他清楚知道门后可能有什么，仍主动把手收了回来。

林栀忽然想起第一夜。

他明明有机会把装醉演到底，也有机会借她的纵容多走一步，最后却停在每一处可以撤回的位置。她一直把那归类为“高明的风险控制”，仿佛只要用职业术语命名，就不必承认其中还包含别的东西。

现在同样的动作又出现了一次。

不夺走客户的选择，不利用未经证明的线索，也不让更大的敌人替眼前的人决定节奏。

林栀合上笔记本：“同意单独归档。”

陆衍看向她：“只有工作意见？”

“你想听什么？”

“例如，陆律师今天表现出了罕见的成熟。”

“‘罕见’可以保留。”

“后半句呢？”

“证据不足。”

唐澄迅速低头喝咖啡，肩膀却抖了一下。

陆衍没反驳，只在自己的便签上写了一行字，推到林栀手边。

`对方已承认存在，成熟程度待核。`

林栀把便签翻过去。

背面是超市购物清单：鸡蛋、牛奶、咖啡豆、厨房纸，还有她昨晚随口说快没有了的垃圾袋。

一张纸同时证明了他在会议里争辩的能力和在她家赖着不走的准备程度。

林栀看了两秒，把“她家”这个定义从脑子里按回去。

共同地址仍在有效期内。

客房钥匙仍以“本案结束”为期限。

衣柜里的透明箱仍贴着陆衍的名字。

所有名词都准确，所有准确的名词又都在回避同一个事实：她已经习惯冰箱里有他买的东西，习惯凌晨会议结束后不必问他往哪儿走，也习惯有人在她准备早餐时把咖啡豆补进原来的位置。

她把购物清单收进口袋。

“垃圾袋买抽绳的。”她说。

陆衍眉梢微动：“这是工作意见还是共同生活指令？”

“风险控制要求。”

“依据？”

“你上次买的会漏。”

“接受整改。”

上午十点半，顾念安的视频会议开始。

她没有参加衡序线索讨论。团队只向她说明与本案直接相关的部分：对方附件与旧文件存在相同编号规则，可能有必要保留后续核查权，但现有证据不足以把衡序加入本次谈判对象，也不建议因此推迟当前方案。

顾念安听完，第一句话是：“如果以后证明他们故意漏了东西，我今天签的协议会不会让我不能再追？”

她关心的不是幕后名字有多大，而是自己的权利会不会再次被一张纸拿走。

林栀打开最新条款：“我们把和解范围限定为清单内充分披露的事项。对故意遗漏、虚假陈述以及协议签署时合理无法发现的重大资产，保留依法主张的权利。”

“什么叫充分披露？”

“这是今天要继续谈的重点。”

对方最新版本写着：程启明一方将“安排相关主体提供其所知范围内的资产信息”。

一句话里有三层退路。

“安排”不等于确保；“相关主体”没有名单；“所知范围”可以把任何缺失解释成不知道。

陆衍把句子拆给她看：“我们建议改成明确主体、明确表格、明确确认人。披露对象至少包括程启明、程启川、澄越、启禾、北屿与明川；范围包括股权、收益、往来、代付和对外投资。谁提供，谁签名确认。”

顾念安沉默了一会儿。

“公司盖章够吗？”

“通常能形成一层责任，但你可以要求法定代表人或实际经办人一并确认。”

“程启明会说他不是股东，也不是那些公司的负责人。”

“所以需要把他的个人确认义务单列。”林栀说，“他确认的不是自己形式上拥有全部资产，而是确认已经披露其直接或间接享有、控制、指定使用，或者由关联主体代为支付的利益。”

顾念安看着条款，没有立即表态。

屏幕里的她比第一次来律所时安静许多。那时她每问一个问题都要先证明自己不是为了钱，仿佛只有否认物质利益，才能保住婚姻受害者的体面。现在她不再解释。

她会直接问钱什么时候到，股票怎么估，漏报以后谁负责。

这不是冷酷。

是一个长期被别人替她定义的人，终于开始练习使用自己的判断。

“我还有一个担心。”她说，“他们会不会给我一张几十页的表，最后说是财务做的、律师做的、弟弟做的，他本人没看过？”

“会有这种风险。”唐澄回答。

“以前公司的事情，他总说自己不知道。可要买车、买保险、付家里的钱，他又都知道。”顾念安的声音没有提高，“我不想再听一句‘下面的人办的’。”

陆衍没有急着替她把愤怒翻译成法律条款。

林栀也没有。

他们等她自己把话说完。

“我可以接受不是所有资产今天都查清，也可以接受分期。”顾念安说，“但每一份披露不能只盖一个我根本不认识的公司章。我要他们两个人亲自看过，亲自确认。以后少了什么，不能再推给财务。”

林栀问：“你说的两个人，是程启明和程启川？”

“对。”

“即使程启川主张部分事项与他无关？”

“那就让他在具体项目上写无关和理由，不要用一张总表糊过去。”

林栀把她的要求逐字记下。

它可能增加谈判阻力，也可能让对方缩减愿意披露的范围；个人确认不等于将来一定能证明故意隐瞒，更不自动产生所有法律后果。这些限制，她一项项向顾念安解释。

顾念安听完仍然说：“加。”

“确认可能因此延长谈判？”

“确认。”

“确认不把个人签字理解为绝对保证，只作为披露责任和后续核验基础？”

“确认。”

“好。”

林栀新建条款。

没有替她拔高，也没有替她软化。

屏幕上，文字一行行出现：

`本协议所附资产及利益披露表，应由程启明、程启川分别就其知悉、控制、经办及受益范围进行逐项核对并亲笔确认；任何主体盖章、代理人签署或经办人员说明，均不得替代前述个人确认。对声明无关或不知悉的项目，应列明具体理由。`

顾念安读了两遍。

“最后再加一句。”

林栀停下键盘：“你说。”

“任何补充披露，也一样。”

“可以。”

她在条款末尾补上适用范围。

这一次，顾念安没有问他们觉得该不该坚持。

她只说：“就按这条发。”

中午十二点零三分，反建议送出。

十二点十七分，对方律师回了一条消息：个人确认范围过宽，程启川不会为程启明的个人受益负责，程启明也无权确认独立公司的全部经营事项。

顾念安还在线。

她读完没有像从前那样立刻问“是不是我要求太多”。

“他们又把两件事混在一起了。”她说，“我没要求弟弟替哥哥负责。我要求每个人确认自己知道的部分。”

林栀没有掩饰眼里的赞许：“对。”

“那就告诉他们，可以按主体和项目拆表，但不能取消个人确认。”

“这是新的谈判授权，我们记录一下。”

顾念安在镜头前完整复述了授权范围。沈念制作会议纪要，发给她本人核对。她回复“确认”时没有附加任何解释，也没有为自己的坚持道歉。

陆衍关闭对话框：“他们下一步大概率会接受签字，但要求把责任限定为‘截至签署日实际知悉’。”

“能谈吗？”顾念安问。

“能谈知悉标准，不能让它变成随口一句不知道。”林栀说，“可以要求他们说明为确认所做的核查，包括询问谁、调取哪些账目。签字不是魔法，核查过程才让它有分量。”

顾念安点头：“那就继续拆。”

她说的是条款，也是过去十年里别人替她打包好的一切。婚姻、公司、家庭和利益曾被塞进一句“你不用管”里，如今她把它们一件件拿出来，问清名称、归属和后果。

衡序的编号被封进独立档案，暂时没有抢走任何人的结局。

而顾念安在自己的最终方案里，第一次要求每一个试图躲在公司、弟弟与经办人身后的人，都用自己的名字确认答案。
