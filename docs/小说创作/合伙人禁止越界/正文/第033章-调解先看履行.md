# 第33章 调解先看履行

正式签署安排在第二天上午十点。

九点四十五分，顾念安已经到了。

她没有问签在哪里，也没有问对方会不会临时反悔。她坐下后的第一件事，是把昨晚的框架翻到付款附件。

“监管账户信息再核一次。”

沈念把银行出具的账户确认、监管协议与收款用途说明逐项摆开。户名、账号、开户行、用途、释放条件，共五处需要核对。

顾念安自己念了一遍账号，又拿手机里的银行页面逐位比照。

过去，她会因为这样显得不信任别人而不自在。今天没有。

一个人被“你不用管”挡在自己的财产之外太久以后，重新学会核对并不是多疑，是把判断权拿回来。

十点零八分，对方到场。

程启明仍未亲自出现，程启川也没有来。代理律师带来了两份已经签名的个人确认承诺，表示正式披露表将在首期款支付时一并提交。

顾念安看见那两个熟悉的签名，手指停了一下。

林栀没有问她是否需要休息，只把文件推到她可以看清、又不必立刻触碰的位置。

“签名目前只证明他们接受核查和确认义务。”她说，“不代表披露已经完成。今天签框架，仍然要等款项和表格。”

顾念安点头：“我知道。”

对方律师却说：“双方既然签署调解文件，希望顾女士今天同步申请解除现有全部措施。这是基本互信。”

会议室里的空气像被一句“互信”压紧。

陆衍翻到第七条：“文本写的是首期款进入监管账户、基础披露提交并经形式核验后，申请调整附件列明的特定措施。没有‘今天’，也没有‘全部’。”

“框架签署本身已经说明程先生愿意解决。”

“意愿不是履行。”

“陆律师坚持得太僵，会影响后续合作气氛。”

“监管账户不会因为气氛良好自动增加余额。”

对方律师脸色微沉。

唐澄在记录页上写下时间，没有抬头。林栀则把争论重新放回条款：“如果贵方认为顺序需要调整，可以提出新方案并说明等值保障。否则按已确认文本执行。”

“程先生的公司和个人信用足够构成保障。”

顾念安看向对方：“如果足够，他把钱付进监管账户就不难。”

她的声音不大。

对方却没有立刻接话。

这不是顾念安第一次坐在程启明的律师对面，却是她第一次没有通过自己的律师转述。她不再试图证明自己温和，也不再担心一句直接的质问会不会让调解失败。

失败若来自对方拒绝履行，不是她说话太硬。

双方最终按原文本签署。

签字过程没有音乐，也没有影视剧里尘埃落定的长镜头。每页骑缝、附件编号、签署权限和时间都要核验。电子文件生成后，周屿保存原始版本与校验记录；纸质文本分别封装，监管银行收到生效条件通知。

对方律师在离场前再次提出，希望当天对外发布联合说明。

林栀拒绝：“等首期义务完成。”

“说明与付款没有直接关系。”

“在本协议里有。”

对方律师把文件夹合上，又换了一种说法：“至少可以先通知公司员工，争议已经解决。持续的不确定状态会影响经营。”

“可以通知已经形成附条件框架，正在履行。”林栀说，“不能通知争议已经解决。”

“只是内部措辞。”

“内部措辞也会形成事实外观。员工转述、客户询问、融资尽调都可能引用。阶段到哪里，就写到哪里。”

陆衍补充：“贵方如果需要现成文本，我们可以现在提供：双方已形成阶段性安排，相关义务正在履行，现有程序状态不因框架签署自动改变。”

对方律师显然不喜欢最后半句：“没必要强调程序状态。”

“那就只保留前两句，但不能使用‘已圆满解决’。”

顾念安一直听着，忽然问：“你们这么急着说解决，是因为钱还没付，还是因为公司明天有事？”

对方没有回答公司日程，只说企业需要稳定预期。

周屿立刻记下这句话，准备核对澄越近期公开事项。林栀没有把会议变成临时审讯，也没有利用猜测施压，只重申通知边界。

离场前，对方最终带走了两句中性文本。

顾念安望着关上的门：“以前他每次说已经处理好了，我都以为事情真的结束了。”

“对外宣布结果，本身也是一种控制节奏的方式。”陆衍说，“所以这次结果由客观节点决定，不由谁先命名。”

门关上后，顾念安长长吐出一口气。

“签完了。”她说。

没有人告诉她“结束了”。

林栀把待办表翻到下一页：“现在开始看履行。”

第一项，首期款须在两个工作日内进入监管账户。

第二项，基础披露表应同时提交，不得以公司内部审批为由延期。

第三项，到账与表格只完成触发条件的一部分，团队还要核验付款主体、款项性质和披露形式。若付款来自未经说明的第三方，可能制造新的债务或追偿问题；若表格缺少个人确认，也不视为完成。

第四项，只有以上内容通过基础核验，顾念安一方才申请调整清单中的部分措施。其他措施随评估与第二期补偿分阶段处理。

顾念安看完：“所以签字不是结案。”

“签字是把将来要做的事变成可检查的义务。”陆衍说。

“如果他们不做？”

“按违约路径继续，不替他们把承诺想象成结果。”

顾念安笑了一下：“我以前最擅长的就是把承诺想象成结果。”

林栀没有顺着评价她过去的婚姻。

“现在不用了。”她只说。

中午，案件管理系统自动生成“拟结阶段任务”。其中一项是回收临时出入授权，另一项是归档共同地址安全安排。

沈念发现后，把页面转给林栀：“系统按签署时间触发的，要不要先关？”

林栀视线在“临时出入授权”上停了半秒。

“统一延后。”她说，“履行条件没完成，案件状态不改成办结。”

“包括钥匙类实物登记？”

“包括。”

她回答得平稳，像这只是归档规则。

陆衍坐在对面，正在检查付款主体限制。他听见了，没有抬头，也没有用任何一句话提醒她客房钥匙的期限。

林栀反而生出一点不合时宜的警觉。

他太安静了。

按照他们过去几天的相处方式，系统把“回收临时授权”递到眼前，足够他设计至少三种问题。比如案件以签署还是履行为结束，比如签发人是否有权单方延长，比如共同生活风险是否需要连续控制。

任何一个问题都能把她逼到钥匙去留上。

他却只在付款附件上标出一句话：“首期款不得来源于顾念安依法可能承担共同清偿责任的新增借款。”

“补这一条。”他说。

林栀看着他：“你没有其他意见？”

“关于付款主体，有。”

“关于系统任务。”

陆衍这才抬眼：“系统任务怎么了？”

“提示回收临时授权。”

“你已经延后，处理合理。”

“如果我没延后呢？”

“那就按原期限执行。”

他说得太干脆，林栀心里那点警觉反而变成一根细刺。

“陆衍。”

“嗯？”

“你在装不在意？”

他的目光落在她脸上，没有躲。

“我在区分客户履行节点和私人谈判节点。”

“翻译一下。”

“顾念安什么时候拿到钱，不该成为我逼你决定钥匙去留的计时器。”

会议室外有人经过，玻璃上掠过一道影子。

林栀指尖停在触控板边缘。

她忽然明白，他不是没看到机会。

恰恰是看见了，才主动不用。

只要他现在提起“本案结束”，她就会在客户履行尚未稳定的时候，把一部分注意力交给他们之间的期限；而无论她选择收回还是保留，那个选择都会沾上首期款是否到账的偶然性。

他不允许客户成为他们的钟。

也不允许自己的居住资格成为催促她的工具。

这种克制没有昨晚厨房里的玩笑好应付。玩笑可以反击，沉默却把决定权原样放回她手里，连一丝被迫的借口都不给。

林栀心口微微发紧。

“案子结束后，你也不问？”

“会问。”

“什么时候？”

“你不需要在客户款项提醒和钥匙期限之间二选一的时候。”

“你对提问时机要求很多。”

“关系证据也要排除不当压力。”

林栀想说他又把感情包装成证据规则。

话到嘴边，却没有说。

因为她知道，那不是包装。

是他真的愿意等她在没有任何外部倒计时的时候回答。

她移开视线，把新增付款主体条款录入清单：“批准延后。”

“哪一项？”

“所有不属于客户履行的提问。”

陆衍点头：“收到。”

他嘴角没有明显上扬，只是重新低头看文件时，手里的笔转错了半圈，笔帽落在桌面。

林栀弯腰捡起，放回他右手边。

两人的手没有碰到。

距离却比碰到更清楚。

接下来的两个工作日，团队没有停在等待里。

周屿制作披露核验矩阵，把六个主体、十二类账户和已经取得的付款审批逐项对应；唐澄准备措施调整申请的两个版本，以便根据履行完整程度决定释放范围；沈念每天上午十点和下午四点向监管银行核验，不通过客户反复追问账户余额。

第一天下午，对方说银行限额需要内部审批。

团队回复：付款期限不变，如需分笔，应提前提供路径且不得改变资金性质。

同一天晚上，顾念安转来程启明的一条私人消息。

`都已经签了，你还要把账户卡到什么时候？公司如果因此出问题，最后损失的也是你和孩子。`

她没有回复，先问团队这是否影响框架。

“消息本身不改变条款。”林栀说，“保存原始记录。你是否回复由你决定，我们可以说明不同选择的影响。”

“我不想跟他吵。”

“可以不回。”

“不回会不会显得我没诚意？”

这句话问出口后，顾念安自己先停住。

她像听见了旧日的回声。过去每当程启明把公司的后果、孩子的利益和她的态度捆在一起，她都会立刻解释。解释自己没有要毁掉公司，没有要拿走不属于自己的钱，没有想让孩子失去父亲。解释得越多，对方越不必回答最初的问题。

这次她把手机放下。

“算了。”她说，“协议里写了什么时候调整。他知道。”

“好。”

“我不回复，不代表我拒绝履行。”

“对。”

“也不代表他消息里的后果要由我负责。”

“对。”

顾念安沉默两秒：“你们不用每次都说对。我是在练习自己确认。”

林栀笑了：“收到。”

通话结束后，陆衍把那条消息列入履行期联络记录，但没有把它夸大成威胁证据。语言里的压力需要结合频率、语境和后续行为判断，一条消息只先证明它被发送过。

林栀看他标注证据等级：“你今天很喜欢限制结论。”

“受你的长期影响。”

“观察期只有七天，谈不上长期。”

陆衍抬头：“签发人口供与客观生活状态矛盾。”

“哪项客观状态？”

“抽绳垃圾袋已经按要求采购，咖啡豆补充完成，第三只杯子进入稳定使用。”

“这些只能证明你有预谋地增加沉没成本。”

“也可以证明共同生活运行良好。”

林栀把他的屏幕转回履行记录：“私人提问仍在延后期。”

“这不是提问，是阶段汇报。”

她没接话，耳尖却被电脑屏幕的白光照得发热。

第二天上午，对方又提出先发布中性声明。

团队回复：按框架顺序执行。

中午十二点，顾念安发来一条消息：“他们是不是又想拖？”

林栀没有用“别担心”敷衍。

她把事实写清：尚未逾期；已提出两个与原顺序不符的要求，均被拒绝；监管账户目前未到账；团队将在期限届满时立即按约定处理。

顾念安回复：“好，我等你们的事实。”

下午三点五十八分，银行提醒终于出现。

首期款分两笔进入监管账户，付款人均为程启明本人。金额与协议一致，附言注明本案调解首期款，不含借款或代付款性质。

沈念核验回单，监管银行确认资金已实际入账且不存在当日可撤回安排。

顾念安接到通知后安静了十几秒。

“真的到了？”

“真的到了。”林栀说，“但我们还要看同时提交的披露表。”

“先看。”

她没有被到账提醒冲昏判断。

四点零七分，对方邮件抵达。

附件共三十二页，程启明、程启川均有签名。澄越的股权和审批权限、启禾的收付款、北屿的专项往来、两人的个人账户摘要都列在表中。每一页形式完整，签章齐全，连“不知悉”的理由栏也填得工整。

唐澄迅速对照主体清单。

第一遍看到第五项时，她的手停住。

“少了一家。”

周屿已经调出此前取得的邮件和付款审批。

那封由北屿询问、QCM账号回复的邮件仍清清楚楚：

`照旧，走明川往来，不进我个人报销。`

而刚提交的三十二页披露表里，没有“明川管理”四个字。

对方付了第一笔钱。

也在同一时间，漏掉了最能解释个人费用如何绕开个人报销的那家公司。

到账是真的，遗漏也是真的，任何一项都不能替另一项消失。
