# 第20章 雨幕与责任页

新客户登记名为“陈珂”。

手机号码可以接通，却始终无人接听；问卷所填公司名称查不到公开登记，身份证明也没有进入正式委托阶段，因此前台没有收取。唯一经过格式校验的是邮箱，地址创建时间无法从普通公开信息确认。

团队没有继续拨打，更没有假装回访发送追踪链接。

“先听与异常问题对应的片段。”林栀说。

沈念打开咨询系统。录音前有标准告知：本次初谈用于冲突检索和需求评估，将按律所规则限制保存；来电人明确同意。

前十分钟很普通。

“陈珂”称配偶准备转让一家小公司股权，自己担心财产消失。前台询问时间窗口、登记状态和已有材料，对方回答模糊，却不断把问题抛回来。

“如果只剩六小时，你们第一步会查什么？”

“没有银行流水也能申请吗？”

“车辆照片不够的话，是不是先查证券？”

“担保材料通常什么时候准备？”

“第一次申请没覆盖的财产，你们会不会马上做第二套？”

单看任何一句，都像一个焦虑的潜在客户在了解服务。连起来，却几乎完整走过顾念安案前十几章的决策顺序。

负责初谈的前台没有透露客户事实，只按一般流程回答：需要结合具体证据评估，不承诺措施结果；可能先固定时间窗口和明确财产，再依法申请调查；车辆、证券等均需核验权属和资金来源。

“他没拿到方案B。”周屿说。

“但拿到了判断框架。”沈念道。

专业问询进入周屿接手的第二段。

录音里的周屿先做冲突提示，再重复确认这只是初步交流，不构成正式法律意见。他没有说顾念安名字，也没有引用案件金额。对方却把情形越问越像：亲属代持、赠与协议、会议后回款、个人消费。

“你当时没觉得不对？”林栀问。

“觉得像常见的婚内财产转移咨询。”周屿脸色很差，“而且他说得很碎，每次只补一点。我以为他是不敢一次讲完。”

“这不等于你违规。”陆衍说，“先看你实际回答到哪里。”

录音播放到第二十一分钟，“陈珂”问：“如果对方已经猜到你们要追证券账户，下一步会怎么防？”

周屿回答：“我不能基于假设提供规避建议。如果你是担心自己的权利，应把真实材料交给律师评估。”

“那如果车辆证据不够，你们会暂缓吗？”

周屿说：“任何方向都要看证据，不能为了申请而申请。”

他没有说“证券优先、车辆暂停”。

可对方已经把这两个方向放进同一句话。

咨询记录至少证明，匿名邮件之前，有人通过正式入口反复试探相同策略。是否与程启明一方有关、是否由衡序或供应商安排，仍无证据。

“先封存这条咨询记录。”林栀说，“不联系对方指认，不对外说假委托。审接入来源、后续预约和录音完整性。”

话音刚落，沈念的手机响了。

律所楼下聚集了媒体。

程启明上午在澄越办公楼外接受采访，首次公开点名林衍所。他称顾念安在律师煽动下把正常家庭沟通升级为财产争夺，恶意申请措施影响企业融资和员工稳定；又称林栀、陆衍借所谓“明星合伙人”身份制造舆论压力。

视频已经登上本地热榜。

镜头里的程启明神情疲惫，身后有几名员工。他没有披露具体账户，却反复强调“公司几百人的饭碗”和“律师鼓励离婚”。

评论很快分裂。

有人认为企业家拿员工挡家庭财产问题，也有人质疑律所过度保全。更多人只截取“明星合伙人”和“两位律师共同生活”的传言，开始讨论案件之外的关系。

沈念没有让团队逐条看评论，而是做舆情分类。

第一类是可以纠正的程序误解，例如保全等于胜诉、申请等于法院照单全收；第二类是对顾念安动机的评价，除非她授权，不回应；第三类是企业经营和员工稳定的具体担忧，需要澄越自己以真实数据说明，律所不替公司证明也不反向猜测；第四类是两位合伙人的私人关系，与案件无关。

“最热的是第四类。”周屿说。

“热度不决定回应必要性。”沈念道。

“如果不答，记者会一直问。”

陆衍说：“一直问不等于有权得到答案。”

林栀看了一眼视频传播路径。程启明没有直接展示顾念安的隐私材料，却把家庭决定写成律师煽动，把企业损失预先归给申请方。若律所为了反击公开家庭账本、关联转款和父亲手术记录，短期可能赢得评论，却会让顾念安承担永久的信息代价。

“不以客户隐私换舆论优势。”她说，“所有回应都要能在删掉热榜之后仍然成立。”

团队把这句话放在对外说明首页，作为逐句审查标准。

顾念安打来电话时，声音发抖：“他把公司员工都叫来了。他以前每次都是这样，只要我问钱，就说我想毁掉所有人的生活。”

“你现在在哪里？”林栀问。

“家里。”

“门窗安全吗？有没有人联系或上门？”

“没有。”

“先不要看评论，也不要自己直播回应。我们会按你的授权处理程序误导，私人事实仍不公开。”

“可他说是你们煽动我离婚。”

“你的决定由你作出。我们只对接受委托后的专业行为负责。”

顾念安沉默几秒：“我授权你们说，我在来律所之前就已经决定结束婚姻，也已经发现股权变动。其他家庭细节不要说。”

“确认：可以说明委托时间和决定先后，不披露发现方式、金额与家庭记录。”

“对。”

团队记录授权。

林栀又向顾念安说明回应的风险：一旦确认委托先后，媒体可能继续追问她何时决定离婚、是否提前准备财产材料；律所会拒绝扩张，但无法保证外界停止猜测。

“我还是授权。”顾念安说，“我不想让他把我的决定说成别人塞给我的。”

“你可以随时缩小授权，但已经公开的内容无法收回。”

“我明白。”

林栀让她用书面消息再次确认，没有把电话里的情绪性回答当成无限许可。授权内容被限定为两句话，使用一次，不自动延伸到后续采访。

“为什么这么麻烦？”顾念安问。

“因为这是你的故事。我们只在你同意的范围里使用。”

电话那边安静片刻：“好。”

沈念建议发布书面回应，不接受失控围堵式采访。回应只包含四点：顾念安在正式委托前已自主作出婚姻决定；律所根据其授权提供服务；相关程序由法院依法审查，现有措施不等于实体权属结论；律所尊重企业正常经营，也不会以员工和舆论替代具体证据。

第一版回应写了八百字。

唐澄删掉所有可能让人反推出具体财产范围的句子；沈念删掉情绪化措辞和对热榜原话的逐项反驳；陆衍将“恶意指控”改成“相关评价缺乏已公开事实基础”；林栀则把“客户早已决定离婚”改为“在正式委托本所前已自主形成相关决定”，避免替顾念安说明过多心理过程。

最终稿只有三百二十字。

没有胜诉口号，没有展示证据，也没有一句可被截成对程启明的人身攻击。

“太克制会不会传播不动？”周屿问。

“我们不是公关公司。”林栀说。

“可对方正在用传播影响程序环境。”

“所以更不能给他们第二个议题。”陆衍道，“责任页不是战书，是以后每一句都能回看的记录。”

这句话使林栀停了一下。

责任页的意义不在今天看起来多并肩，而在以后若有事实变化、程序结果不利或客户质疑，两个人都不能说当时只是站在旁边。

“责任署名我来。”林栀说。

陆衍把文件拉到自己面前，在末页加上名字。

林栀看他：“这是对外责任页。”

“我知道。”

“声明主体可以是律所，不需要个人并列。”

“媒体点名两名共同承办人。既然事实判断和程序策略由我们共同完成，责任也共同承担。”

“你不必因为他们把你和我绑在一起，就配合叙事。”

“不是配合媒体。”陆衍说，“是记录真实分工。”

他没有说要替她挡，也没有问能否代她出面。只把自己的名字放到同一页，与她承担完全相同的措辞和后果。

林栀看着那一行签名栏。

前几天，她要求他先问“要我处理，还是只陪你”。今天他没有越过她的决定，却也没有把共同责任误解成站在侧后方就足够。

陪伴不是隐身。

尊重她主办，也不等于让她独自承担。

“位置往左一点。”林栀说。

陆衍看向她。

“签名并列，排版要对称。”

他把名字移动半格。

林栀没有阻止。

唐澄进行最后复核时问：“个人署名意味着如果措辞或授权边界出问题，你们共同解释。确认？”

“确认。”林栀说。

“确认。”陆衍说。

两人的声音同时落下。

没有人把这当成私人承诺。正因为它首先是一项真实职业责任，签名并列才比任何镜头前的称呼更重。

下午四点，律所发布授权范围内的书面回应。记者仍守在楼下，物业建议两位合伙人从地下车库离开。

林栀拒绝躲开：“正常出入。不接受追加采访，不展示客户材料。”

外面下起大雨。

一楼玻璃门打开时，闪光灯和雨幕同时涌来。保安拉出通道，记者隔着安全线追问。

“林律师，顾女士是不是被你建议离婚？”

“陆律师，你们是否利用保全逼迫程先生和解？”

“两位共同生活是否影响案件独立判断？”

林栀没有停下，只重复一句：“书面回应已经说明授权范围内的事实，客户隐私不作补充。”

陆衍撑开伞，站在她右侧。

雨从侧面压过来。他调整伞面，让大部分雨落到自己肩侧，却没有伸手揽她，也没有借拥挤触碰她的背。两人之间保持着可以独立行走的距离，步速却完全一致。

记者往前挤时，陆衍只把伞柄横向抬高一点，形成清楚的公共边界。

“责任声明为什么由你们共同署名？”有人喊。

陆衍回答：“因为是共同承办。”

“只是共同承办吗？”

他没有接私人问题。

林栀也没有。

镜头却已经拍到那一页公开声明。最下方，林栀与陆衍的名字并列，没有主次。另一张照片里，他把伞倾向她，她则没有往伞外退。

雨水从伞骨末端连续落下，在两人之间形成一道很窄的水帘。陆衍每次调整伞面都会先看前方通道，不借动作把她圈进怀里；林栀也没有因为镜头故意拉开距离。她只是按自己的步速向前，而他将边界跟着她移动。

这幅画面之所以被拍得像某种无声承诺，不是因为发生了触碰。

恰恰是因为所有人都看得见，他明明可以更近，却把距离停在她没有拒绝的位置。

车门关上，雨声被隔在外面。

陆衍左肩已经湿了一片。

林栀看了一眼：“伞可以居中。”

“风向问题。”

“风只吹你那边？”

“我站在迎风侧。”

“可以换位置。”

“你先走出门。”

“所以你就必须淋雨？”

“不构成必须。只是成本较低的路径。”

他连淋雨都要包装成路线优化。

林栀从车内储物格拿出一条干毛巾，递给他：“擦一下。”

“关怀是否计分？”

“客户危机期间不计。”

“那我接受。”

他没有故意把毛巾留给她动手，也没有用湿透的肩膀换取距离。只是接过去，安静擦掉雨水。

林栀心里那点无名的紧张随之松开。

有些人替你挡雨，是为了让你记住他站在前面。

陆衍不是。

他只是调整伞面，然后仍让她自己走。

回律所的路上，热榜上的短视频开始扩散。评论区有人截出两人的责任签名，也有人给陆衍的站位配字：“嘴上与客户无关，伞面非常诚实。”

周屿把截图发到工作群，又迅速撤回。

沈念回复：“私人评论不进入案件群。”

周屿：“收到。”

三秒后，他私发给林栀：“但传播效果很好。”

林栀没有回复，把手机扣下。

她耳尖有一点热，原因当然是车内暖气。

晚上六点，团队回到咨询流程审查。

媒体事件没有改变优先级。书面回应已经发布，顾念安安全状态稳定，私人攻防继续暂停。沈念核对“陈珂”咨询录音的文件校验和时间轴。

系统显示通话总时长二十九分四十二秒。

录音文件却只有二十五分三十九秒。

中间没有明显断点。文件在周屿回答“任何方向都要看证据”后继续了三分多钟，随后正常结束提示出现，像系统认为录音已经完整。

“少了四分钟。”周屿说。

“可能是通话保持、转接或系统延迟。”沈念没有下结论，“查原始通话日志和录音任务日志。”

技术支持调出时间戳。

最后四分零三秒，通话仍在进行，录音任务却提前停止。停止指令来源字段为空，不符合正常人工结束，也不符合系统超时。

那四分钟里说了什么，没有任何人能凭现有文件证明。

周屿努力回忆：“我记得他最后问过……问过我们什么时候会换第二套方案。然后好像有人进会议室叫我。”

“谁？”林栀问。

“想不起来。”

沈念打开当天的门禁和会议记录：“不要先猜。按时间核。”

雨还在窗外敲打玻璃。

桌上那份并列责任声明尚未收起，屏幕上却出现一个更具体的缺口。

假委托咨询录音，少了最后四分钟。
