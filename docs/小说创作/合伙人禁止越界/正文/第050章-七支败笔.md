# 第50章 七支败笔

“第一次。”陆衍说。

林栀挑眉：“职业生涯第一次败诉？”

“私人录音回合第一次被宣布败诉。”

“你对统计范围限制得很谨慎。”

“因为结果有争议。”

“没有人告白，主张方的目标没有实现。”

“被申请方同样没有实现反向目标。”

“我的目标是驳回你的指定陈述，已经完成。”

“你没有裁判权限。”

“录音最后一句是你说‘驳回’，构成自认。”

陆衍看了一眼熄灭的红灯：“那是驳回你的举证责任异议。”

“没有上下文支持你的解释。最后两分钟只有沉默、笑声和‘驳回’。”

“前段录音有完整上下文。”

“所以你承认这支设备同时证明你发起终局、未能完成？”

陆衍停了两秒：“建议封存，不作胜负认定。”

“败诉方常见请求。”

林栀笑着把录音笔放回桌面，没有擅自播放。

回合已经结束，接下来不是谁抢到设备谁拥有文件。录音内容同时属于两人的私人陈述，保留、复制和删除都要重新确认。

“是否保留？”陆衍问。

“保留原设备，不复制。”

“保存目的？”

“证明公约中的确认、暂停测试和停止都被执行，也保留第一场有录音回合的原始记录。”

“是否保留具体告白攻防内容？”

林栀想了一会儿：“文件无法拆掉中段又保持原始连续性。整体封存，不在后续回合引用具体内容。任何一方提出删除，再共同处理。”

“同意。”

“保管位置？”

“家里普通抽屉安全性不足。可以放进我办公室私人防火柜，双人封条。”

“为什么不是我办公室？”

“你随时可以选择。”

“放你那里。”

“确认不是把保管等同于单方使用权？”

“确认。”

陆衍拿出防静电袋和一次性封条。林栀检查设备没有联网同步，文件数量与时长对应，然后由两人共同把录音笔放进去。

标签栏很小。

“写什么？”他问。

“第一次败诉。”

“拒绝。”

“陆无说一号证物。”

“标签不得含评价性结论。”

“那你写。”

陆衍落笔：`01号双方知情回合。`

不写日期之外的私人主题，不写谁问了什么，也不写最终两分钟为何沉默。即使有人意外看见标签，也无法据此得知内容。

林栀在封条左侧签名，陆衍签右侧。

“一支用过。”她看向门外密封盒，“另外六支呢？”

“继续未启用。”

“你原本准备七支做什么？”

“战术冗余。”

“一场回合只用一支，够打七场。”

“设备可能故障。”

“也可能主张方连续败诉。”

“概率很低。”

“第一支已经形成样本。”

陆衍把其余六支逐一检查，全部保持出厂状态，没有任何文件。他没有为了反驳败诉立刻启用第二支，也没有宣布今晚再来一局。

林栀刚恢复，回合强度已经足够。

“今天到此。”他说。

“你主动停止？”

“结束后不立即重开，避免把情绪延续误当成新同意。”

“合格。”

“起草人是否需要再休息？”

“这不属于私人问题。”

“健康检查。”

“状态稳定，准备睡觉。”

两人把椅子搬回原处，蓝色筹码放回客厅。卧室恢复日常状态，床边桌不再像一张临时谈判桌。

林栀躺下后，心跳仍比平常快。

那句“说你爱我，这一回合我认输”留在记忆里，没有因为录音封存而消失。她反向要求示范，陆衍没说；可他也没有用玩笑撤回自己想听的事实。

两个人仍是零比零。

赌注却比开始时更清楚。

早上六点四十，林栀先醒。

她没有发热，睡眠也足够。经过客厅时，蓝色筹码仍在原位，旁边多了一张陆衍留下的便签：`01号封存完成，未记分。`

林栀拿笔补了一句：`主张失败，建议记败诉一次。`

早餐时，陆衍看见便签：“公约只有得分表，没有败诉表。”

“可以新增。”

“单方新增对我不利的统计，程序不正当。”

“你可以买七支录音笔，不允许我建一个败诉栏？”

“录音笔是设备，败诉栏是评价。”

“设备已经产生评价依据。”

“双方都没有实现目标，应记平局。”

“你发起回合，承担主要举证责任。”

“你反向要求示范，同样提出主张。”

两个人为一场无人告白的回合争了五分钟。

最终台账仍没有新增栏位。林栀把“建议败诉”折进便签背面，陆衍没有要求销毁，只写“异议保留”。

“为什么不再听一遍？”她问。

“没有必要。”

“你不想确认我沉默时有没有小声说话？”

“当时听见的是沉默。用设备放大呼吸寻找一句可能存在的词，不符合共同知情用途。”

“如果真有呢？”

“没有经过双方当场确认，也不能成为告白。”

林栀低头喝咖啡。

陆衍对“有效告白”的要求近乎固执。他宁可让一支录音笔成为败笔，也不从噪声里找胜利。

“那为什么保留？”

“因为暂停时红灯真的熄灭，恢复前真的重新确认，结束时你亲手关机。”陆衍说，“它证明我们制定的规则可以在想赢的时候仍然生效。”

“不是为了两分钟沉默？”

“沉默只是副产品。”

“你笑了。”

“被申请方也有明显笑意。”

“没有声音，无法证明。”

“我看见了。”

“主观陈述。”

“我保留记忆。”

林栀没有要求他忘掉。

他们封存的是设备，不是共同经历。录音不再引用，不代表那一晚需要从生活里删除。

七点五十五分，两人一起出门。私人设备硬盒由陆衍携带，封条朝上，途中没有打开。到律所后，林栀亲眼确认防火柜内没有网络设备和公共访问权限，双人封条编号录入私人清单，不进入案件系统。

“如果你办公室被检查？”她问。

“外盒没有内容说明，设备与客户证据分柜。任何依法需要处理的情况先通知你。”

“如果你离职？”

“先共同决定转移或删除。”

“如果律所解散？”

“同上。”

“如果我们——”

林栀停住。

“如果共同生活结束？”陆衍替她补全。

“对。”

“录音不作为挽留工具。共同处理后各自退出。”

“接受。”

最坏结果被说出来，没有让早晨变冷。退出安排清楚，反而使保留不再像一份隐形债务。

第二天早上八点半，法院补充通知到达。

审查人员要求在当日中午前补充两项：一是许棠母亲转达宋恺信息的原始过程与是否持续；二是儿童手表协管账号的权限、登录及与位置暴露时间的对应材料。

七十二小时节点只剩不到七小时。

私人回合自动冻结。

陆衍把封存袋与六支未启用设备装进不透明硬盒，带到办公室私人防火柜。外层总标签只写：`战术库存：7。已启用1，未启用6。`

林栀看见：“为什么把一号也计入库存？”

“总数连续，避免以后出现设备数量争议。”

“建议增加‘败笔1’。”

“拒绝。”

“保留异议。”

硬盒上锁。

九点，团队进入补证。

许棠母亲愿意说明联系过程，但第一句话仍是：“宋恺也是担心孩子，他没说要伤害谁。”

林栀没有要求她站队。

“我们只核对他联系了几次、说了什么、有没有询问位置，以及您向许棠转达了什么。”

“他给我打了三个电话，问小棠是不是在你们律所安排的地方。”

“您怎么回答？”

“我说不知道。他让我劝小棠把孩子送回去，说一直不上学会毁了小禾。”

“是否问过新住址？”

“问过。我真不知道。”

“有没有把许棠与您联系的时间、号码或其他信息告诉他？”

许母迟疑：“我说她凌晨给我发过一句安全。没说号码，还是原来的聊天软件。”

“后来呢？”

“他又说，只要她肯回家，之前的事情都可以不追究。”

这句话带有压力，却仍需按原样记录，不替许母解释成威胁。

许棠听完说明，选择把三个电话的通话记录、母亲转达的原消息和自己的“不回复”一起提交。她不要求母亲加入与宋恺的直接冲突，也要求后续不再向任何一方转发自己的上线时间。

“你愿意让我们给你母亲一份统一回复文本吗？”陆衍先问。

“愿意。但不要让她说我永远不见宋恺，只说现在通过律师联系。”

“好。”

他没有直接替她向许母下达全部封锁要求。

第二项更复杂。

越州取证团队发来初步说明。协管账号建立于手表首次激活当天，权限一直包含最后位置、安全区域通知和紧急联系人管理。过去三十日有十四次登录，其中五次发生在许棠明确要求停止定位之后。

服务商将“登录”和“位置查询”分开说明。

十四次登录里，有的只打开设备状态页，有的进入联系人设置，有的读取最后位置。不能把每次登录都写成实时跟踪，也不能因为不是每次都查询，就忽略账号持续拥有的控制能力。

安全区域通知则有三次触发。

一次是小禾离开学校常用范围，一次是进入青蒲路小区，一次是离开青蒲路。通知接收端包含当前主账号和那个协管账号。许棠此前以为关闭前台定位便会停止所有共享，后台设置却仍向协管端保留最后位置与区域事件。

“这是不是平台的问题？”许棠问。

“可能涉及提示和权限设计，也可能与首次设置时的授权有关。”周屿说，“现在先不把责任全部归给平台或个人。我们固定你看到的界面、服务规则和实际日志，后续分别判断。”

“我明明点了关闭。”

“你的理解很重要。”林栀说，“材料会写前台显示关闭、后台协管权限仍存在，两者不一致造成的实际风险。是否构成平台责任，需要更多规则和操作记录。”

许棠最不安的不是技术术语。

是她曾经以为自己已经关掉。

一个清楚显示为“关闭”的按钮，让她带着孩子走进新住处，也让她相信便利店是随机且安全的。后台管理员的存在，把这个选择建立的事实基础拿走了。

团队没有责怪她不懂设置。

普通用户没有义务在逃离危险时理解每一层服务后台。律师与取证人员要做的是还原权限，而不是把后果推给没有找到隐藏入口的人。

便利店暴露当晚，账号有两次查询。

第一次在母女离开青蒲路后七分钟。

第二次在进入便利店后四分钟。

时间高度对应。

但账号绑定的是一张企业通信副卡，实名主体不是宋恺个人，而是他任职公司的通信账户。服务商只能确认绑定尾号与登录设备标识，无法仅凭现有回函确定具体操作者。

“不能写宋恺登录。”周屿说。

“写企业副卡与其任职公司关联，具体使用人待核。”林栀说，“再把登录时间和消息发送时间并列，不下最终归属。”

后台记录还显示，保护申请受理后，协管账号再次登录过一次。

没有发起新的位置查询，只查看了权限页与设备状态。

“这能说明对方知道申请吗？”唐澄问。

“不能。”陆衍说，“只能说明受理后仍有人进入该账号。是否与申请有关，没有证据。”

“但它证明控制没有因许棠关机自动结束。”林栀说。

团队将事实分成四行：账号持续存在；与宋恺任职公司通信账户存在关联；关键夜晚查询时间与位置暴露对应；受理后仍有一次登录。每一行都附原始记录与取得路径，每一行也都注明尚不能证明的部分。

十点二十分，周屿到陆衍办公室取一支律所公用录音设备，准备记录许母补充说明。

公用设备柜与私人防火柜相邻。

他一眼看见硬盒外层标签：战术库存七，已启用一，未启用六。

“七支？”周屿问。

陆衍关上柜门：“私人设备，不属于本案。”

“我没问内容。”

“那就拿公用设备出去。”

周屿想起“陆无说”，又想起昨晚两人都没在工作群出现，嘴角缓慢扬起来。

“七支设备，”他说，“也未必够你说三个字。”

陆衍看着他：“许母的授权确认了吗？”

“确认了。”

“录音用途和停止权？”

“都确认。”

“那去工作。”

不羞恼，不解释，也不拿私人内容反击。

周屿走到门口，又回头：“至少第一支录到声音了吗？”

“与工作无关。”

“明白。默认失败。”

门关上。

林栀正好从外面经过，听见最后四个字。她没有追进去补充“确实败诉”，更没有告诉周屿两分钟录音里有什么。

私人笑点停在设备数量。

具体语言只属于录音中的两个人。

十一点四十五分，补充材料提交。

法院确认接收，七十二小时审查继续计时。许棠母女安全状态没有新异常，学校仍按临时方案运行。

服务商随后发来第二封回函。

其中一行登录记录被标成红色：保护申请正式受理四十三分钟后，协管账号通过原绑定设备再次登录。

许棠关闭了手表。

对方却仍在查看那扇已经被她关上的门。

而这一次，后台终于留下了不能被一句“只是关心”轻易抹去的时间痕迹。

登录者是谁仍待核验，持续进入本身已经成为新的事实。
