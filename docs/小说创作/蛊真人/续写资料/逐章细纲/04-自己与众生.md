# 剧情段四：自己与众生（401—412）

| 节次 | 暂定标题 | 主推进与角色决策 | 章末状态 |
|---:|---|---|---|
| 401 | 自己不语 | 王小二进入神帝城，自己蛊拒绝被检测；元莲意志只能通过壁画观察其影响 | 自己蛊让一名被人道杀招统一情绪的凡人恢复独立意愿 |
| 402 | 人山缺石 | 人道十子尝试以众生经历塑造人山雏形，发现只有群体记忆而无个人选择会崩塌 | 王小二成为实验不可替代的变量 |
| 403 | 方正之问 | 方正负责保护王小二，却从他身上看见自己长期作为克制方源棋子的处境 | 方正开始查阅方想资料，而非立刻上报星宿 |
| 404 | 马鸿运的魂 | 赵怜云复盘爱情蛊在天庭战中的偏转，确认马鸿运魂魄仍在方源处，但与气海夺魂发生过短暂共鸣 | 她决定进入神帝城研究人道复活，不再只等待爱情蛊随机发动 |
| 405 | 众生有价 | 星宿主张以众生自愿贡献构筑人山，天庭幸存者却想强制征集以求复兴 | 星宿压下强制方案，却暗留战争状态下的例外条款 |
| 406 | 大爱育人 | 方源获知人山进展，在至尊仙窍复制实验，以贡献、寿命和复活名额诱导众生提供经历 | 实验高效却产生大量趋同人格，正是自己蛊可克制的问题 |
| 407 | 商心慈入画 | 商心慈受邀进入壁画世界，她的治理经验让一片人道景象自行稳定 | 元莲意志判断“善意”可成为人道材料，但不等于无代价 |
| 408 | 铁若男审心 | 铁若男追查贡献者是否真正自愿，揭开天庭例外条款和大爱盟契约中的强迫边界 | 人道工程被迫公开规则，进度放慢却更加稳定 |
| 409 | 方想见父 | 方想通过血脉线索与方正隔空接触，双方都误判对方意图；方源允许接触以观察自己蛊和血脉反应 | 方正确认方想与自己、方源存在近亲联系 |
| 410 | 自己选择 | 王小二首次主动调用自己蛊，不是攻击，而是拒绝所有阵营对其未来的定义 | 人山雏形因无数个体选择而真正凝出第一块山石 |
| 411 | 人海有岸 | 方源推算人山人海合一可制造九转层次的人道“众生身”，但无法承载尊者全部道痕 | 替代仙体食物路线获得希望，同时暴露巨大人口成本 |
| 412 | 不归一人 | 星宿、方源都试图掌握人山，元莲意志选择将核心分散在参与者经历中，任何一方都无法独占 | 人山工程进入分布式发展，下一段转向巨阳失去的光帝君 |

## 闭环检查

- 自己蛊展示“拒绝被统一定义”的核心能力，而非万能战斗蛊。
- 人山获得可执行构筑方式，同时明确无法立刻解决九转食物。
- 方正、方想和赵怜云各自形成主动目标。
