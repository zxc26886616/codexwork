| 419 | 光帝自择 | 光帝君主动切断一部分血脉感应，以自身伤势换取短暂独立，并要求先救佑天光 | 巨阳震怒，却因亲情没有强行抽取血脉坐标 |
| 420 | 幽天追逐 | 三方追兵在幽天交错，幽魂受光蛊刺激靠近；方源用天鬼匿形穿过幽魂影响区 | 光蛊从佑天光体内短暂现世，引发幽天大范围光潮 |
| 421 | 暗光一界 | 左夜灰牺牲部分暗道根基，配合光帝君把光潮折成暗光界，暂时隔绝尊者直接锁定 | 暗光界需要持续消耗光蛊伤势，不能长存 |
| 422 | 巨阳入界 | 巨阳强闯暗光界，面对光帝君“先让佑天光自由”的条件；他可以夺蛊，却会亲手毁掉儿子的选择 | 巨阳退让一步，同意解除对佑天光的血脉化控制方案 |
| 423 | 残炼之光 | 方源表面修复光蛊，实则只修到可稳定存在并留下无法立即察觉的炼道接口 | 光蛊仍为野生，不属于任何尊者；光帝君暂时成为其同行者 |
| 424 | 父子分路 | 光帝君拒绝立即回长生天，随佑天光、左夜灰留在暗光界；巨阳留下保护手段后离开 | 巨阳第一次承认血脉后裔可不服从，杀道异变随光潮到来 |

## 闭环检查

- 光帝君完成违背巨阳预期但符合自身利益的选择。
- 光蛊保持野生且只被部分修复，方源获得隐蔽接口而非完整所有权。
- 左夜灰、佑天光从道具升级为有分歧的行动者。
