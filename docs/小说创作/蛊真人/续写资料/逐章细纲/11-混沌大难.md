| 486 | 门开幽天 | 方源选择在幽天深处落下至尊仙窍并开启门户，表面被迫，实际位置靠近晶壁盲区 | 星宿通过早布线索锁定大致方位 |

| 489 | 混沌入窍 | 第一股混沌不是元素灾害，而是抹去流派区分；至尊仙窍多道不互斥的优势反成扩散通道 | 方源必须主动切断数条已经营成熟的道脉 |
| 490 | 人海撤民 | 人山人海负责迁移众生，个体自愿机制拖慢效率；方源设定明确贡献与生存优先级，不假装人人平等 | 自己蛊保护一批拒绝迁移者，他们意外稳定一处人道孤岛 |
| 491 | 星宿三解 | 星宿给联盟三套攻窍方案，却把最危险的一套留给天庭自己，避免盟友提前崩溃 | 林剑行看出她也在借灾劫测试世界边界 |
| 492 | 幽魂食劫 | 幽魂以杀道终止部分混沌变化，反而吞下无法消化的“无流派”痕迹 | 幽魂获得伤害混沌的能力，也开始被混沌改写 |
| 493 | 九转炼阵 | 方源以天元宝皇莲供元、升炼蛊调度、天网蛊封边、天机蛊测变，四九转首次组成完整体系 | 四蛊联动暴露，天下终于看清方源真正底蕴 |
| 494 | 方正入窍 | 诛魔榜通过血脉感应突破一处假核心，方正却发现这里存有方想和大量普通人的生存区 | 他拒绝按原计划引爆，改为只破坏方源资源节点 |
| 495 | 兄弟之别 | 方源远程与方正交涉，不谈亲情，只指出方正的选择已违背星宿最优解；方正承认选择属于自己 | 自己蛊的力量在方正身上产生短暂响应 |
| 496 | 元始气墙 | 星宿唤醒元始意志，用残余气道成果在仙窍门户建立气墙，阻止方源关闭门户 | 方源以乎地和气海魂魄反制，元始、气海的因果最后一次交锋 |
| 497 | 气海归海 | 气海魂魄主动按方源预设自毁，化为可炼化的气道桥梁；不是人格反抗，而是分身使命最后一环 | 元始气墙破开，方源得到短暂关门机会 |
| 498 | 星宿入局 | 星宿本体踏入至尊仙窍，接受离开天庭主场的风险，以智道统合联盟攻势 | 方源关闭部分门户，把星宿也困入大难范围 |
| 499 | 天意夺身 | 混沌借至尊仙体饥饿缺陷，把整个仙窍判定为“未完成的九转蛊材”，天意试图接管炼制 | 方源发现必须反炼自身，否则渡劫不会结束 |
| 500 | 舍弃不互斥 | 方源不完全消除多道不互斥，而把它改为可主动开关、需要仙元维持的状态；代价是失去永久被动优势 | 改炼开始，至尊仙窍各道暂时互斥并发生大崩塌 |
| 501 | 众生撑天 | 人道孤岛、神帝城来援者和至尊仙窍居民分别稳住局部；他们不是为方源忠诚，而是为自身世界不毁 | 星宿发现众生行动让她无法简单把仙窍整体封死 |
| 502 | 杀尽混沌 | 幽魂以自身为刀斩断一股混沌，准九转杀蛊真正升至九转；代价是幽魂旧有魂道人格大面积消散 | 新的杀道存在诞生，既非旧幽魂也非纯天意傀儡 |
| 503 | 智道失主 | 星宿为封住混沌缺口动用大量蛊界智道自然痕迹，主场根基向至尊仙窍转移并被方源炼阵截留 | 星宿失去对天下智道道痕的完整道主控制 |
| 504 | 大难之后 | 方源完成改炼，关闭门户，保住核心但损失大量资源与人口；星宿借元始意志撤出，杀道幽魂离去 | 混沌大难闭环，方源、星宿、幽魂三方都已不再是战前状态 |

## 闭环检查

- 大难针对至尊仙体本质，不是普通大威力天劫。
- 方源付出道脉、人口、资源和被动不互斥优势的真实代价。
- 方正、人道众生改变局部条件，但未正面击败尊者。
- 星宿失去完整道主基础；幽魂转为新的杀道存在。
