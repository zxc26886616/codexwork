# 剧情段十二：破壁求生（505—520）

| 节次 | 暂定标题 | 主推进与角色决策 | 章末状态 |
|---:|---|---|---|
| 505 | 劫后天下 | 五域承受混沌余波，天庭、长生天与大爱盟均无法恢复旧统治；地方势力先救自身 | 方源虽仍最强，却没有资源直接统治天下 |
| 506 | 最后一壁 | 晶壁核心记录到大难开合时的界外路径，穿越需要炼道定形、智道定位、人道承载和杀道断后 | 任何单一尊者都无法独自完成 |
| 507 | 星宿条件 | 方源要求星宿合作定位界外，星宿提出条件：不得把整个蛊界炼成穿界耗材，并要留下可独立延续的文明核心 | 方源不承诺道德，只接受成本更低且不妨碍目标的部分 |
| 508 | 人道不献 | 人山人海参与者拒绝被整体炼作载体，提出以自愿者经历形成可分离的众生舟 | 方源允许自由退出，因为强制意志会让载体在界外崩溃 |
| 509 | 光照界门 | 光帝君带野生光蛊归来，光蛊可照出边界而不能穿过；巨阳残意请求他继承长生天 | 光帝君接受保护北原后裔，拒绝继承父亲全部秩序 |
| 510 | 杀道断后 | 新杀道存在只想验证能否终止混沌，愿为界门斩开一瞬；凤九歌再次出现，确认这是幽魂自己的新命运 | 杀道与命运不再完全敌对，成为一次性开门条件 |
| 511 | 元始告别 | 元始残意判断破界会削弱蛊界屏障，选择把自身最后力量用于修补内侧而非复活 | 星宿接受师父第二次离去，获得稳定世界内侧的方法 |
| 512 | 红莲后手 | 凤九歌交出红莲留下的命运成果：穿界者不能带走确定的未来，只能带走选择能力 | 春秋蝉与既定时间线不能成为界外保险 |
| 513 | 盗天之路 | 盗天遗留给出天外之魔穿界经验，其失败点是执着原世界坐标；方源只取方法，不继承回乡目标 | 方源确定穿界后无法保证返回 |
| 514 | 大爱最后一市 | 方源公开出售最后一轮炼蛊和迁移名额，收集穿界所需资源；天下人在知情下各取所需 | 大爱盟完成工具使命，成员可选择留下或同行 |
| 515 | 白凝冰等人的选择 | 白凝冰、黑楼兰、武庸、商心慈、铁若男等分别决定追逐未知、争夺本土、守护秩序或继续个人道路 | 主要旧人物不被强行集合成同一阵营 |
| 516 | 星宿战方源 | 合作完成后，星宿最后试图夺取界门控制权，防止方源未来返回吞并蛊界；方源早预留炼道权限 | 两人展开最后一场以控制而非毁灭为目标的尊者战 |
| 517 | 众生不作注 | 神帝城、人山和各域势力同时切断双方对世界资源的无限抽取，迫使终战局限在界门 | 星宿失去以天下为主场，方源也失去把众生当即时仙材的捷径 |
| 518 | 炼天有界 | 方源以改炼后的至尊仙体承受界外混沌，击败星宿的界门控制；他没有能力也没有必要毁灭蛊界 | 星宿保住文明核心，接受方源离开是当前最低代价 |
| 519 | 一步之外 | 光蛊照路、杀道断混沌、智道定位、众生舟承载，方源踏入世界边界；九转蛊和分身必须取舍 | 他舍弃无法适应界外的大片资产，只带走可继续推演的核心体系 |
| 520 | 永生未竟 | 蛊界内各方开始无单一尊者的新秩序；界外方源确认自己跨过已知死亡规则，却仍无法证明永远不死 | 他不回望，也不宣布成功，只继续向下一个未知前行 |

## 闭环检查

- 蛊界主要势力与代表人物获得方向明确、非整齐划一的结局。
- 星宿保住文明延续，方源取得破界自由，双方都没有价值观反转。
- 永生在剧情上跨越已知边界，在哲学上保持不可穷尽。
