# 剧情段六：杀道初生（425—436）

| 节次 | 暂定标题 | 主推进与角色决策 | 章末状态 |
|---:|---|---|---|
| 425 | 杀意成潮 | 暗光潮刺激幽天，众生杀意向幽魂汇聚；八转杀蛊开始自行统合魂道手段 | 幽魂第一次主动放过无杀意者，显示行为规律改变 |
| 426 | 九歌再现 | 凤九歌现身，以命运歌让幽魂的不同可能同时短暂存在，阻止星宿直接推算杀道成形路线 | 星宿判断红莲布局正在借幽魂开创新道 |
| 427 | 鬼不觉鬼 | 方源靠天鬼匿形接近幽魂，却被杀蛊而非幽魂感知；手段从绝对隐蔽降为有条件有效 | 方源主动撤退并取得一缕原始杀道道痕 |
| 428 | 薄青之锋 | 星宿唤醒薄青魂魄片段，以剑道切割幽魂新生杀道；林剑行拒绝被征召，改以交易方式提供天外剑痕 | 天外道痕能伤杀道，却同时帮助它排除魂道杂质 |
| 429 | 杀不等于死 | 人道十子研究受杀意影响者，发现杀道针对“终止可能”而不只是肉身死亡 | 自己蛊可保留一线选择，因此成为天然克制雏形 |
| 430 | 幽魂一问 | 幽魂恢复极小片段神智，首次以明确问题询问凤九歌：杀尽之后还有什么 | 凤九歌不回答，只继续命运歌，让问题成为幽魂新目标 |
| 431 | 三尊封杀 | 方源、星宿、巨阳短暂同意限制杀道扩散，各自却想保留样本；联合方案因分赃从开始就有裂缝 | 幽魂借三种压制完成杀道第一套攻防循环 |
| 432 | 火蛊炼杀 | 九转火蛊烧去幽魂体内不合用的魂道痕迹，杀蛊升转契机出现；方源决定不立即抢蛊，先借天道炼制观察九转过程 | 杀蛊开始冲击九转，幽天出现无声区域 |
| 433 | 命运一声 | 凤九歌以自身道痕补足杀道缺口，却不是帮助幽魂称尊，而是确保新道不被任何一尊垄断 | 命运歌受损，凤九歌暂时失去巅峰战力 |
| 434 | 杀道之主 | 杀蛊升至九转失败半步，形成准九转核心；幽魂获得“选择目标、积累杀势、终止生机”的初步体系 | 天鬼匿形不能再保证幽魂完全忽略方源 |
| 435 | 各取一道 | 三尊分别夺取杀道样本；自己蛊保下一批受害者，证明人道可阻止杀势锁死未来 | 幽魂带准九转杀蛊退入幽天深处，开始主动选择猎物 |
| 436 | 新敌旧鬼 | 星宿确认幽魂不再只是可操纵野兽；方源则把杀道列入混沌大难预案 | 混元一气子在北原升仙潮中重生的迹象暴露 |

## 闭环检查

- 杀道获得清晰规则、核心和限制，不只是更强魂道。
- 幽魂恢复目标性但非完整旧人格。
- 天鬼匿形被合理削弱；凤九歌、自己蛊和天外剑道均产生作用。
