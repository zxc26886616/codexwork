# 断点局势与伏笔清单

## 一、当前断点：第三百八十八节末

“残庭分赃”已经闭环，故事从尊者战后处理转入五域政治抢位：

1. 方源在至尊仙窍完成战利品初步结算，持有气海大半魂魄、气道复活道果、受损乎地、半座仙墓和大量灾后交易数据。
2. 九转天网蛊和方源仙元不再短缺已被星宿、巨阳确认；另外三只九转仙蛊仍受天机混淆保护。
3. 新天庭只剩原洞天不足三成，以神帝城、绣楼和残存智道道痕为移动核心；元始意念沉睡。
4. 中洲十大古派获得自治，天庭不再能保护整个中洲；武家、林家等已和星宿签订首批资源契约。
5. 巨阳仍在追索光帝君，并让费雾秘密验证混元一气子旧痕；星宿误判旧痕碎片被方源所得。
6. 方正已把方想的模糊血脉回应列入密报；赵怜云与气海魂魄的爱情蛊印记暂未再次发动。

## 二、第三百八十九节必须承接

- 中洲失去统一保护后，地方门派、散仙和外域势力立即争夺资源与秩序，不能维持旧天庭统治的表面状态。
- 武家和林家已完成初步契约，下一步写契约执行及其引发的区域反应，不重复首次议价。
- 方源的大爱盟已开始灾后交易，下一阶段应把治疗与炼蛊扩展成政治和资源保护体系。
- 星宿已经开放部分成果，下一步是第一批外域蛊仙进入神帝城及由此产生的控制边界。
- 方源三条食物路线仍处研究阶段，不能马上无成本炼出九转人道空壳。

## 四、人物状态债务

- **方源**：公开仙元优势后，交易方和敌人都会提高戒备；必须把暴露转化为大爱盟信用和威慑。
- **星宿**：主场大幅削弱，必须在有限控制与盟友自主之间取舍，不能继续按旧天庭模式号令五域。
- **巨阳**：兼顾寻子和混元一气子线；方源只知道其光道血脉软肋，不知道具体真相。
- **方正**：开始承担救援与新一代组织责任；血脉线索应按天庭程序上报。
- **赵怜云**：半头白发、寿命受损，目标仍是马鸿运魂魄；不能连续无代价发动爱情蛊。
- **武庸、林剑行**：已用资源或一剑履行首批契约，下一步会要求相应政治回报。

## 五、伏笔优先级

### S 级：五域抢位剧情段闭环前

- 中洲新仙盟、十大古派与新天庭之间的权限边界。
- 武家取得中洲南缘资源后的南疆反应。
- 林家清白与天外剑道资料交易如何落地。
- 大爱盟从灾后市场扩展为怎样的保护契约。
- 神帝城外域学员制度和天庭知识换资源的长期模式。

### A 级：随后两个剧情段

- 方想密报与方正的处理。
- 王小二、自己蛊与人山人海。
- 赵怜云如何研究人道复活。
- 混元一气子旧痕在各域升仙气流中的验证。
- 光帝君、佑天光、左夜灰与光蛊。

### B 级：中长线

- 三条九转食物路线与混沌大难。
- 幽魂杀道、凤九歌和红莲。
- 乾坤晶壁、林剑行天外剑痕、紫薇与影无邪。

## 六、五域抢位闭环条件

1. 中洲、南疆、西漠至少三处新政治关系落定。
2. 天庭知识契约和大爱盟市场保护形成不同秩序模式。
3. 武庸、林剑行、商心慈等非尊者人物取得可见主动权。
4. 新秩序必须同时展示收益和约束，不能写成单方无代价扩张。
5. 王小二进入神帝城，为下一剧情段“自己与众生”建立入口。
