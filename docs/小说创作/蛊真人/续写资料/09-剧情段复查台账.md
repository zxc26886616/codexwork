# 剧情段复查台账

## 一、触发规则

复查不以固定章数触发，而以剧情段闭环触发。满足以下任一条件时，必须暂停写下一章：

1. 本段在细纲中列出的闭环条件全部完成。
2. 核心物件归属、主要人物目标或胜负结果已发生不可逆变化。
3. 正文自然形成了比预定更早的高潮与收束。
4. 实际发展明显偏离细纲，继续写会放大连续性误差。

若一段过长，可在中途做“轻复查”，但只有闭环复查会正式更新完整设定集与后续大纲。

## 二、闭环复查清单

### 事实与连续性

- 本段起止节次、实际标题和时间跨度。
- 人物最终位置、伤势、修为、立场、已知情报。
- 仙蛊、天地秘境、仙窍、资源点的归属与状态。
- 仙元、仙材、寿命、灾劫和杀招反噬是否结账。
- 新增设定是否与仙蛊唯一、道痕互斥、尊者主场等规则冲突。

### 角色逻辑

- 方源的行动是否直接或间接服务永生，而非情绪泄愤。
- 星宿是否基于天庭长期利益作出选择，且未因剧情需要降智。
- 巨阳、幽魂及非尊者是否保有自身目标，而非只为推动主角。
- 每个关键角色知道的信息是否有合法来源。

### 叙事质量

- 本段主问题是否真正改变状态。
- 是否至少支付一项可见代价。
- 是否回收旧伏笔并新增不超过必要数量的新问题。
- 战斗、谋略、经营、人物视角是否失衡。
- 是否出现重复桥段、无效议价或只列设定不推进事件。

## 三、必须更新的文档

闭环后按需更新：

1. `01-世界观与力量体系.md`：新增规则、手段和已改变的世界状态。
2. `02-人物与势力状态.md`：更新所有出场关键人物与势力。
3. `03-全书剧情大纲.md`：把完成剧情段从“计划”写成“已发生”。
4. `04-断点局势与伏笔清单.md`：移动断点、关闭伏笔、重排优先级。
5. `06-续写总纲.md`：若实际结果改变终局路径，修订后续剧情段。
6. `08-逐章细纲.md` 及子文件：记录已完成节次，并细化下一剧情段。
7. `续写正文/README.md`：更新章节索引和当前连续性账本。
