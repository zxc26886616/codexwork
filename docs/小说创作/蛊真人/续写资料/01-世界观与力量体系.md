# 世界观与力量体系

## 一、第三百六十八节时的天地格局

宿命蛊已毁，五域界壁消失。太古黑、白两天在幽魂吞食黑天天灵、太阳毁灭和冷蓝魂火蔓延后，已经融合成 **幽天**。幽魂是幽天最大光源和事实上的主宰；其杀意影响五域，魂兽增殖，暗道兴盛，光道受压。

| 地域 | 当前格局 | 战略状态 |
|---|---|---|
| 中洲 | 天庭与十大古派 | 漫天繁星精算阵约毁八成；中洲资源遭大掠；元始爆炸令正道骨干十不存一 |
| 北原 | 长生天与黄金部族 | 巨阳已炼化约六成北原运道自然道痕；光帝君与受损九转光蛊失陷 |
| 南疆 | 家族割据，武家扩张 | 升仙大潮带来新仙，铁若男、商心慈等旧线进入新阶段 |
| 东海 | 方源公开经营大爱盟 | 方源炼化炼道自然道痕，以炼蛊、交易和至尊仙窍为根基 |
| 西漠 | 家族割据 | 房家战争余波仍在；林剑行暴露天外之魔与亚仙尊实力 |

幽天形成后，先前因两天混淆而紊乱的天意重新稳定。天意不喜方源，方源因此以九转天机蛊和大盗仙蛊组成 **盗天机**，借他人升仙时师法自然的窗口强夺天地知识。天意会迁移野生仙蛊和资源规避方源，双方已形成主动对抗。

## 二、蛊修与尊者规则

- 一至五转为凡蛊，六至九转为仙蛊；仙蛊唯一。
- 单只蛊不是完整战力，杀招、蛊阵、仙蛊屋决定实际用途。
- 仙窍产出仙元、承载生态并经历灾劫；自然升仙时可师法自然。
- 至尊仙窍道痕不互斥，可兼修多道、吞并仙窍，但经营和灾劫压力极大。
- 尊者能炼化本流派自然道痕，在相应地域获得主场增幅。
- 无上大宗师境界会随天地新发展而跌落；只有炼化全部本流派自然道痕，才能稳定维持境界。

方源经天道梦境后达到深厚天道大宗师层次，并可能逼近准无上。星宿在天庭智道道痕加持下可正面抵御方源、巨阳；巨阳在北原拥有同类运道主场优势。

## 三、关键九转与天地秘境

### 方源的四只九转仙蛊

1. **天元宝皇莲**：提供黄杏仙元，是隐藏仙元优势的根本。
2. **升炼蛊**：辅助仙蛊升炼。
3. **天机蛊**：用于盗天机与天机混淆。
4. **天网蛊**：用于天网恢恢并强化天机混淆，是 340 节炼成的第四只九转蛊。

另有八转智慧蛊，由自然重生的六转智慧蛊逐步升炼而来。

### 关键资产

- **炼海、人海**：方源已建成；人海因缺人山仍不完整。
- **乎地**：从气海仙窍中取出并被天庭镇压，爆炸后状态未明。
- **乾坤晶壁碎片**：方源在东海、南疆、西漠广泛收集；完整晶壁可记录天下万事并产生元境。
- **心境**：星宿用来抽取中洲众生对天庭的不利情绪，加强凝聚力。
- **神帝城与壁画世界**：人道圣地；人道十子因身在其中避过元始爆炸。

## 四、方源的当前手段与硬约束

### 已确认手段

- **九转天机混淆**：形成稳定、自愈的天道道痕网络，被侦查时才会消耗。
- **盗天机**：强夺升仙时的天地知识，已盗出衍化大阵、智慧蛊位置与诸多蛊方。
- **天鬼匿形**：天道改良的鬼不觉，使神志不清的幽魂忽略方源。
- **天网恢恢**：以九转天网蛊为核心的强大防御。
- 多道复合攻伐、梦道分身、可转移的逆流护身印及大量新战斗体系。

### 两项迫近危机

1. **混沌大难**：后患无穷不能跳过。渡劫时至尊仙窍必须落入幽天并开启门户，形成尊者可攻的巨大破绽。
2. **至尊仙体饥饿**：方源已是九转，需要吞食九转仙窍；当前没有安全现成的食物。

这两项危机迫使方源主动打破三尊均势，不能无限拖延炼蛊。

## 五、新流派发展

- 衍化大阵借野生九转衍化蛊推动人道、丹道、兵道、画道等急速发展，后被毁约八成。
- 王小二体内发现 **自己蛊**，把《人祖传》与人道重新连到主线。
- 天道梦境证明天道境界可由梦境提升。
- 幽魂在无神智状态下生成八转 **杀蛊**，标志杀道已有开创迹象。
- 送生庙、多胎蛊、骨肉团圆蛊与人海复活循环，使至尊仙窍的人口和蛊仙种子进入工业化培养阶段。

## 六、连续性边界

- 仙蛊唯一；新增同名仙蛊前必须确认原有归属和是否已毁。
- 道痕通常互斥，至尊仙体是核心例外；复合杀招仍需合理核心和代价。
- 尊者主场增幅巨大，不能用普通八转围攻解决。
- 方源永生优先；星宿天庭长远利益优先；巨阳的血脉亲情是结构性弱点但不是愚蠢。
- 强大手段至少保留仙元、仙材、催动时间、情报暴露或反噬中的一种成本。

## 七、续写已落定规则（369—376，C 级连续性）

- 星宿可借神帝城人道根基，把幸存蛊仙的位置、情绪、伤势和气运临时组织成“人智星图”；它依赖现场人员与撤退路线，不等同于重建漫天繁星精算阵。
- 秦鼎菱的运道杀招 **孤注连枝** 不能直接伤害尊者，只能以寿命、自身气运和天庭残运为赌注，暂时连接两个原本无关的结果，提高巨阳在意之人受难的可能。
- 元始复活残核最终分为意识根基、气道复活道果和九转身躯根基。三者可以被分离，说明气功果复活不是不可拆解的整体。
- 爱情蛊能够沿方源分身与本体的因果联系寻找马鸿运魂魄，但威能自主选择路径，赵怜云无法精确控制。

## 八、续写已落定规则（377—388，C 级连续性）

- 天庭主动切除外围七成洞天，以神帝城、绣楼和残存智道自然道痕组成可移动核心；移动需要大量仙元，且主场增幅远弱于旧天庭。
- 方源可以把一次性天网恢恢提前灌注给梦求真等分身，但需要大量黄杏仙元，使用后无法回收，并会留下九转天网蛊痕迹。
- 九转天网蛊已被星宿通过气墙碰撞记录确认，并向天下放出证据；天元宝皇莲、升炼蛊、天机蛊仍未被敌方确认。
- 元始留下的残缺气道纹路能把升仙三气转成仙元石雏形，但缺少混元一气子的生命本质时无法稳定生产。
- 方源从气道复活道果推演出三条仙体食物路线：人山人海炼制九转空壳、多个八转仙窍拼合、吞食真正尊者仙窍；目前均有重大缺陷。
