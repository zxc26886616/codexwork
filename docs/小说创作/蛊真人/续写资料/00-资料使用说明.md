## 资料架构

1. **原文事实层**：`01`—`04` 与 `07`，只记录正文明确事实或稳定推论。
2. **创作约束层**：`05`，记录叙事组织、视角、连续性和原创表达边界。
3. **续写推演层**：`06`、`08`，存放完整总纲和逐章细纲；未落入正文前均为 C 级推演。
4. **复查更新层**：`09`，每完成一个具有明确闭环条件的剧情段，就更新状态、伏笔与后续细纲；不机械绑定章数。

## 事实等级

| 等级 | 定义 | 使用规则 |
|---|---|---|
| A | 权威正文明确陈述且截至 368 节仍有效 | 可直接用于续章 |
| B | 可由多处正文稳定推断 | 可用于人物判断，但保留反转空间 |
| C | 续写新增的解释、桥段或结局路线 | 只记入总纲、细纲和正文台账 |
| D | 未核实、互相矛盾或仅凭记忆 | 禁止写入正文，先回查 TXT |

## 固定工作流

1. 动笔前从细纲确认本章主推进、副推进和章末状态。
2. 回查相关人物最近一次出场，核对位置、修为、伤势、仙蛊归属与情报边界。
3. 每章先发生局势变化，再写利益判断，最后落到代价、转折或新问题。
4. 新增蛊虫、杀招、秘境前先检索原文；优先组合已有设定。
5. 每完成一个剧情段暂停续写，按 `09` 复查并更新 `01`—`04`、`06`、`08`；剧情段以事件闭环为准，可长可短。
6. 完稿检查时间、地点、视角、仙元、伤势、道痕互斥、蛊虫唯一性和消息边界。

## 创作边界

续写保持既有世界规则、人物利益逻辑和宏观叙事功能，但使用原创措辞，不复刻原作者的独特句式，不拼接原文段落。
