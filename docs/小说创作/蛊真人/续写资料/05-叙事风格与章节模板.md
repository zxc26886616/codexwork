# 叙事风格与章节模板

> 本文服务于原创衍生续写：保留世界规则、叙事功能和人物决策逻辑，不复刻原作者的独特句式，不拼接或改写原文段落。

## 一、续写要保持的高层特征

本文件提炼的是可操作的叙事特征，不要求复制原作者的句式或独特表达。

### 1. 利益逻辑推动剧情

人物很少因为抽象立场直接行动。即使谈正义、亲情、族群或天下，也要落到资源、风险、组织延续、个人执念或长远目标。对话表层可以冠冕堂皇，内心分析必须揭示真正筹码。

### 2. 信息差大于单纯战力差

一场胜负常由“谁知道什么、谁误判什么、谁隐藏了什么”决定。强者不会无理由犯错；他们的失败通常来自信息不完整、时间压力、多目标冲突或对方付出超预期代价。

### 3. 多线切换形成世界感

重大事件之后，视角会从尊者切到区域势力、普通蛊仙甚至凡人，展示同一事件在不同阶层的后果。切换不是散漫插叙，而要完成以下至少一项：

- 证明世界规则发生变化；
- 埋入下一条行动线；
- 用小人物处境反衬尊者决策；
- 展示谣言与真实情报之间的偏差。

### 4. 先解释规则，再利用规则反转

战斗和炼蛊不能只写声光。先交代关键限制，再让人物利用限制取胜。解释应紧贴当下决策，避免大段百科式说明。

### 5. 得利必伴随新负担

获得仙蛊、资源、盟友或情报后，通常会增加喂养、炼化、暴露、忠诚、气运或防守成本。章节结尾的理想状态不是“问题彻底解决”，而是“旧问题被解决，新代价已出现”。

### 6. 冷峻主线与有限幽默并存

尊者算计、灾变和死亡保持冷峻；人物性格碰撞可提供短促幽默。幽默应来自身份反差、利益尴尬或人物习惯，不能把紧张战局写成连续段子。

## 二、方源视角规则

- 先观察局势，再列出目标与约束，然后快速比较方案。
- 内心可以承认恐惧、遗憾和压力，但不会沉溺。
- 他不会为了证明强大而冒险，只会为了值得的收益冒险。
- 公开言辞常与真实意图不同，但不能每次都用同一种“表面愤怒、暗中欢喜”。应轮换沉默、交易、退让、误导、借势等策略。
- 他可以计算他人情感，却不能全知。遇到尊者、天意、爱情蛊、梦境等变量时要保留不确定性。

## 三、其他核心人物视角规则

### 星宿

结构是“收集情报—建立模型—权衡天庭长远利益—有限妥协”。她的错误应源自模型输入被方源污染，不能源自智力突然下降。

### 巨阳

结构是“感知气运—保护血脉与北原—用偶然性制造窗口—承担人情牵绊的代价”。他既豪迈又精明，不能写成只靠运气。

### 幽魂

断点时不适合长篇理性内心戏。应通过本能、痛苦、魂道规则、残缺记忆碎片和外界反应表现其变化。

### 区域人物

让他们在有限情报下做出自洽选择。他们可以误解尊者异象，但要依据看得到的灾害、宝黄天消息或本地利益行动。

## 四、单章结构模板

推荐每章约 2500—4000 中文字，按内容调整。

### 模板A：谋略章

1. 异象或情报到达。
2. 两到三方分别解读，各自掌握的信息不同。
3. 主视角列出限制，提出行动。
4. 行动表面成功。
5. 结尾揭示另一方已利用这次行动，或成功带来新成本。

### 模板B：战斗章

1. 明确争夺物和失败代价。
2. 第一轮手段展示流派优势。
3. 解释关键规则或道痕环境。
4. 第二轮针对性反制，迫使一方暴露底牌。
5. 第三方、环境或旧伏笔改变胜负条件。
6. 结尾不必分出胜负，但必须改变资源或信息状态。

### 模板C：区域回响章

1. 用一个具体人物承受世界事件。
2. 展示生活、修行或政治秩序的变化。
3. 人物做出选择并付出小代价。
4. 选择与尊者主线产生连接。
5. 以一条新情报或异常收束。

## 五、语言自检

- 每段只承担一个主要信息。
- 少用连续感叹号和重复形容词，强度靠局势与代价体现。
- 战斗名词出现后要说明功能，避免只报杀招名。
- 议论必须改变人物的下一步决策，否则删减。
- 避免现代网络口吻进入严肃叙述；人物原有的通俗、夸张表达可以有限保留。
- 不复刻原文整句、名段或《人祖传》既有段落。

## 六、完章检查表

- [ ] 本章主推进点是否明确？
- [ ] 至少有一个角色因新情报改变行动吗？
- [ ] 强者的误判是否有可信原因？
- [ ] 仙元、伤势、蛊虫归属和地点是否连续？
- [ ] 新手段是否遵守流派与道痕规则？
- [ ] 得利是否带来成本或暴露？
- [ ] 结尾悬念是否来自本章因果，而非生硬截断？
- [ ] 新增C级设定是否同步到资料库？

## 七、分批轻复查

每完成一批连续正文、尚未达到剧情段闭环时，也必须暂停做轻复查：

1. 检查方源、星宿、巨阳等核心人物是否仍按既定利益和信息边界行动。
2. 检查章节是否只有设定说明而缺少状态变化，或只有战斗声光而缺少规则利用。
3. 检查取得收益是否同步产生消耗、暴露、守护责任或新风险。
4. 检查境界、道痕、魂魄、仙窍等概念有没有被错误地当作可随意转移的普通物件。
5. 轻复查只修正已写章节与记录新债务；剧情段闭环后仍需按 `09-剧情段复查台账.md` 更新全部设定集和总纲。
