# 第三百七十六节：各自退路

星光遍照天庭。

方源、巨阳仙尊同时感到压力暴涨。

气功果核尚在时，星宿仙尊必须围绕果核层层设防。如今元始完整复活已无可能，她再没有需要固守的目标。

天庭仍是她的主场。

海量智道自然道痕在她调动之下，迅速从防御转为进攻。

一颗颗星辰虚影浮现在幽天，密密麻麻，围绕方源和巨阳仙尊旋转。

每一颗星辰都在推算。

方源身上炼道道痕如何运转，巨阳仙尊的气运向哪里流动，两人下一刻可能施展何种杀招，全部被迅速收集、拆解。

方源当机立断。

他催动天网恢恢，挡住第一轮星光，身形则向天庭废墟下方落去。

既然已经决定撤退，离开前自然要尽可能多取战利品。

天庭被元始爆炸炸得四分五裂，许多资源点、仙蛊屋残骸和秘库碎片散落各处。星宿此前要守护果核，无暇全部收取，如今正是最后机会。

灰白炼道大手接连抓下。

一片星道湖泊被连根拔起。

半座残破仙墓被卷入方源袖中。

数十块沾染气道道痕的天庭地砖也没有被放过。

“方源！”天庭群仙看得目眦欲裂。

方源先杀人，再夺宝，完全没有把天庭群仙的愤怒放在心上。

巨阳仙尊却没有跟着搜刮。

他此战已经达成目标，又被秦鼎菱的杀招牵动心神。比起天庭残骸，他更关心远在幽天的光帝君。

“方源，元始复活已败，你我联手到此为止。”

巨阳仙尊周身金光汇聚，准备撤离。

方源笑道：“巨阳仙友何必急着走？星宿身负重伤，天庭又是天下第一宝地。你我继续联手，将星宿也留在这里，岂不快哉？”

“你若真有此意，便先把刚才所得气道成果交给我保管。”巨阳仙尊冷笑。

方源叹息：“仙友此言，实在伤了你我盟友情分。”

两人嘴上交谈，彼此却都在防备。

巨阳仙尊知道，方源绝不会满足于一枚气道复活道果。

他若继续留下，很可能要和方源共同承受星宿反攻，最后还要防备方源暗算。

方源同样明白，巨阳去意已决。

他出言挽留，不过是想让星宿把更多注意力放到巨阳身上，也试探巨阳是否会因幽天中的那一点光失去冷静。

星宿仙尊没有给两人继续试探的时间。

仙道杀招发动。

漫天星辰同时坠落！

星光并非单纯攻向肉身，而是落在方源和巨阳仙尊即将经过的位置。两人每一次挪移，都仿佛主动迎向星辰。

方源连续改变三次方向，仍有星光提前截住去路。

“星宿已经推算出我眼下大半撤退路线。”

他并不惊慌。

天庭主场中的星宿，本就有这等威能。

方源头顶升起一片朦胧梦雾，令自身念头和行动变得难以预测。天网恢恢则护住周身，硬顶星光，继续收取沿途资源。

巨阳仙尊的应对更加直接。

他察看气运，专挑星光最稀薄之处移动。即便偶尔被星光封锁，也能从无数不可能中撞出一条运势最好的道路。

就在双尊准备离开时，幽魂魔尊再次扑来。

果核毁灭，生机四散，让他失去最明确的目标。

星宿、方源、巨阳、天庭群仙，在他的感知中重新混成一片。

九转火蛊的冷蓝火焰烧灼全身，八转杀蛊则不断寻找新的猎物。

幽魂魔尊三颗头颅各自锁定一方。

一颗盯住星宿。

一颗盯住巨阳。

最后一颗扫过方源所在，却在天鬼匿形影响下略过，转向天庭群仙。

星宿仙尊立即改变杀招。

坠落的星辰忽然偏移，不再封锁方源和巨阳，而是在天庭一侧轰开一道巨大裂口。

裂口之外，便是浩瀚幽天。

天庭原本就是太古白天洞天，蕴含大量白天残余气息。对已经成为幽天之主的幽魂而言，这种气息本就是必须消灭、吞并的对象。

裂口开启后，浓郁白天气息像一道长河，向幽天倾泻。

幽魂魔尊三颗头颅同时转向裂口。

他放弃天庭群仙，庞大身躯撞碎沿途星雾，顺着白天气息冲了出去。

星宿仙尊不是单纯放走幽魂。

裂口位置恰好处在方源和巨阳撤退方向之间。

幽魂冲出时，万千手臂横扫，冷蓝火海淹没大片虚空。巨阳仙尊若按原路返回北原，就要从幽魂身边经过。

方源若继续留在天庭搜刮，裂口周围的天庭碎片也会被幽魂卷走。

两人都被迫改变选择。

巨阳仙尊大喝一声，金光化作长虹，抢在幽魂完全冲出前穿过裂口。

临走之前，他看了方源一眼。

“下次见面，你我就是敌人。”

方源面带微笑：“你我何时不是敌人？”

巨阳仙尊没有回应，身形迅速消失在幽天深处。

他离开天庭后，立即改变方向，追寻那一点已经变得极其微弱的血脉光芒。

方源则又抓取最后一片天庭碎片，这才抽身而退。

星宿仙尊想要追击，却没有离开天庭。

她身后还有大量重伤蛊仙，神帝城也尚未完全收容众人。更重要的是，元始意念所化的透明心脏极其脆弱，需要立即镇压、保存。

她只能目送方源离开。

幽魂魔尊冲入幽天，吞噬沿途白天气息。

他身上的杀意比进入天庭前更加凝练。八转杀蛊在魂体深处不断跳动，每一次跳动，周围冷蓝火焰都会安静一瞬。

这种安静，比咆哮更令人心悸。

天庭终于恢复短暂平静。

星宿仙尊缓缓落到神帝城上空。

秦鼎菱昏迷不醒，赵怜云半头白发，不真子等人已经战死。诸多仙蛊屋残破，天庭洞天更是到处都在崩解。

这一战，元始没有复活。

天庭也再一次遭受重创。

但星宿手中，仍保住了一缕元始意念。

她低头望向星光蚕茧，沉默良久。

“师父，天庭还在。”

幽天另一侧。

方源确认星宿没有追来，便停下身形。

他清点所得。

气海魂魄、气道复活道果、天庭碎片、仙墓残骸，还有数处资源。

收获极其丰厚。

但他心中最重视的，却是另外两条情报。

其一，星宿已经看出天网恢恢远胜从前，第四只九转仙蛊的秘密很难再完全隐瞒。

其二，巨阳仙尊在幽天中有一处和血脉、光道密切相关的软肋。

方源将气海魂魄和浑圆气珠送入至尊仙窍，立即调动智慧蛊开始推算。

旧的一战已经结束。

新的谋算，才刚刚开始。
