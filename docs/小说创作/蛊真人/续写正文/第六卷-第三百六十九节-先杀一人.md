# 第三百六十九节：先杀一人

方源话音落下，天庭群仙无不变色。

他们早已料到方源不会放过这个机会。

但料到是一回事，真正被一位尊者当众宣布要尽数杀光，又是另外一回事。

一座座仙蛊屋中，气息陡然紊乱。有人愤怒，有人恐惧，也有人已将生死置之度外，只默默催动蛊虫，等待星宿仙尊调遣。

星宿仙尊神色不变。

方源却已出手。

他左掌拍向气功果核，五指间灰白烟尘翻滚，化作龙蛇万千。右袖一扬，数百道青碧风刃洒向下方，彼此并不相连，所取方位也毫无规律。

与此同时，他头顶的小荡魂山再次震动，粉色音波冲击星雾。

攻核，杀仙，扰雾。

三处攻势同时爆发！

若只看任何一处，都算不上方源最强手段。但三处齐发，星宿仙尊便必须判断哪一处是真，哪一处是假，又有哪一处会在下一刻由虚转实。

星宿仙尊眼中星芒连闪。

星雾先向内收缩，将气功果核严密包裹。随后数十道星光从她袖中飞出，彼此交织，宛若一张大网，兜住青碧风刃。

她没有反攻方源。

防守本就比进攻艰难。眼下她不仅要保住气功果核，还要庇护天庭群仙，镇压幽魂魔尊。若再分出力量反击，便会主动给方源和巨阳仙尊创造空隙。

方源对此早有预料。

他嘴角冷笑，右手忽然握紧。

被星网兜住的青碧风刃齐齐崩散，化作无数细小风丝。风丝大半在星光中泯灭，仍有数十缕穿过网眼，向各座仙蛊屋飘去。

这些风丝威能有限，莫说仙蛊屋，就连状态完好的七转蛊仙都能轻易挡下。

天庭群仙却无人敢轻视。

一座形如高阁的仙蛊屋率先放出白光。风丝落入白光，好似冰雪遇见烈日，迅速消散。

风满楼、揽雀阁等仙蛊屋也各自催动防御。

只是这样一来，仙蛊屋原本勉强维系的阵形便出现了细微停顿。

方源等的就是这一刻。

一道风丝忽然转折。

它没有攻向仙蛊屋，而是钻入两片天庭废墟之间。

那里躺着不真子。

不真子一半身躯已经消失，另一半则维持着虚化状态。他先前被元始复活的大爆炸重创，虚道道痕又被气道道痕严重侵蚀，根本无法移动。

赵怜云等人发现他后，曾留下防护手段和求援标记。但随后幽魂来袭，天庭内外一片混乱，始终没有人能够将他安全转移。

那一缕风丝在他身前停住。

下一刻，风丝中陡然亮起一点刺目的白芒。

仙道杀招的后续变化！

“住手！”

赵怜云失声惊呼。

她距离不真子极远，爱情蛊也没有丝毫动静，根本来不及相救。

星宿仙尊看向不真子的方向。

在这一刹那，她脑海中已有无数念头升腾碰撞。

救下一位重伤濒死的七转蛊仙，需要她分出一道星光。只是一道星光而已，对此刻的她而言微不足道。

但是方源攻向气功果核的龙蛇尘雾中，至少有三十七处威能正在变化。巨阳仙尊也在另一侧蓄势待发。只要她为不真子分出这一道星光，方源便能判断她救援的速度、方向和力量。

之后，是第二人、第三人。

天庭中还有上百位受伤蛊仙。

方源不需要真的杀光所有人。他只要不断攻击，便能用这些人的性命，一次次测量星宿仙尊的防御。

星宿仙尊没有出手。

白芒闪过。

不真子剩余的半边身躯悄然一滞。

原本维持虚化的轮廓像是被一只无形的手抹去，先是头颅，然后是胸膛，最后彻底化为一缕白气。

他本就处在生死边缘。这道杀招只是稍稍破坏了他体内虚道道痕的平衡，浓郁的气道道痕便替方源完成了最后一击。

不真子，死！

天庭群仙一片死寂。

赵怜云怔怔望着那片废墟，双手攥紧，指甲刺入掌心。

残阳老君脸色铁青。古月方正更是双目泛红，诛魔榜周围血光大盛。

方源哈哈大笑：“星宿仙友，我还以为你真能护住天庭中的所有人。看来所谓天庭，也不过如此。”

星宿仙尊淡淡回应：“炼天魔尊杀人无算，今日多添一条性命，又有什么值得自得？”

她的语气没有一丝波动。

下一刻，她的命令同时传入所有天庭蛊仙耳中。

“退入神帝城。”

“按星位而行，不得救援，不得停留，不得擅自改变先后次序。”

天庭群仙心头一震。

不救援，意味着途中无论谁遭受方源袭击，其余人都不得出手。

不少中洲蛊仙本能地感到寒意。

但天庭成员只是沉默一瞬，便纷纷领命。

秦鼎菱最先调转方向。

她驾驭一座残破仙蛊屋，从左侧斜飞出去。诛魔榜没有紧随其后，而是向右下方绕行。其余仙蛊屋有快有慢，有远有近，明明都在退向神帝城，路线却彼此交错。

方源再度挥袖。

数十道攻势追击而下。

星宿仙尊只拦截其中真正能够摧毁仙蛊屋的部分。至于一些较弱攻势，她竟任凭它们落下。

一座仙蛊屋被打得剧烈摇晃，屋檐崩碎。

屋中蛊仙吐血不止，却咬牙继续沿既定方向飞行。相邻仙蛊屋从旁掠过，没有任何人停下救援。

方源目光微凝。

他一边维持三处攻势，一边观察撤退中的群仙。

初看之下，星宿只是让天庭蛊仙分散逃命，避免被他一网打尽。

但随着一座座仙蛊屋改变位置，方源逐渐察觉异样。

秦鼎菱所在仙蛊屋是第一点，诛魔榜是第二点，神帝城则是始终不动的中央。

其他仙蛊屋看似混乱，实则每经过一处位置，就会与另外两处遥相呼应。

它们不是单纯撤退。

所有人的伤势、速度，甚至恐惧和愤怒，都被星宿计算在内。

这一条救援通道，本身就是一座正在成形的仙阵！

方源立即明白过来。

星宿仙尊的确没有救不真子。

她却借不真子的死，看清了方源杀仙手段的第一层变化，又用其余人的撤退，为自己增添了另一重防线。

而最先踏入阵位的秦鼎菱，已经悄然闭上双眼。

她的注意力，并不在方源身上。

而在巨阳仙尊。
