# 第三百七十九节：气海余魂

至尊仙窍。

气海魂魄悬浮在四元方悔血炼池上空。

他的魂体残缺不全。

星宿仙尊此前催动星刃，斩去了约三成魂魄。剩余部分又经历镇魂殿崩毁、爱情蛊牵引和尊者争夺，遍布裂纹。

换作普通魂魄，早已消散。

气海老祖原本就是亚仙尊，魂道底蕴虽非所长，魂魄强度仍远超寻常八转。

方源又及时用魂道手段稳定下来，才保住眼下状态。

气海魂魄双目紧闭，没有任何反应。

方源分出一股意念，进入魂魄深处。

大量记忆碎片迎面而来。

东海气海宴。

对抗气绝魔仙。

和天庭交易。

疯狂魔窟大战。

这些经历仍在，却像一幅幅互不相连的画面，缺乏最重要的主线。

有关方源本体、主动送入漫天繁星精算阵、肉身预处理等记忆，都被提前删除。

这是方源亲手所为。

他当初不能让气海老祖知道真正计划。

星宿是智道尊者。一旦气海心中藏有“自己是诱饵”的认知，哪怕他不主动思考，也可能在情绪、念头或下意识反应中露出破绽。

所以方源不只是欺骗星宿和天庭，也欺骗了自己的分身。

如今计划成功，缺失的记忆却无法凭空恢复。

“魂魄还在，气道修行经验和魂魄底蕴仍有大半保留。”

“和气道复活道果配合，可以重炼分身。”

“但要恢复原本亚仙尊战力，需要大量时间和资源。”

方源很快得出结论。

重生气海老祖并非不可能。

价值却需要重新衡量。

气海身份已经彻底暴露，肉身、仙窍和大量仙蛊尽失。即便重新炼出，也无法再用东海气道领袖的身份活动。

相比重新得到一个气道分身，研究元始复活法和仙体饥饿更加重要。

方源又尝试唤醒魂魄。

气海老祖缓缓睁眼，目光却没有焦点。

方源向他灌输一段最基础的身份记忆。

“你是气海老祖。”

“这里是至尊仙窍。”

气海魂魄听到这两句话，神情出现细微变化。散乱记忆开始自行聚拢，却很快在多个缺口处停下。

他知道自己曾统领东海气道，知道自己和天庭合作，也知道方源本体存在。

却想不起为何会进入漫天繁星精算阵，更不知道自己如何变成眼前残魂。

若方源继续灌输记忆，自然能塑造出一个愿意服从的气海老祖。

但灌输的内容不等于原本经历。

一旦用这具魂魄推算元始复活法，伪造记忆和真实炼道痕迹互相冲突，反而会污染结果。

方源只让他保持最基本意识，便再次令其沉睡。

工具要用在合适的位置。

眼下气海魂魄作为研究样本，比作为能够思考的分身更有价值。

方源又看向魂魄深处的一点白光。

爱情蛊留下的印记。

这点印记十分微弱，既不像魂道道痕，也不像智道、信道或因果手段。

方源连续催动数种侦查杀招，只能确认它没有立即破坏魂魄。

至于是否可以定位、牵引，或在赵怜云再次催动爱情蛊时产生变化，暂时无法确定。

九转爱情蛊极其特殊。

即便星宿也不曾将其炼化。

方源没有贸然强行驱除。

他曾拥有过爱情蛊的相关情报，也亲眼见识过它无视常规的威能。

这只蛊的力量并非没有代价，只是代价和效果都很难由使用者选择。

赵怜云想取回马鸿运魂魄，爱情蛊却先牵出气海魂魄。下一次发动，它可能继续沿同一路径深入，也可能突然转向完全无关的目标。

方源无法把这种不确定性纳入精确杀招。

却可以为不同结果预先准备收益。

印记若定位，他便设置假位置。

印记若牵引，他便准备一具替代魂魄。

印记若突然爆发破坏力，外围三层封印和封闭密室足以先承受冲击。

无法控制，不代表无法利用。

一来，未知手段最忌随意刺激。

二来，印记也可以利用。

赵怜云想顺着它找到马鸿运魂魄，方源同样可以借印记观察爱情蛊威能，甚至反过来给她准备一份“正确”的线索。

他调动天道道痕，在印记外覆盖三层封印，又将气海魂魄转入至尊仙窍中的封闭密室。

处理完爱情印记后，方源开始检查魂魄和气道复活道果之间的感应。

浑圆气珠悬浮在旁。

气海魂魄靠近后，气珠内部云海自动翻腾，天地人三气循环加快。

一道道气道知识从中显现。

这些内容不是元始完整传承，只是复活过程中自然留下的痕迹。就像炼蛊失败后残留的蛊材，能够帮助炼道蛊师反推蛊方，却不可能直接得到全部答案。

方源并不急躁。

八转智慧蛊悬于高空，智慧光晕笼罩气海魂魄和气珠。海量念头在他脑海中碰撞，逐步还原复活过程。

片刻后，气海魂魄忽然轻轻震动。

不是受到气珠影响。

而是感应到外界某样事物。

方源立即停止推算，将感应放大。

第一处感应来自数只气道仙蛊。

这些仙蛊原本属于气海老祖，被星宿从仙窍中抽出，以仙阵镇压。元始爆炸后，仙阵破损，仙蛊散落各处。其中一部分仍在天庭掌控，另一部分则随着洞天碎片进入幽天。

第二处感应更加强烈。

乎地！

气海老祖曾经长期以乎地为核心催动乎昂杀招，魂魄、仙蛊和天地秘境之间形成深厚联系。

即便方源删除了相关计划记忆，这种长期使用产生的痕迹仍在。

感应十分模糊，断断续续。

方源顺着方向推算，很快发现异常。

乎地没有留在天庭主体，也没有完全被爆炸抛入幽天。

它似乎卡在两者之间。

感应所在的区域，正是星宿宣布放弃的外围洞天之一。

“星宿真的无力回收，还是故意留下的诱饵？”

方源心中升起疑问。

他继续推算周围的洞天碎片和星宿调度。

很快，一片被气流和星光共同遮掩的爆炸区域，在他脑海中逐渐清晰。

星宿撤走了附近所有天庭蛊仙。

既没有安排回收，也没有留下明显防守。

这片区域，干净得过了头。
