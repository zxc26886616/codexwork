# 第三百八十三节：大爱收尸

宝黄天中，一道消息迅速传遍五域。

天地一家大爱盟再次开放炼蛊。

这一次，不只代炼仙蛊。

方源同时出售仙蛊屋修复、仙窍稳定、气道伤势治疗和魂魄保存等服务。

所有项目都和天庭爆炸后的需求严密对应。

价格不低。

但比起失去仙蛊、洞天崩毁或魂飞魄散，这些代价又显得十分合理。

消息一出，天下哗然。

“炼天魔尊刚刚炸毁天庭，杀死中洲蛊仙，现在又来出售疗伤手段！”

“一边杀人，一边救人，这就是所谓大爱？”

“方源从天庭夺走那么多资源，现在还要赚中洲人的仙材，实在无耻！”

宝黄天中骂声不断。

大爱盟负责交易的蛊仙没有反驳。

他们只是把不同服务的价格、所需时间和效果一一展示。

一位中洲散仙最先前来询问。

他的仙窍受到元始爆炸余波影响，内部充斥气道道痕。资源点不断化气，地灵也开始衰弱。

若不及时处理，整个福地将在数月内崩毁。

中洲十大古派自顾不暇，天庭又封闭神帝城，无法为他提供援助。

散仙在宝黄天中怒斥方源许久。

最后仍然取出全部积蓄，购买一套稳定仙窍的仙阵。

“仇恨不能稳定福地。”

“只要价格合适，敌人的东西也可以用。”

有了第一人，很快就有第二人、第三人。

一些中洲蛊仙不愿公开交易，便通过其他四域的中间人购买。还有人一面在宝黄天中痛骂，一面私下询问能否打折。

交易量迅速上涨。

方源没有亲自关注这些琐事。

至尊仙窍中，大量炼道蛊仙和毛民蛊仙已经开始工作。

天庭爆炸造成的伤势虽复杂，核心却大多是气道道痕侵蚀。方源刚刚取得气道复活道果和气海魂魄，推算相应治疗手段并不困难。

每完成一次交易，他不只得到仙材和仙元石，也能收集一份真实伤势数据。

这些数据反过来帮助他拆解元始爆炸和气功果复活。

公开交易之外，还有另一份清单。

这份清单不会出现在宝黄天。

清单收购的是中洲蛊仙尸骸、残魂、无主福地入口、仙蛊碎片和天庭洞天残土。

负责秘密清单的不是大爱盟公开成员。

方源把收购任务拆成数百份，交给不同区域的散修、商队和异人蛊仙。有人只负责尸骸，有人只收福地入口，还有人专门辨认天庭残土。

每层中间人只能看见自己负责的一类交易。

如此既能保护出售者身份，也避免星宿通过交易流向还原方源真正需求。

报酬不全部使用仙元石。

出售尸骸者可以换取疗伤，提供福地入口者可以换取仙蛊代炼，交出天庭残土者则得到大爱盟贡献。

同一批资源经过不同价格体系流转，最终都进入至尊仙窍。

价格比寻常市价高出数成。

交易者身份则由大爱盟保密。

最初很少有人回应。

死者大多有宗门、家族或亲友。出售尸骸不仅有损名声，还可能让死者的修行秘密落入方源手中。

但中洲损失实在太大。

许多宗门同时要救治活人、修复大阵、安置凡人，还要防备外敌。仙材和仙元迅速见底。

一具已经无法复活的蛊仙尸骸，继续保存需要资源。

卖给方源，却能换回救治数位活人的仙材。

这个选择很残酷。

也很实际。

第一笔秘密交易来自一个小型宗门。

宗门太上长老死于元始爆炸，只留下半具尸骸和一座正在崩毁的福地。门中剩余两位蛊仙争论整整一夜，最终把尸骸交给大爱盟，换取稳定福地的手段。

他们对外宣称，太上长老尸身已经在爆炸中彻底毁去。

交易完成后，两位蛊仙并没有立刻安心。

其中一人担心方源从尸骸中搜出宗门传承，主张毁掉所有相关典籍。另一人则认为传承已经泄露，更应该保留原本内容、尽快培养新弟子。

两人再次争执。

最终，他们把换来的仙材大半用于稳定福地，小半用于救治门中伤者。

死去太上长老留下的资源，没有被用来修建纪念殿堂，而是维持宗门继续存在。

这就是他们给出的选择。

类似交易随后不断出现。

方源来者不拒。

尸骸中的道痕可以炼蛊。

残魂可以补充人海，或提供中洲传承情报。

福地入口既能成为至尊仙窍食物，也能被迁入仙窍，补充资源生态。

就连天庭残土，都可能保留智道、人道或气道自然道痕。

方源杀死一批人，再利用幸存者救援和重建的需求，从他们手中换走更多资源。

这不是一时劫掠。

而是把天庭战败的余波，变成持续不断的收益。

星宿仙尊很快得到消息。

她没有禁止中洲蛊仙交易。

眼下强行禁止，只会让伤者失去救治机会，并把秘密交易逼得更加隐蔽。

她只下达一条命令。

所有使用大爱盟手段的蛊仙，都必须保留完整副本，事后交由天庭分析。

方源借治疗收集情报。

星宿也要借方源的治疗手段，反推他的气道和炼道进展。

双方围绕每一位伤者，再次展开无声较量。

宝黄天中，谴责方源的声音越来越多。

交易清单上的数字，却上涨得更快。

方源看了一眼结果，便不再关注。

他把所有伤势数据交给气道智囊和炼道蛊仙分组推演。

相同气道侵蚀，在不同流派蛊仙身上表现完全不同。炎道蛊仙会令体内气流升温爆裂，虚道蛊仙则可能在虚实转换时直接化气，木道蛊仙的资源点更会持续产生带气道道痕的变异植株。

这些差异逐步拼出元始爆炸残余威能的完整轮廓。

治疗越多，方源越了解当时自己引发、却未能完全控制的九转爆炸。

这份理解将来既能用于疗伤，也能重新变成杀招。

大爱从来不要求别人喜欢。

只要他们愿意付钱就够了。
