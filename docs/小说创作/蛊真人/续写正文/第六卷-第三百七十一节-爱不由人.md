# 第三百七十一节：爱不由人

赵怜云跟随灵缘斋，一同向神帝城退去。

仙蛊屋摇晃不止。

方源的魂道音浪虽然被其他星位分担大半，剩余威能仍让屋内众仙头疼欲裂。有人鼻孔溢血，有人魂魄震荡，连站立都十分勉强。

赵怜云伤势最轻。

九转爱情蛊寄居在她身上。此前元始复活的惊天爆炸中，正是此蛊自行发动，让她几乎毫发无损。

但她没有因此感到庆幸。

不真子的死，就发生在她眼前。

她明明知道方源是为了逼迫星宿仙尊出手，也知道星宿仙尊若救一人，便可能令更多人陷入危险。

这些道理她都明白。

可是看着一个刚刚还活着的人被抹去，道理并不能让她心中好受半分。

“方源……”

赵怜云死死望着高空中的身影。

她恨方源。

但她最想要的，始终不是杀死方源。

而是取回马鸿运的魂魄。

只要魂魄还在，宿命蛊又已毁灭，就有重生的希望。

眼下方源一面攻击星宿仙尊，一面追杀天庭群仙，还要提防巨阳仙尊和幽魂魔尊。

这是他最分心的时候。

“若错过今日，下一次不知道要等到什么时候。”

赵怜云不再犹豫。

她闭上双眼，将全部心念都集中在马鸿运身上。

北原冰冷的风雪。

两人相依为命的日子。

马鸿运笨拙的笑容。

还有她最后只能眼睁睁看着他死去的无力。

种种记忆从心底升起。

她没有办法炼化爱情蛊，也不能指定爱情蛊一定施展何种威能。

她唯一能做的，就是把愿望尽可能清晰地交给它。

“请你帮我。”

“让我找到马郎的魂魄。”

爱情蛊没有动静。

赵怜云心中渐渐下沉。

就在她以为这次又将毫无结果时，胸口忽然传来一阵剧痛。

她猛地弯下腰，仿佛有一只无形大手探入体内，抓住了某样东西。

下一刻，一点白光从她心口飞出。

白光细若发丝，刚刚出现，便穿透仙蛊屋，径直指向高空中的方源。

“成了！”

赵怜云大喜。

然而白光才飞出百丈，忽然偏转方向。

它没有继续飞向方源，而是斜斜落向天庭废墟深处。

“不！”赵怜云脸色骤变，“不是那里！”

爱情蛊根本不听她的。

白光不断向下延伸，途中穿过数重废墟和紊乱气流，最终没入一片毫不起眼的碎砖瓦砾。

轰隆。

废墟轻轻震动。

一座通体漆黑的宫殿轮廓缓缓显现。

这座宫殿原本被元始爆炸掀翻，又被海量气道道痕和天庭碎片掩埋。宫门上悬着一块残破匾额，只剩下两个尚能辨认的古字。

镇魂。

“镇魂殿！”古月方正率先认出，神情剧变。

镇魂殿曾经关押过幽魂魔尊。

气海老祖的魂魄从气功果中被抽出后，也被星宿仙尊单独关押在这里。

元始爆炸发生得太快，镇魂殿虽有损伤，却没有完全毁去。只是它原本的遮掩手段和周围气道道痕混在一起，就连天庭群仙也未能立即找到。

爱情蛊的白光穿过宫门，没入殿中。

殿内深处，一团被重重锁链包围的魂魄忽然睁开双眼。

正是气海老祖之魂！

他的记忆已被方源提前删除大半，神情木然，几乎没有反应。

但白光缠上魂魄之后，一缕极其隐晦的联系被牵引出来。

这缕联系先指向方源，随后又穿透重重虚空，探向至尊仙窍深处。

赵怜云感应到了这条联系。

她不知道气海老祖是方源分身，也不明白爱情蛊为何选中此处。

但在那条联系的更深处，她感受到了一丝熟悉至极的气息。

马鸿运！

“马郎的魂魄果然还在方源手中！”

赵怜云又惊又喜。

爱情蛊并未替她直接夺魂。

它只是尝试沿着方源与至尊仙窍的联系寻找马鸿运。方源本体有天机混淆、天网恢恢等重重防护，难以直接突破。气海老祖却同样源自方源，又近在天庭，便成了这道威能能够触及的最近节点。

白光越发明亮。

镇魂殿周围的遮掩被迅速剥离。

赵怜云鬓角忽然变白。

随后是第二缕，第三缕。

爱情蛊正在收取代价。

她却没有停止，也无法停止。

高空中，方源神色微变。

气海老祖虽然只是分身，肉身与仙窍又已被他当作炼材牺牲，但魂魄和本体之间仍有极深联系。

这种联系原本被他亲自斩断、遮掩。

爱情蛊却不讲道理地从另一处重新牵起一线。

若任由白光继续深入，至尊仙窍的位置自然不会因此暴露，马鸿运魂魄也不可能轻易被取走。但气海老祖魂魄中的某些炼道布置，却可能被星宿仙尊看出端倪。

方源立即改变攻势。

原本攻向气功果核的灰白龙蛇突然分出一半，直扑镇魂殿。

星宿仙尊也在同一刻出手。

数道星光垂落，一道保护镇魂殿，两道则斩向爱情蛊形成的白线。

她的目的与方源不同。

方源想夺回气海魂魄，或者干脆将其毁去。

星宿仙尊则要保住魂魄，查明气海老祖肉身中究竟被方源做了什么手脚。

两位尊者同时转移注意。

巨阳仙尊眼中金芒暴涨。

他的手掌已经按在气功果核的第一层封护上。

眼下正是毁核的最佳时机！

而秦鼎菱，也终于完成了自己的杀招。

她缓缓摊开掌心。

掌心中躺着一枚虚幻的铜钱。

铜钱一面刻着气功果核，另一面却是一点微弱光芒。

“巨阳仙尊。”

秦鼎菱声音沙哑，传遍战场。

“这一局，你敢赌么？”
