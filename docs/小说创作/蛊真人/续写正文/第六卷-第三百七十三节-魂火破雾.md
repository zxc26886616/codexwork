# 第三百七十三节：魂火破雾

幽魂魔尊记忆残缺，神志混乱。

他已经认不出许多人，也分辨不清眼前局势。

但有些东西，并不需要记忆。

镇魂殿的气息，就像烙印在魂魄最深处的伤痕。宫殿从废墟中显露的一刻，幽魂魔尊无数手臂同时僵住。

下一瞬，三颗头颅一齐怒吼！

声浪在星雾中反复震荡。

星宿仙尊早有准备，星雾层层旋转，将魂啸切分、引导。大半威能被送向天庭之外，剩余部分也被分散到广阔雾海。

幽魂魔尊找不到出口。

但他知道镇魂殿就在某个方向。

漆黑巨臂接连挥舞，每一击都撕开大片星雾。星宿仙尊念头运转，破开的缺口随即弥合。若照此下去，幽魂仍旧会被牢牢困住。

方源自然不会让星宿如愿。

他看了一眼镇魂殿，又看向星雾中的巨大黑影，立即有了决断。

气海老祖魂魄价值极高。

魂魄中虽被删去关键记忆，仍保留气道大宗师的修行积累。更重要的是，这具魂魄曾经完整存在于被方源预处理的肉身中，是研究元始复活和气功果爆炸的最好样本。

但和眼前战机相比，一具分身魂魄也可以继续牺牲。

方源伸出一指，遥遥点向镇魂殿。

灰白炼道光辉凝成一根长针，瞬间跨过战场，刺中宫殿外墙。

星宿仙尊落下的保护星光立即阻拦。

长针只刺入半寸，便被星光定住。

方源却露出笑意。

长针不是为了摧毁镇魂殿。

它只是引子。

针尖刺入之处，一点炼道道痕迅速变化。镇魂殿内，气海老祖魂魄周围的锁链跟着震动。

这些锁链原本属于天庭手段，和方源无关。

但气海老祖的魂魄属于方源分身。方源以炼道尊者的境界，顺着魂魄与锁链之间的接触，开始反炼锁链上的一小部分凡蛊。

他不求打开所有封印。

只需让气海魂魄的气息泄露出去。

咔。

一枚凡蛊破碎。

紧接着是第二枚、第三枚。

宫殿缝隙中，一缕苍白魂气缓缓溢出。

这缕魂气十分微弱。

幽魂魔尊却立即捕捉到了。

气海魂魄曾被天庭抽离、镇压，身上充满镇魂殿的封印气息。同时，他又是方源分身，魂魄本质经过至尊仙体和影宗手段影响。

对幽魂而言，这缕气息既熟悉又陌生。

熟悉的是魂道根源。

陌生的则是方源夺走至尊仙胎蛊后形成的特殊联系。

仇恨、痛苦、贪欲和杀意一齐涌动。

幽魂身上的冷蓝火焰猛地高涨！

他体内的九转火蛊受到刺激，火焰从千万伤口中喷涌而出，烧灼星雾。

星雾本是智道杀招。

智道擅长变化和操控，正面防御并非所长。此前能困住幽魂，是因为星宿仙尊占据天庭主场，又欺负幽魂没有神智，只会在迷雾中胡乱攻击。

眼下幽魂有了明确目标，情况顿时不同。

所有巨臂同时攻向一个方向。

冷蓝魂火也集中烧灼同一处星雾。

星宿仙尊眉头紧皱。

她可以转移镇魂殿。

但爱情蛊的白光仍缠绕气海魂魄，镇魂殿稍有移动，就可能破坏殿中封印。方源也在一旁不断反炼，她若强行转移，很可能让气海魂魄直接脱困。

她也可以斩断爱情蛊的白光。

但九转爱情蛊威能诡异。她刚才连续斩击数次，白光明明断裂，转眼又会从别处重新连接。每次斩断，赵怜云都要付出代价，却也让这道威能产生新的变化。

“方源利用赵怜云的手段，反过来引动幽魂。”

“他对爱情蛊同样无法控制，只是在看清结果后，立即选择了最有利的用法。”

星宿仙尊迅速看透方源的应变。

却无法不作回应。

星雾轰然破裂。

一只漆黑巨手从缺口中探出，五指张开，直接抓向镇魂殿。

天庭群仙惊呼。

星宿仙尊身形一闪，挡在巨手之前。

她抬起右掌，掌心星光汇聚成一面小巧棋盘。巨手拍中棋盘，庞大力量没有爆发，而是被分散成无数细流，沿着天庭智道道痕传向四面八方。

整座天庭残骸再次剧烈震动。

数十片洞天碎片崩裂，向幽天坠落。

星宿仙尊嘴角又溢出鲜血。

她终究有伤在身。

幽魂魔尊一击受阻，更多巨臂却从破口中伸出。冷蓝魂火如同洪水，迅速冲散周围星雾。

星宿仙尊不得不将更多注意力转向幽魂。

困住幽魂的星雾仍未完全崩溃，已经无法像先前那样严密。

气功果核周围的星光也随之薄弱。

巨阳仙尊立即发力。

金镶玉运顺着裂缝深入，整层封护被向外扯开。

方源则同时伸手抓向镇魂殿。

一只灰白大手凭空凝成，五指间炼道光华流转。星宿用于保护镇魂殿的星光，在大手触及的瞬间就开始被层层剥离。

星宿仙尊同时面对三处危机。

幽魂魔尊攻破星雾。

巨阳仙尊撕扯气功果核。

方源争夺气海魂魄。

临时星图虽然还在运转，天庭群仙却只能提供情报，无法替她挡住任何一位尊者。

就在这时，幽魂魔尊其中一颗头颅忽然转向气功果核。

果核外层封护破裂后，浓郁气道道痕和人道生机一同泄露出来。

生机。

对于正在开创杀道的幽魂而言，浓烈生机本身就是最醒目的目标。

他放弃镇魂殿，数千只手臂同时改变方向。

九转火蛊掀起的冷蓝火海，也跟着扑向气功果核。

星宿仙尊脸色终于变了。

她可以暂时舍弃气海魂魄。

却绝不能让幽魂击中气功果核！

星光如海，瞬间从镇魂殿周围退去，全部挡在幽魂和气功果核之间。

方源的灰白大手再无阻碍，一把抓住镇魂殿。

而气功果核的最内层封护，也第一次完全暴露在巨阳仙尊面前。
