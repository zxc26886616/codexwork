# 第三百七十五节：三分遗果

气功果核中的三团核心，分别呈现不同形态。

第一团如同一颗透明心脏。

心脏每跳动一次，就会散发出元始仙尊的意念和人道生机。这是复活过程中刚刚凝聚出来的意识根基，也是元始仙尊此刻能够开口、思考的依凭。

第二团是一枚浑圆气珠。

气珠内部云海翻腾，天、地、人三气相互循环，又混杂着气海老祖毕生积累的气道道痕。它既是气功果复活法的成果，也是方源炼道暗手爆炸后仅存的道果。

第三团最为庞大。

它已经有了模糊的人形骨架，血肉、魂魄和仙窍虚影在其中不断生灭。若复活顺利，这团核心本该成长为元始仙尊的新身。

三者原本紧密相连。

元始意念将生机送给天庭群仙后，连接迅速松动。

星宿仙尊最先出手。

星宿棋盘在她掌心旋转，数十枚棋子同时飞出，围住透明心脏。

她已经明白师父的选择。

完整复活几乎不可能，便先保住元始意念。只要意识根基仍在，未来未必没有其他复活方法。

方源则盯上浑圆气珠。

这枚气珠不仅蕴含气道成果，还记录了气海老祖如何从分身肉身被炼成气功果，再被元始手段改造的完整过程。

对于炼道尊者而言，它就是一份九转复活法的残缺蛊方。

更何况方源已经夺回大半气海魂魄。

魂魄和气珠合在一起，价值还要暴涨。

巨阳仙尊的目标最为单纯。

他不争元始意念，也不在意气道成果。

他只要毁掉第三团人形核心。

只要九转身躯和仙窍无法形成，元始仙尊就不可能在短时间内重返尊者之位。

三尊同时行动。

星光、炼霞、金芒瞬间淹没果核。

星宿棋子刚刚围住透明心脏，方源的炼道长河便横冲而来。

“大爱仙友，你要气道成果，我可以让你一部分。师父意念与天庭因果深重，对你并无大用。”星宿仙尊迅速传音。

方源回应：“星宿仙友此言有理。不如你先把元始意念交给我检查一遍，我确认无用之后，自然归还。”

星宿仙尊不再言语。

方源根本没有交易诚意。

他争夺元始意念，并非一定要得到，而是不愿星宿轻易保住。

只要让星宿多耗费一分力量，巨阳仙尊毁去人形核心的机会就会大上一分。元始无法复活，符合方源利益。

星宿仙尊同样看得明白。

她忽然放弃外围三枚棋子。

三枚棋子被炼道长河卷中，当场炼成粉末。其余棋子却借此变化位置，化作一只星光蚕茧，将透明心脏严密包住。

方源正要继续追击，幽魂魔尊的巨臂已经再次砸落。

他并不在意三团核心属于谁。

浓郁生机正在从果核向天庭群仙流淌，对杀道而言，这就是最醒目的道路。

幽魂巨臂顺着生机流向，一路横扫。

数座仙蛊屋被余波掀飞。

元始意念催动气膜，护住屋中蛊仙，自身所在的透明心脏却因此越发黯淡。

星宿仙尊不得不再次分出星光，阻拦幽魂。

方源趁机改变目标。

他放弃透明心脏，炼道长河回卷，围住浑圆气珠。

气珠和气海魂魄同源。

方源稍一催动，气海魂魄便化作一阵苍白狂风，从镇魂殿碎片中飞出。

星宿先前斩碎了部分魂体，仍有大半保存下来。

爱情蛊的白线依旧缠绕其上。

赵怜云感到白线另一端越来越沉重，寿命快速消耗，鬓发已经白了近半。

她再也支撑不住，跪倒在仙蛊屋中。

“停下，快停下！”灵缘斋蛊仙急忙扶住她。

赵怜云却只盯着白线深处。

她已经借这次机会确认马鸿运魂魄仍在。

若爱情蛊继续消耗下去，她或许会当场老死，也未必能把马鸿运魂魄取来。

“回来。”

她第一次主动放弃。

爱情蛊似乎听见了，又似乎只是恰好结束威能。

白线寸寸消散。

最后一截白光没有回到赵怜云身上，而是没入气海魂魄，留下一个极淡的印记。

方源察觉印记，却没有时间处理。

他将气海魂魄投入炼道长河，和浑圆气珠隔空呼应。气珠剧烈震动，主动脱离果核残骸，向方源飞去。

“休想！”星宿仙尊冷喝。

一道星刃斩向气珠。

方源身前浮现一张半透明巨网。

星刃落在网上，威能被无数网结分散。巨网只是向内凹陷，旋即恢复原状。

星宿仙尊目光一凝。

这道防御远胜方源此前展现的天网恢恢。

她立即推断，方源必定在天网蛊上有了重大突破，甚至可能已经将其升至九转。

但眼下没有时间继续验证。

巨阳仙尊已经攻中人形核心。

他五指并拢，化作掌刀。

仙道杀招——命败运绝！

这记杀招不直接摧毁血肉，而是斩断一件事情继续成功的可能。

人形核心本就接连遭受爆炸、幽魂、方源和巨阳的攻势，能够维持到现在，全靠星宿和元始残余布置苦苦支撑。

掌刀斩落，最后一线复活之运断裂。

人形骨架先是停滞，随后从头部开始崩溃。

尚未成形的血肉化为气流。

仙窍虚影碎成无数光片。

星宿仙尊立即想要收取这些碎片。

方源也催动炼道长河，席卷而来。

元始意念却主动引爆残余气道力量。

轰！

无数光片四散飞射。

一部分飞向天庭群仙，继续加固保护气膜。一部分融入破碎天庭，稳定即将脱落的洞天碎片。剩余部分则在三尊争夺中彻底毁去。

元始宁愿把复活根基用于保护天庭，也不愿让方源、巨阳得到。

巨阳仙尊迅速后退，脸上露出满意之色。

他没有得到任何实质战利品。

但人形核心已毁，元始仙尊完整复活的希望破灭。他此行最大的目标已经完成。

方源将浑圆气珠和气海魂魄一同收入囊中。

星宿仙尊则以星光蚕茧包住透明心脏，退到天庭智道道痕最浓郁之处。

三团核心，三种归宿。

元始复活彻底失败。

但战斗并未结束。

人形核心毁灭后，气道与人道力量四处散去，星宿再没有必须固守原地的理由。

她缓缓抬头，看向方源和巨阳。

星光从天庭各处升起。

方才只能被动防守的智道尊者，终于腾出了双手。
