# 第三百七十四节：元始一念

“好！”

巨阳仙尊大喝一声，金镶玉运全力催动。

气功果核最内层封护猛烈震荡。

这层封护并非星宿仙尊所设，而是元始仙尊三百多万年前留下的复活手段自行凝结。

星宿仙尊可以加固、保护，却无法完全改变其中规则。

巨阳仙尊正是看准这一点。

他不再直接破坏果核，而是利用运道手段，让封护与当今天地不断出现不合。

三百多万年前，太古九天尚未完全破碎，五域界壁仍在，宿命蛊也完好无损。

如今五域合一，两天化为幽天，宿命已毁，天地格局翻天覆地。

元始仙尊的复活手段纵然玄妙，也不可能预见所有变化。

一点点差错被金镶玉运不断放大。

内层封护上很快浮现数道裂纹。

方源同样没有闲着。

他抓住镇魂殿之后，没有立即将整座仙蛊屋收入至尊仙窍。

镇魂殿属于天庭，又经过元始爆炸，内部道痕混乱。贸然收入仙窍，不仅可能引发反制，还会让星宿仙尊顺势感知至尊仙窍门户。

方源五指收紧，炼道光华笼罩整座宫殿。

一枚枚凡蛊被迅速炼化。

爱情蛊形成的白线仍旧缠绕气海魂魄，替他指出最短路径。他便沿着这条路径，集中炼化相应封印。

“赵怜云，你做得不错。”方源忽然开口，“待我取回气海魂魄，不妨把马鸿运的魂魄也一并送你。”

赵怜云心神剧震。

方源当然不会如此好心。

他特意说出这番话，是要扰乱她的心境。

爱情蛊威能与赵怜云的心意密切相关。一旦她生出迟疑、希望或恐惧，这道白线就可能产生新的变化。

“我绝不会信你！”赵怜云咬牙。

话虽如此，她心底仍不可避免地浮现一丝希望。

方源过去曾多次交易，只要价码足够，他的确什么都能卖。

白线轻轻震荡。

原本深入镇魂殿的威能竟分出一缕，再次探向方源。

星宿仙尊见状，立即催动星光斩击。

她已经顾不得保住镇魂殿完整。

星刃穿透宫殿外墙，斩断数十条封印锁链。气海魂魄顿时剧烈震荡，一部分魂体当场崩散。

方源神色不变。

星宿得不到完整气海魂魄，便宁愿先将其毁去。

这是正确选择。

方源心念一动，灰白大手忽然化抓为拍。

镇魂殿被拍得四分五裂。

气海魂魄随着无数碎片飞出，身上还缠着大半锁链。方源早已锁定位置，炼道霞光化作长河，向其卷去。

另一边，幽魂魔尊的攻势也已落下。

数千只漆黑巨手重叠在一起，仿佛一座由手臂组成的山岳，狠狠砸向气功果核。

冷蓝魂火紧随其后。

星宿仙尊挡在最前方。

星光凝成无数纱带，缠绕黑山。每一条纱带断裂，都会将一部分力量引向天庭自然智道道痕。

但天庭已经破碎。

能够承载力量的地方越来越少。

轰！

黑山被星纱削去大半，剩余力量仍然砸中果核外围。

巨阳仙尊早已退开。

他不但没有阻挡幽魂，反而暗中催动运道，让幽魂这一击恰好落在内层封护裂纹最多的地方。

裂纹迅速扩张。

气功果核剧烈摇晃，内部的人形轮廓也随之扭曲。

星宿仙尊眼底闪过一丝痛色。

“师父……”

她很清楚，继续这样下去，气功果核必毁无疑。

但就在这一刻，果核中的人形轮廓忽然睁开双眼。

没有惊天威势。

也没有九转气息。

只是一缕刚刚从漫长沉眠中醒来的意念。

他先看见星宿仙尊。

星宿仙尊鬓发散乱，衣衫染血，身后是破碎的天庭和死伤惨重的群仙。

他又看见幽魂魔尊。

三颗头颅，万千手臂，冷蓝火焰烧遍周身。

最后，他看到了方源和巨阳仙尊。

巨阳气息堂皇，运道手段却在不断侵蚀果核。

方源正以炼道手段争夺一具和果核同源的魂魄。

元始意念只用了一个瞬间，便大致明白了局势。

“复活……失败了么。”

他的声音从气功果核中传出，十分微弱，却清晰落入每个人耳中。

天庭群仙先是一怔，随后不少人热泪盈眶。

“元始仙尊大人！”

“仙尊大人醒了！”

星宿仙尊也有刹那失神。

“师父，是徒儿无能。”

元始意念看向她，露出一丝温和笑意。

“你已经做得很好了。”

这一句话，和三百多万年前没有什么不同。

星宿仙尊心中万千念头短暂停顿，随后又以更快速度运转起来。

“师父，你只需固守果核。徒儿还有办法！”

元始意念却没有立即照做。

他看向破碎的镇魂殿和气海魂魄。

气海魂魄中的记忆已被删除，许多关键处一片空白。但元始仙尊是气道开创者，气功果又正以气海肉身为材料。

只凭两者之间的气机，他便察觉到不对。

“这具身躯，从一开始就是送来的炼材。”

“你以它复活我，便已经落入了炼道手段之中。”

星宿仙尊沉默。

她同样明白这一点，只是直到爆炸发生，才真正确定。

元始意念低头看向自身。

气功果核内部，炼道暗手仍在缓慢运转。即便星宿能够击退三尊，复活过程也未必能继续。

完整复生的可能，已经极其渺茫。

反倒是天庭群仙，仍处在尊者大战的余波中。

临时星图正在迅速收缩。只要星宿再分心片刻，方源便会继续杀人。

元始意念很快做出选择。

他抬起手掌，按向果核内部。

一道极淡的人道气息扩散开来。

这股气息与天庭仙墓、群仙贡献的仙窍，以及神帝城中的无数人意相互呼应。

果核中的生机不再向内凝聚，而是沿着临时星图向外流淌。

撤退中的仙蛊屋纷纷得到一层气膜保护。

重伤昏迷的蛊仙气息也稳定下来。

星宿仙尊神色骤变：“师父！”

元始意念正在牺牲复活根基，保护天庭群仙。

“人活着，天庭才在。”元始意念平静地道。

“一具还未炼成的身躯，不值得让所有人陪葬。”

他说完这句话，果核表面裂纹迅速扩大。

最内层封护轰然崩解。

星宿、方源、巨阳三位尊者，同时看见了果核内部真正的结构。

那里已经不是一个完整人形。

而是三团彼此纠缠、正在分离的核心。
