# 第三百八十节：兄弟再见

古月方正单膝跪在神帝城前。

诛魔榜悬浮在他身后，榜身裂纹密布，血光时明时暗。

“仙尊大人，方源刚刚经历大战，又要镇压战利品。眼下或许是追踪他的最后机会。”

“属下不求击败方源，只求以诛魔榜锁定位置，为仙尊大人提供情报。”

方正语气坚定。

他没有因为愤怒就宣称能够杀死尊者。

双方差距有多大，他亲眼所见。

不真子在方源面前没有任何抵抗之力。秦鼎菱押上寿命和天庭残运，也只能改变巨阳仙尊的一次选择。

诛魔榜虽然克制血道，又能借方正和方源的血脉联系进行侦查，但方源已有九转修为，更有天机混淆遮掩。

方正能做的，只有追踪。

星宿仙尊看向他：“你准备追到哪里？”

方正一怔。

“方源身在幽天，随时可以改变方向。他若进入东海自然炼道道痕范围，你的诛魔榜还能追么？”

“若他故意留下炼道手段引你深入，你能分辨本体与假象么？”

“若幽魂途中出现，你是继续追方源，还是保住诛魔榜中的人？”

三个问题，让方正沉默下来。

他没有足够答案。

星宿仙尊继续道：“方源刚才为何没有杀你？”

方正抬头。

“不是因为他念及血脉，也不是因为他没有机会。”

“你执掌诛魔榜，又和他血脉相连。对方源而言，活着的你比死去的你更容易被利用。”

“你此刻追上去，正合他意。”

方正脸色变幻，最终低下头：“是属下冲动了。”

“有恨意并非错。”星宿仙尊道，“能明知有恨，仍不让它替自己选择，才算真正掌握自身。”

她没有继续责备。

天庭损失太重。

过去，方正只是天意和天庭用来克制方源的一枚棋子。后来他执掌诛魔榜，参与宿命大战，又在多次磨砺中成长，已经能够独当一面。

现在的天庭，不能再把他当作可以随时牺牲的年轻人。

“我另有任务交给你。”

星宿仙尊一挥衣袖，十道身影从神帝城中飞出。

正是人道十子。

他们都只有六转修为，战力不强，刚才救治众仙时却展现出远胜寻常手段的效果。

天庭接下来要以神帝城为核心，人道十子的价值比之前更高。

“诛魔榜最擅侦查，也有血道治疗之能。你带领人道十子，清点所有幸存者和落地仙窍。”

“三日之内，我要知道哪些人还能救，哪些仙窍可以迁入神帝城，哪些地方必须放弃。”

方正立即领命。

这项任务没有追踪尊者那般壮烈，却直接关系天庭能保住多少人和底蕴。

他驾驭诛魔榜赶到第一处落地福地。

福地主人已经陨落，地灵尚未成形，门户却被爆炸撕开。白色气流不断涌入，几名凡人被困在资源点中央。

若按过去天庭的处置，只需先封闭门户、保住仙窍，凡人可以随后救援。

眼下门户随时会整体坍塌。

方正让人道十子先救凡人，自己则催动诛魔榜，以血道手段代替地灵暂时稳定仙窍。

这样做会消耗诛魔榜仙元，也可能让福地失去一部分资源。

赤心行者没有阻止。

“你现在是榜主。”他说，“先保人还是先保福地，由你决定。”

方正望着被救入榜中的凡人，忽然明白星宿为何把这项任务交给自己。

追踪方源只需要执念。

带领幸存者，却要在每一次资源不足时决定谁先得救、什么必须放弃。

这种选择不会比战斗轻松。

他起身进入诛魔榜。

人道十子随之进入。

诛魔榜内部，赤心行者仍在疗伤。

他看着方正，没有询问星宿为何拒绝追击，只道：“榜中刚整理出一份异常血脉记录，你先看看。”

一团血光在方正面前展开。

记录来自气功果核破裂之时。

爱情蛊的白线曾沿气海魂魄和方源之间的联系，短暂探入至尊仙窍。诛魔榜当时距离极近，又全力催动侦查，因而捕捉到数道极其模糊的血脉回应。

最强的一道自然属于方源。

第二道来自方正自身。

除此之外，还有一道陌生回应。

它与方源、方正的血脉十分接近，却又混杂着异人气息，时强时弱，仿佛隔着一层完全不同的天地。

“是方源的后代？”方正首先猜测。

赤心行者摇头：“无法确认。也可能是他以血道炼制的人形生命，或者某个古月族幸存血脉。”

方正仔细感应。

那道回应给他一种说不出的亲近，又混杂着毛民才有的特殊气息。

记录只维持了数息便彻底中断。

方正将其加密存入诛魔榜，没有在此刻打断星宿仙尊的救援调度。

他把这道无法定位的血脉感应列入完成首轮搜救后的第一份密报，又命诛魔榜继续收集相同回应。

星宿仙尊眼下要处理天庭存亡，这条线索优先级不高，却仍和方源有关，不能由他私自压下。

诛魔榜缓缓飞离神帝城。

方正透过榜身，看见无数天庭废墟。

他曾经总是追在方源身后。

追查、愤怒、失败，然后再追查。

眼下星宿让他停下，他反而第一次看清了身后。

那里有无数伤者，有刚刚落成的福地，有等待救援的人道十子，也有一个即将被主动切割的新天庭。

方正收回目光。

诛魔榜血光铺开，开始搜寻第一处幸存气息。

而那份陌生血脉记录中，最后闪过一个极其模糊的人影。

半人，半毛民。
