# 第三百八十六节：第四九转

绣楼中，星光如水。

元始意念所化的透明心脏被安置在最深处，周围布置了三层仙阵。

第一层稳定意识，第二层隔绝幽天，第三层则防备方源残留的炼道手段。

星宿仙尊没有立即唤醒师父。

透明心脏每跳动一次，意识气息就会衰弱一分。眼下天庭没有足够气道和魂道仙材，继续让元始保持清醒，只会加速消散。

她把更多心神放在乎地争夺留下的记录上。

星阵完整保存了天网恢恢和元始气墙碰撞的过程。

半透明巨网共有十二万余处网结。

每一处网结承受的力量都不相同，却能在极短时间内彼此调节，把元始气墙的冲击分摊到整张网上。

若核心只是八转天网蛊，绝无可能做到这种程度。

并非八转仙蛊不能发挥九转威能。

尊者以海量自然道痕加持，或者组合多种八转仙蛊，也能催出超越八转的杀招。

但梦求真出现的位置远离方源炼道主场。

方源本体也没有在场。

这道防御还是提前灌注、一次性外放的手段。经过远距离转移和梦求真使用，威能必然有所损耗。

即便如此，它仍挡住了元始气墙。

答案只剩一个。

杀招中存在九转核心。

“天网蛊。”星宿仙尊轻声道。

方源过去的天网恢恢本就以天网蛊为核心。

如今杀招结构虽然改变许多，最关键的网结仍保留天网蛊特征。

星宿可以确认，方源已经把天网蛊升至九转。

对方源而言，天网蛊是继天元宝皇莲、升炼蛊、天机蛊之后的第四只九转仙蛊。

但前三只始终受到天机混淆遮掩，星宿并不知道这份完整清单。

她眼下能够确认的，只有天网蛊已经达到九转，以及方源隐藏的九转底蕴绝不止外界原先估计的程度。

星宿又把这份结果和天道梦境大战中的记录对照。

当时方源承受她和巨阳联手攻势，防御杀招的恢复速度就曾出现异常。只是战场混乱，幽魂、梦境和多种复合杀招互相干扰，无法分辨异常究竟来自仙蛊升转，还是方源炼化的自然炼道道痕。

如今两份记录重叠，许多无法解释之处都得到答案。

天网蛊很可能早在天道梦境大战之前就已升至九转。

这意味着方源隐藏它的时间，比星宿原先估计更久。

也意味着天机混淆能够遮掩九转仙蛊升炼引发的天地异象。

后一个结论同样重要。

今后天地没有出现异象，不能再作为方源没有炼成九转蛊的证据。

更重要的是，方源炼成第四只九转之后，还能持续参与天道梦境大战、攻打中洲、引爆天庭、围攻星宿并远程争夺乎地。

他表现出来的黄杏仙元消耗极其惊人。

若方源真的仙元短缺，绝不会为了乎地让一记九转防御杀招脱离本体。

“我们此前对他仙元储备的判断，已经错了。”

星宿仙尊没有懊恼。

旧判断并非没有依据。

方源刚刚成尊时，至尊仙窍产出黄杏仙元需要时间，他又要炼化自然炼道道痕、升炼九转仙蛊。任何一项都消耗巨大。

他此前的确应该缺乏仙元。

问题在于这个判断已经过时。

方源必定通过某种方式解决了仙元产出。

可能是九转天元宝皇莲。

也可能是至尊仙窍中的特殊时间流速和资源。

还有可能是他掌握了天庭尚不知道的仙元生产方法。

星宿仙尊把不同可能逐一列出，又将消息分成两份。

她还主动删除了一项无法验证的推测。

方源或许掌握九转仙元生产蛊。

这个猜想能够解释他持续作战，却没有直接证据。若把猜想混入正式情报，天庭成员很可能把它误当成确定事实，反而影响判断。

星宿需要他们提高对方源的估计，不是被所有最坏可能吓得不敢行动。

第一份送给天庭核心成员。

内容只说方源拥有九转天网蛊，今后任何针对方源的行动，都不得再以“仙元不足”为前提，也不得假定这就是他唯一隐藏的九转核心。

第二份则通过宝黄天，以模糊方式传向天下。

星宿没有声称自己掌握方源所有九转仙蛊，更没有公开那些缺乏证据的猜测。

她只放出天网恢恢达到九转层次的证据。

让天下知道方源更强，会提高各方对大爱盟的警惕，也会让巨阳仙尊重新评估。

但若把所有推算结果公开，反而等于免费替方源证明底牌。

消息很快传到巨阳仙尊手中。

他仍在幽天追索光帝君。

血脉感应时断时续，显然受到某种遮掩。巨阳一边追踪，一边查看星宿放出的记录。

“九转天网蛊。”

巨阳脸色难看。

天道梦境一战中，方源的防御就远超预料。当时他和星宿都怀疑方源隐藏了手段，却无法确认核心。

现在一切都有了解释。

巨阳又回想起天庭之战。

方源连续催动复合杀招，争夺气功果核，最后还能收取天庭碎片，从容撤离。

这绝不是黄杏仙元即将耗尽的样子。

“方源很可能早就不缺仙元。”

“至少在相当长一段时间里，他表现出的虚弱和节省，都是演给我与星宿看的。”

巨阳仙尊心中升起寒意。

三尊对峙以来，他许多选择都建立在方源仙元不足的判断上。

包括争夺光蛊、天道梦境之战，以及最初拒绝和方源继续攻打天庭。

结果未必因此错误。

但计算收益和风险的基础已经改变。

他立即向长生天传讯。

所有针对大爱盟的情报重新整理。

所有和方源的交易重新评估。

任何人不得再用消耗仙元的方式试探方源。

星宿、巨阳先后修改判断。

方源经营许久的最大情报优势之一，就此消失。

至尊仙窍中，方源同样得到消息。

他只是看了一眼，没有试图否认。

九转天网蛊已经留下确凿痕迹。

越是否认，越会让星宿和巨阳继续追查其他秘密。

有时候，主动承认一张底牌，可以保护剩下的底牌。

方源甚至让大爱盟公开承认，天网恢恢已经得到“重大提升”。

他没有承认仙蛊转数，也没有否认星宿证据。

这种模糊回应让天下更加相信九转天网蛊存在，同时又无法通过他的口供确认杀招全部结构。

既然秘密保不住，就把秘密变成威慑。

至少他们现在的注意力，都集中在天网蛊和仙元储备上。

而不是方源刚刚得到的气道复活道果，以及仍未公开具体威能的盗天机。

方源继续推算乎地和气海魂魄。

第四九转的秘密已经失去。

只要从这次暴露中取得的收益更大，就不算亏本。
