# 第三百八十五节：夺乎

天庭外围即将切割。

方源必须在此之前取走乎地。

星宿仙尊同样清楚这一点。

她没有把乎地强行拖回天庭主体。

天地秘境体量巨大，又卡在洞天裂层中。强行移动不仅会破坏乎地，还可能令整片外围提前崩塌。

她只加固了周围星阵，并把一缕元始意念送入阵中。

元始是气道开创者。

方源即便以炼道隐藏手段，也很难在他面前完全遮掩对气道道痕的改造。

双方都在等对方先动。

幽天深处，一团梦境缓缓飘向天庭。

梦境只有数丈大小，色彩斑斓，气息时强时弱。

幽天中出现过大量天道梦境，一些残片仍在四处漂流。这团梦境夹杂其中，毫不起眼。

星宿仙尊却没有轻视。

她在天道梦境大战中多次和梦求真交手，对方源的梦道手段已有了解。

星阵放出一道星光，远远扫过梦境。

梦境受到刺激，表面荡起涟漪，内部显现出一位凡人气道蛊师渡劫失败的景象。

景象混乱，规则残缺，像是天然形成的梦境碎片。

星光没有继续攻击。

强行破梦可能让梦境扩张，反而污染星阵。

梦境就这样飘过第一层封锁。

它接近天庭裂层时，忽然向内坍缩。

梦求真的身影从中显现。

方源没有让本体冒险。

他在至尊仙窍远处短暂开启门户，放出梦求真，又提前为其准备了数道防御和撤退手段。

梦求真出现之后，立即化作一道梦光，钻入洞天裂层。

这具梦道分身并非毫无代价。

方源为遮掩他的气息，消耗了数座梦境和一批珍贵梦道仙材。一次性天网恢恢更提前灌入大量黄杏仙元，使用之后便无法回收。

若夺乎失败，梦求真可能被星宿俘虏，方源也会同时失去梦道分身、仙材和一记九转防御。

乎地的价值足以让他承担风险。

天地秘境能够补全气道战斗体系，也能和气海魂魄、复活道果形成完整研究链。更重要的是，方源若不出手，乎地就会被幽天逐步同化，价值不断降低。

这是一个会随时间恶化的机会。

星阵随之发动。

无数星线交织成网，从上下左右同时收拢。

梦光没有硬闯，而是主动分裂成数十团小梦境。

星线切中梦境，立刻被卷入不同梦中。

一部分星线经历凡人婚丧，一部分陷入气道升仙，还有一部分不断重复天庭爆炸。

星阵运转顿时迟缓。

梦求真本体趁机深入。

与此同时，至尊仙窍中的气海魂魄缓缓睁眼。

方源把自身念头灌入魂魄，短暂操纵其气道本能。

乎地在裂层中猛烈震动。

它曾长期受气海老祖催动，对气海魂魄的气息极为熟悉。外界感应到梦求真携带的同源气息后，主动向裂层外移动。

元始意念立即察觉。

“炼道为主，梦道遮掩，气道牵引。”

“方源没有让任何一种手段单独承担全部作用。”

元始意念没有向星宿传递完整解释。

他的意识根基太弱，每一次主动思考都会加快消耗。星宿只给了他一个简单任务：辨认气道道痕中是否混入炼道控制。

他把所有力量都用在这个任务上。

这反而让方源更难欺骗。

智道推算可能受假念、假意和错误情报干扰，单纯的气道感应却只比较道痕本身。方源的梦境可以绕过星宿观察，却无法让已经被炼化的气道道痕恢复原状。

元始意念催动星阵中的气道布置。

裂层内气流忽然逆转。

乎地原本向梦求真靠近，此刻却被一股更加古老的气道力量牵住。

两种感应同时作用，乎地停在裂缝中央。

梦求真伸手抓去。

手掌距离乎地还有数丈，一面无形气墙骤然升起。

气墙上没有星宿仙尊的智道气息。

全是元始手段。

梦道可以污染推算，却无法无视气道道痕的正面阻挡。

梦求真立即后退。

气墙却主动向前，将他和周围梦境一同压向幽天。

星宿仙尊没有只想守住乎地。

她要趁机留下方源最重要的梦道分身。

方源远在至尊仙窍，神情平静。

这个变化仍在预料之内。

梦求真身上忽然浮现一张半透明巨网。

这不是九转天网蛊本体。

而是方源在放出梦求真之前，提前灌注在他身上的一次性天网恢恢。

气墙撞上巨网。

巨网向内凹陷，无数网结同时分担力量。元始气墙威能强大，却失去尊者本体主持，连续冲击数次都未能打破防御。

梦求真顶着气墙，强行向前。

他双手化作梦光，穿过巨网，从两侧包住乎地。

气海魂魄也在此刻全力牵引。

乎地终于脱离裂层！

洞天裂口失去天地秘境支撑，立即向内坍塌。

星宿仙尊催动星阵，所有星线同时聚拢，封锁梦求真退路。

方源早已在另一处准备好至尊仙窍门户。

门户只开启一瞬。

梦求真连同乎地化作一道梦光，穿过重重星线，投入门户。

星宿仙尊的侦查杀招紧随其后。

天机混淆立即发动，稳定的天道道痕网络迅速扰乱星宿对门户去向的侦查。

方源同时关闭至尊仙窍门户，残余空间波动也被层层遮掩。

星宿没有追到方源具体位置。

但元始意念和星阵，已经记录下方才天网恢恢承受气墙时的全部变化。

星光中，半透明巨网的一处网结被反复放大。

那里残留的道痕强度，远远超过八转层次。

星宿仙尊望着这道痕迹，眼中星芒流转。

她没有因为失去乎地而恼怒。

从一开始，星宿便知道以天庭当前状态很难同时保住天地秘境和梦求真。

她布置元始意念与星阵，真正的第一目标是留下梦求真，第二目标才是保护乎地。

两个目标都没有达成。

但方源为了救回分身和秘境，被迫显露九转防御核心。

这一份情报会影响今后所有尊者交锋，价值并不低于一座受损乎地。

此前只是怀疑。

现在，她已经能够确认。

方源至少还有一只九转层次的防御仙蛊！

至尊仙窍中，乎地缓缓落下。

方源成功夺回天地秘境。

代价则是他隐藏许久的第四九转底牌，终于被星宿抓住了确凿痕迹。
