# 第三百八十一节：仙元旧石

灰白碎片穿过幽天，向北原坠落。

尚未真正进入五域，一道血影便从虚空中飞出，将它稳稳托住。

血影凝成一位老者。

正是费雾。

费雾不久前才被巨阳仙尊从血海中复活，修为和仙蛊尚未完全恢复。他此次离开长生天，身上只带着一具血道临时身躯。

这具身躯战力有限，胜在即便毁灭，也不会让本体再次死亡。

巨阳仙尊追寻光帝君，无暇亲自收取沿途碎片，便把任务交给了费雾。

灰白碎片落入血云。

方源留下的炼道印记立即发动。

数道灰光从碎片内部飞出，试图把碎片拖向东南方向。

费雾早有准备。

血云化作无数细丝，缠住碎片中的凡蛊。双方没有直接碰撞，而是围绕碎片控制权展开炼化。

费雾不是炼道强者，很快落入下风。

就在灰白碎片即将脱离血云时，一股金色运势从北原升起。

碎片内部恰好有数枚被血丝控制的凡蛊自行崩裂。

方源炼道手段失去关键节点，运转顿时停滞。

费雾趁机把整块碎片收入临时仙窍。

他没有因此得意。

巨阳仙尊留下的运道手段只能帮助一次。若方源本体真正隔空出手，他立即就会舍弃临时身躯和碎片，避免被顺藤摸瓜。

等候片刻，周围再无动静。

费雾这才检查所得。

几颗仙元石被他从混乱气流中取出。

仙元石色泽灰白，表面毫无出奇之处。费雾却没有关注石头本身，而是反复感应周围残留气息。

他的神色逐渐凝重。

“混元一气子的气息。”

费家最深的秘密，就和混元一气子有关。

这头太古传奇能够从蛊师升仙时的混杂气流中重生。神志清醒时，它能够产生仙元；神志混乱时，则能够凝结仙元石。

元始仙尊曾经将它囚禁、改造，天庭后来流通天下的仙元石，便与此有关。

费雾把这个秘密告诉巨阳仙尊之后，巨阳就一直在寻找混元一气子。

可惜升仙大潮遍布五域。

每一次升仙都会产生天地人三气。混元一气子究竟会在哪一次气流中重生，连巨阳的运道也难以直接确定。

眼下这几颗仙元石周围，却残留着比费家记载更加古老的气息。

“不是混元一气子本体。”

“应当是元始仙尊当年研究它时留下的布置。”

费雾取出数只信道蛊虫，将发现完整记录下来。

他没有直接通过宝黄天传讯。

方源、星宿都在关注残庭碎片，一旦消息泄露，长生天很难独占线索。

费雾催动血道手段。

临时身躯的一根手指自行脱落，化作一只血色小鸟，向北原疾飞。

血鸟不携带文字，只保存一段血脉记忆。除巨阳仙尊和费雾本体外，其他人即便捕捉，也只能得到一团混乱血气。

安排妥当之后，费雾又从碎片中取出一块天庭地砖。

地砖背面刻着极其残缺的气道纹路。

纹路一端连接仙元石，另一端则被爆炸撕断。

费雾沿着断口推算，发现它原本应当通向天庭深处。

那里可能还有更加完整的生产布置。

但天庭外围即将被星宿主动切割，想要潜入其中并不容易。

费雾略一思索，催动血云向北原落去。

他没有前往长生天。

血鸟则在更早之前追上巨阳仙尊。

巨阳仍循着光帝君的血脉气息前行。血鸟靠近后自行崩解，一段记忆落入他的脑海。

他脚步没有停顿，只分出数股念头分析。

混元一气子关系仙元石来源，价值足以改变天下蛊仙的资源体系。

但眼下只有一缕旧痕。

为了它中断追索光帝君，反而可能同时失去儿子和九转光蛊。

“先验证，不要惊动星宿与方源。”

巨阳通过血脉联系给费雾下令。

“若旧痕能在升仙气流中产生反应，就沿所有近年升仙者的地点布置感应。”

“不要只查北原。”

混元一气子可以在五域任何一次升仙中重生。

长生天在北原最有势力，在其他四域却远不如大爱盟和天庭。巨阳决定通过黄金部族商队、血道暗线和宝黄天交易，秘密收集各域升仙气流。

这会很慢。

胜在不容易让另外两尊发现真正目标。

费雾随后落入一处刚刚经历升仙的荒原。

天地二气尚未完全消散，地面还残留着三气混杂形成的雾霭。

费雾将天庭地砖埋入气流中心，又留下一滴自身精血。

若混元一气子能够从类似气流中重生，这块地砖或许会产生反应。

地砖刚刚接触气流，背面的残缺纹路便亮了一瞬。

几缕原本正在消散的天地人三气被纹路吸引，混合成一团灰雾。

灰雾内部没有生命形成，却凝出几粒比沙尘更小的灰白结晶。

费雾小心收取。

这些结晶还算不上仙元石，结构却与仙元石极其相近。

验证成功了一半。

元始留下的纹路确实能把升仙气流转化为仙元石雏形。缺少的部分，很可能就是混元一气子的生命本质和特殊神智状态。

这也证明单靠残纹，无法建立稳定生产。

他们仍需要找到本体。

即便不能，也能帮助他验证元始布置的作用。

费雾做完一切，立即让临时身躯自毁。

血肉、魂魄和所有气息都化作一片普通血水，渗入荒原。

灰白碎片则被血道手段分成数份，分别藏入不同地点。

幽天之外。

星宿仙尊正在回收天庭残片。

她很快发现，那块带有元始气息的碎片已经失去踪迹。

碎片上原本附着方源的炼道印记。

附近又没有明显尊者交手痕迹。

星宿仙尊稍加推算，便得出最有可能的结论。

“方源隔空收走了。”

这个结论合情合理。

她却不知道，方源的确留下炼道手段，最后得到碎片的却是巨阳一方。

一次小小误判，就此进入她接下来的推算。

误判不会立即导致失败。

星宿甚至在结论旁边标注了“尚未证实”。

但今后若再出现混元一气子的线索，她首先会检查方源，而不是巨阳。

巨阳因此得到一段无人关注的时间。
