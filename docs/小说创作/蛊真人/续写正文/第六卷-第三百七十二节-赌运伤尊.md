# 第三百七十二节：赌运伤尊

巨阳仙尊听到秦鼎菱的声音，心头顿生警兆。

他没有回头。

区区一位八转蛊仙，即便燃尽性命，也不可能正面伤到尊者。

但秦鼎菱不同。

她曾被巨阳仙尊亲手安排，作为运道在中洲的一处试验。后来她摆脱控制，反过来钻研如何克制巨阳。

她对运道的理解远不及巨阳仙尊，却对巨阳的手段和习惯十分熟悉。

有时候，最了解一座大山的，不是站在山巅的人，而是多年都在寻找登山道路的人。

巨阳仙尊没有轻视她。

他一面催动金镶玉运，侵入气功果核的气运，一面分出心神察看自身。

他的磅礴气运仍如金色光柱，上接幽天，下镇天庭。

表面毫无异状。

但在金柱深处，一条极细的裂痕正在蔓延。

裂痕的一端连着他按在果核上的手掌，另一端延伸向遥远幽天。

那里正是光帝君所在！

巨阳仙尊神色顿时阴沉下来。

他并不知道光帝君的具体位置。

佑天光吞下光帝君，和左夜灰一同逃走之后，便依靠太古传奇的天生手段隐藏踪迹。巨阳只能确认大儿子仍未死去，却无法将其立即寻回。

秦鼎菱竟借他攻击气功果核的机会，顺着运势找到了这条最脆弱的联系。

“虚张声势！”巨阳仙尊冷哼。

秦鼎菱惨然一笑。

她掌心那枚虚幻铜钱缓缓升起。

仙道杀招——孤注连枝！

铜钱飞到半空，疾速翻转。

每翻转一次，秦鼎菱的气息就衰弱一分。她原本乌黑的长发从根部开始变白，面上皱纹也迅速增多。

这记杀招不是直接削弱巨阳仙尊。

秦鼎菱也没有这样的能力。

她做的是下注。

以自己的寿命、自身气运，以及临时星图中所有愿意保卫天庭之人的一缕运势作为赌注，将巨阳仙尊眼下的两件事强行连接起来。

一件事，是毁灭气功果核。

另一件事，则是那一点远在幽天的光能否继续存活。

两件事原本毫无关系。

但运道最擅长的，正是让没有关系的事情，因为偶然与选择产生联系。

孤注连枝一旦成功，巨阳仙尊越是接近毁掉气功果核，那点光遭遇凶险的可能就越大。

这并非必然。

秦鼎菱无法固定结果，只能提高可能。

若是对付其他尊者，这样的威胁近乎可笑。

但她赌的是巨阳仙尊。

巨阳重视血脉，尤其重视光帝君这位长子。

只要他不能确认光帝君绝对安全，这一点可能性便足以影响选择。

“你在拿天庭残运作赌。”巨阳仙尊声音冰冷，“此招若败，你们这些人的运势都要衰败。就算今日不死，今后也会灾劫连连。”

“天庭都到了这般地步，还有什么不能押的？”秦鼎菱反问。

铜钱翻转得越来越慢。

最终，它在半空停下。

刻有气功果核的一面朝上。

秦鼎菱身躯剧震，猛地吐出一大口鲜血。

杀招成了！

巨阳仙尊立即感到，远方那一点光芒骤然黯淡。

这或许只是杀招营造的假象。

也可能是光帝君真的遭遇了危险。

星宿仙尊是否暗中留有其他手段？方源是否早已找到光帝君？又或者幽魂魔尊此前的异动，正影响着佑天光和左夜灰？

一瞬间，巨阳仙尊心中闪过许多猜测。

他无法验证。

眼下若松手，气功果核便可能被星宿重新护住。若继续催动，光帝君却要承担未知风险。

“秦鼎菱……”

巨阳仙尊杀意暴涨。

秦鼎菱却已无力再战，整个人向后倒去，被诛魔榜射出的血光接住。

她以一位八转之身，当然伤不了尊者。

却真正改变了尊者的选择。

巨阳仙尊五指微曲。

原本向气功果核内部侵蚀的金色运势忽然改变方向，不再一味衰败果核运势，而是将其向外牵引。

他没有彻底放弃攻击。

只是把“当场毁核”，改成了“撕开封护、令果核脱离星宿掌控”。

如此一来，孤注连枝所连接的结果就不再明确，他也能避免把光帝君的生死推向最危险的一端。

这一变招极其精妙。

气功果核外层星光先向内凹陷，随后猛地向外凸起。

咔嚓。

第一层封护裂开一道细缝。

星宿仙尊神色微变。

她此刻一手镇压方源攻势，一手保护镇魂殿，还要维持星雾困住幽魂。巨阳仙尊忽然变招，让她原本的推算出现偏差。

一道星光匆忙回援。

方源却在这时大笑起来。

“巨阳仙友，区区八转就让你畏首畏尾。看来那一点光，对你十分重要啊。”

巨阳仙尊没有回答。

方源并不知道光帝君被佑天光吞下，也不知道九转光蛊正藏在其体内。

但他看到了巨阳气运深处一闪即逝的光线，也看到了巨阳在必胜机会前突然改变选择。

这些已经足够。

“血脉？光道？还是九转光蛊？”

方源心中迅速列出数种可能。

无论真相是哪一种，都意味着巨阳仙尊在幽天中还藏着一处重要软肋。

当然，眼下不是深究此事的时候。

气功果核的封护已经裂开。

镇魂殿也被爱情蛊从废墟中牵引出来。

更重要的是，星雾中的幽魂魔尊忽然停止了咆哮。

一座漆黑宫殿的气息，穿过裂开的星雾，传入他的感知。

幽魂魔尊的三颗头颅同时转动。

六只猩红巨眼，齐齐盯向镇魂殿。

这座宫殿，曾经关押过他。

一股比之前狂暴数倍的杀意，从幽魂魔尊庞大身躯中轰然爆发！
