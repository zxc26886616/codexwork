# 第三百八十八节：战利品账

至尊仙窍中，乎地缓缓落下。

天地秘境体量庞大，外围又遭幽天侵蚀。落入仙窍之后，立即引发气道道痕和幽天残痕冲突。

方源早有准备。

数座气道仙阵同时发动，把乎地周围隔绝开来。梦求真退到远处，气海魂魄则悬浮在仙阵中央，以自身气息安抚天地秘境。

乎地震动逐渐减弱。

它的损伤不轻。

部分外围道痕已经被幽天同化，内部也残留元始和星宿的手段。想要重新用于乎昂杀招，必须先全面检查、炼化和修复。

方源没有急于动手。

他先清点天庭一战的全部所得。

第一项，气海魂魄。

魂体只剩七成左右，关键记忆又被提前删除。它仍能提供气道经验、分身魂魄样本，以及和气海道仙蛊、乎地之间的感应。

爱情蛊留下的印记已经被封锁，没有出现新变化。

第二项，气道复活道果。

浑圆气珠中记录了气海肉身、仙窍如何被炼成气功果，又如何被元始手段转化为九转身躯根基的部分过程。

这是此战最有价值的收获。

它既能帮助方源推算复活法，也能用于改良气道分身、人海和至尊仙体。

但它并不是完整传承。

其中许多关键步骤依赖天庭三百多万年前的气道布置，以及元始仙尊本人的气道境界。方源可以用炼道推演，却需要时间。

第三项，乎地。

天地秘境可以补足气道战斗体系，也能和气海魂魄、复活道果互相印证。代价是修复所需仙材极多，还要防备元始残留后手。

第四项，半座仙墓、天庭碎片和数处资源点。

仙墓中有人道延寿、魂魄保存和压制灾劫的残缺成果。天庭碎片则保留智道、气道、人道自然道痕，可以成为至尊仙窍道脉材料。

第五项，是尸骸、残魂和福地入口。

这些不是天庭战场直接夺得，而是大爱盟在战后交易中持续收购。

数量还在增加。

方源把所有收获换算成仙元、道痕、推算时间和未来用途，形成一份庞大账目。

账目中也记录支出。

天庭一战消耗了大量黄杏仙元。

外放一次性天网恢恢、接引梦求真和乎地，又增加一笔消耗。修复乎地、保存气海魂魄、拆解仙墓都需要持续投入仙材与人手。

大爱盟从灾后交易中得到的利润，短时间内还无法覆盖全部成本。

方源不缺仙元，不代表仙元可以随意浪费。

天元宝皇莲持续产出，也需要时间。四只九转仙蛊各有喂养需求，至尊仙窍的资源经营更从未停止消耗。

此战仍是大赚。

却不是没有成本的凭空增长。

单看任何一项，他都是赢家。

全部合在一起，收益更是惊人。

方源却没有喜悦。

因为这些战利品，仍无法解决至尊仙体最根本的问题。

饥饿。

至尊仙体源自九转至尊仙胎蛊。

它必须定期吞食和自身修为相同的仙窍。

方源如今已是尊者。

七转、八转福地吞得再多，也只能补充资源和道痕，无法满足九转层次的食物要求。

气道复活道果蕴含九转奥妙，却不是完整九转仙窍。

乎地堪比九转仙蛊，同样不是仙窍。

半座仙墓和人道成果能够延缓魂魄、寿命与灾劫，也无法让至尊仙体停止饥饿。

方源催动智慧蛊，围绕现有成果推算数日。

最终得到三个方向。

第一，利用气道复活道果、人海和大量仙窍，人工炼制一个九转层次的空窍外壳。

它不需要拥有尊者意识，只需满足至尊仙体对食物的判断。

问题在于人海尚不完整。

缺少人山，人工空窍无法稳定承载众生经验和人道根基。

并且人道外壳即便达到九转层次，也未必会被至尊仙体视作真正食物。

至尊仙胎蛊的食道缺陷由幽魂和影宗设计，其中判断标准至今未被完全解析。方源必须先用较低层次仙体做试验，才能避免炼出一件价值巨大却无法吞食的成品。

第二，把多个八转仙窍通过炼道强行合一，堆叠到九转层次。

这个方向看似直接，道痕冲突却极其严重。至尊仙窍能够让不同道痕不互斥，不代表作为食物的拼合仙窍也能做到。

若只拼合相同流派，道痕冲突会减少，所需八转仙窍数量却极其庞大。天下八转本就有限，大规模捕杀还会促使星宿、巨阳和所有超级势力提前联合。

这条路线可以秘密研究，不能立刻公开实施。

第三，吞食真正的尊者仙窍。

星宿、巨阳、幽魂。

星宿拥有天庭和中洲组织，最难设局。

巨阳有北原主场与血脉后裔，弱点更加明显，运道却最难保证最后结果。

幽魂没有完整神智，看似容易诱导，又和整个幽天、九转火蛊及新生杀道纠缠。吞下他的仙窍或魂道根基，可能把无穷杀意和幽天污染一并带入至尊仙窍。

没有一个安全目标。

这条路线最危险，也最直接。

方源暂时没有做出选择。

他又检查混沌大难。

后患无穷仍能继续拖延普通灾劫，却无法改变混沌大难越来越近的事实。

仙体饥饿和混沌大难正在同时逼近。

天庭之战取得的资源，可以让方源变得更强，也能为他争取时间。

但不能让问题消失。

就在推算结束时，至尊仙体深处再次传来饥饿感。

比上一次更加清晰。

方源睁开双眼。

他的目光先落在人海之上。

人海波涛起伏，距离完整仍缺少另一半天地秘境。

人山。

随后，他又抬头望向仙窍之外。

幽天深处，星宿和巨阳的气息都已经远去。

两位尊者，便是两个真正的九转仙窍。

方源神情平静。

“看来接下来，要做的事情还有很多。”
