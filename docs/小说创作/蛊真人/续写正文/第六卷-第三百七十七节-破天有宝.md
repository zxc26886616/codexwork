# 第三百七十七节：破天有宝

天庭爆炸，洞天门户破损大半。

数不清的碎片被抛入幽天。

小的不过拳头大小，落入冷蓝魂火，转眼就被烧成灰烬。大的则仿佛山岳，裹挟楼阁、河流和资源点，在幽天中缓缓漂流。

其中一些碎片还残留着天庭意志。

它们试图返回洞天主体，却受到幽天道痕排斥，只能在附近徘徊。

更多碎片失去约束，沿着爆炸余力飞向五域。

天庭经营三百多万年。

即便仙库早被幽魂搜刮，后来又经历宿命大战、疯狂魔窟之战和元始爆炸，残留下来的任何一块土地，也可能埋着上古仙材、古代蛊方或仙蛊屋残骸。

消息很快传入宝黄天。

原本仍在中洲劫掠的四域蛊仙纷纷抬头。

一些人立即放弃手中资源点，冒险进入幽天。一些人则守在五域上空，计算碎片可能坠落的位置。

天庭的威名还在。

星宿仙尊也没有陨落。

没有人敢靠近洞天主体，但对于已经飞出很远、失去天庭气息保护的残片，群仙就没有那么多顾虑了。

一位东海七转蛊仙最先发现目标。

那是一块十余里宽的灰白土地，地面倒插半座石塔，塔中不时传出蛊虫哀鸣。

“仙蛊屋残骸！”

东海蛊仙大喜，立即追去。

他刚靠近百里，侧面忽然飞来一条黄沙长河。

西漠蛊仙现身，二话不说，便向他发动攻势。

两人争斗数回合，尚未分出胜负，灰白土地上空忽然出现一只炼道大手。

大手五指合拢，将整块土地握入掌心。

两位蛊仙脸色大变，立即停战，各自逃遁。

“是炼天魔尊！”

方源本体已经远离天庭，但他沿途留下了数道炼道手段。

这些手段依附在洞天碎片上，可以缓慢炼化其中无主凡蛊，也能在附近有人争夺时向他传递消息。

对寻常蛊仙而言价值极高的仙蛊屋残骸，在方源眼中只能算一笔小利。

但小利也是利。

炼道大手带着灰白土地，跨越幽天，飞向方源预先留下的接收地点。

类似争夺在各处发生。

天庭群仙无力全部回收，方源也不可能把所有碎片收入囊中。长生天、南疆武家、西漠房家和东海各方，都派出了人手。

一场围绕残庭碎片的争夺迅速展开。

幽天深处。

方源一边飞行，一边催动炼道手段。

他刚才从天庭带出的最大碎片，正悬浮在身前。

碎片中有半座仙墓。

墓中沉眠者早已被天庭消耗殆尽，只残留一些仙窍气息和人道布置。元始爆炸将其从天庭撕裂，内部道痕又遭方源收取时的炼道侵蚀，已经无法继续承担复活作用。

方源并不失望。

天庭仙墓最有价值的不只是沉眠者，还有三百多万年来不断改良的延寿、保存魂魄和压制仙窍灾劫的成果。

这些成果与气道复活道果互相印证，能够节省大量推算时间。

“可惜，最重要的部分仍留在天庭。”

方源心中评估。

星宿最后腾出手来，优先护住了绣楼、神帝城、星宿棋盘和元始意识根基。真正核心的仙墓布置也被她用星光强行拖回。

方源夺得的只是残余。

他将半座仙墓送入至尊仙窍，交由智道蛊仙和炼道蛊仙共同拆解。

随后，另一道炼道感应传来。

一块天庭碎片正快速飞向北方。

这块碎片只有数里宽，表面没有任何楼阁和资源，只覆盖着一层混乱气流。

方源先前没有在意。

但炼道手段逐渐侵入之后，气流深处显露出几颗灰白石块。

仙元石。

这几颗仙元石本身没有什么。

真正引起方源注意的，是石块周围残留的一缕气息。

气息古老至极，与元始仙尊同源，却又不像单纯的气道道痕。

“仙元石生产之秘？”

方源立即调动智慧蛊推算。

天庭长期把持仙元石来源。即使到了尊者对峙时期，仙元石的真正生产方法仍未完全公开。

这块碎片很可能只是元始旧有布置的一处边角。

但只要顺藤摸瓜，就可能找到更多线索。

方源正要改变方向，幽天中忽然涌来一阵金色气流。

气流没有攻击他的炼道感应，而是托住碎片，令其速度暴涨。

碎片原本只是向北漂流，得到金色气流助力后，去势快了十倍不止。

“巨阳。”

方源立即明白是谁出手。

巨阳仙尊没有亲自返回。

这股金色气流只是他沿途留下的运道手段。碎片恰好撞入其中，又恰好得到助力，迅速脱离方源最容易拦截的方向。

是巧合，也是运道。

方源若本体追击，自然能把碎片截下。

但这样一来，他就要暂缓处理气海魂魄，还可能沿途遭遇幽魂或巨阳的后手。

几颗仙元石和一缕未知气息，还不值得他立即暴露更多手段。

方源又推算碎片上的金色气流。

这道运道手段并非刚刚施展，原本就潜伏在巨阳撤退经过的路径上。换言之，巨阳在赶去寻找血脉光芒的途中，仍没有忘记布置手段争取残庭利益。

“他虽然急于寻找那处软肋，心神并未乱。”

方源据此修正对巨阳状态的判断。

若巨阳因光帝君彻底失去冷静，反而更容易对付。

眼下对方仍能随手留下这种布置，就说明血脉光芒虽然重要，还没有重要到让一位尊者放弃所有其他收益。

方源没有追。

他只是加强碎片上的炼道印记，让它继续传回模糊感应。

灰白碎片越飞越远，最终穿过幽天，向北原方向坠去。

在那里，已有一道血色身影等候多时。
进入幽天争夺残片的蛊仙越来越多。

他们很快摸索出一些规律。

带有浓厚星光的碎片最危险。这类碎片往往仍受星宿仙尊感应，刚有人接近，便会自行改变方向，或者放出星道杀招。

完全失去气息的碎片也未必安全。

一块看似普通的天庭泥土忽然裂开，放出被封存数十万年的上古荒兽。争抢它的三位蛊仙当场一死两伤，荒兽随后又被幽天气息侵蚀，发狂冲入中洲。

真正容易获取的，是那些体量不大、仍保留资源异象，却没有天庭意志维持的残片。

许多散仙不再各自行动，而是在宝黄天临时结盟。

有人负责推算坠落路线，有人负责抵御幽天魂兽，还有人专门在得到残片后切割分配。

盟约大多只能维持一次争夺。

残片到手，原本并肩作战的蛊仙转眼就会为了分配大打出手。

方源的炼道感应穿梭在这些争夺之间。

他不是什么都取。

价值不够的碎片，就留给天下蛊仙互相消耗。带有明显星宿手段的碎片，则先让他人触碰，观察反应之后再决定是否出手。

只有仙墓、秘库、气道布置和高价值仙蛊屋残骸，才值得他隔空催动炼道大手。

如此一来，方源收取的数量并非最多，价值却始终居于首位。
