# 第三百七十节：众生作子

巨阳仙尊通体金光闪耀。

他的攻势看似猛烈，心中却始终保持冷静。

方源宣布屠杀天庭蛊仙，巨阳仙尊并未附和。

他也不需要附和。

方源杀得越狠，星宿仙尊需要分出的心力就越多。只要气功果核被毁，元始仙尊无法复活，他此行的目的便已达成。

至于天庭群仙死多少，和他没有直接关系。

但让他亲自动手屠戮这些无力反抗之人，又是另一回事。

正如方源此前所料，巨阳仙尊还要为将来留有余地。他的血脉后裔遍布北原，不可能像方源一样毫无牵挂。

此时天庭仙蛊屋纷纷退向神帝城，星宿仙尊的防线随之扩张。

巨阳仙尊立即发现机会。

“方源，我来毁去果核。你若真有本事，就替我牵制星宿！”

他大喝一声，双掌猛地合拢。

万千金芒从他身上飞起，在高空凝成一头巨大的金色公鸡。

金鸡昂首啼鸣。

声音并不响亮，却令气功果核周围的星光微微摇曳。

这不是寻常音道手段，而是运道变化。金鸡每鸣叫一次，气功果核周围便有一处星光莫名黯淡，仿佛运转时恰好出现了微不足道的差错。

星宿仙尊立即催动念头，修补这些差错。

方源见状，攻势越发猛烈。

他又向下方洒出大片灰白光点。

这些光点落在仙蛊屋上，并不直接爆炸，而是迅速附着、蔓延，企图残炼构成仙蛊屋的凡蛊。

一旦凡蛊大规模受损，仙蛊屋杀招就会失去平衡。

星宿仙尊依旧只拦截最危险的一部分。

她似乎完全不在意中洲蛊仙的伤亡。

但那些正在撤退的仙蛊屋，已经悄然生出变化。

秦鼎菱所在的仙蛊屋最先亮起金光。

这股金光与巨阳仙尊的堂皇光辉不同，十分黯淡，还夹杂着一层灰败之色。随后诛魔榜亮起血光，残阳老君所在的仙蛊屋燃起一豆灯火，赵怜云身边则浮现出一圈近乎透明的白晕。

一种种光辉颜色各异，气息也互不相同。

它们唯一的共同之处，就是极其微弱。

任何一道光辉，都不足以挡住方源随手一击。

然而这些光辉随着仙蛊屋移动，彼此连接起来，竟形成一幅不断变化的星图。

星图中央正是神帝城。

群仙身上的情绪、意志、伤势和气运，都沿着星图汇聚过去。神帝城壁画世界中，无数人物画像自行浮现。有人恐惧，有人愤恨，有人哀悼，也有人依旧在废墟中救治伤者。

元莲意志站在壁画世界上空，仰望这些不断增多的人影。

“以人为星，以意为光。”

“星宿仙尊借神帝城的人道根基，临时弥补漫天繁星精算阵的缺损。”

他很快看清星宿仙尊的用意。

原本的漫天繁星精算阵覆盖整个中洲，采集山川万物的讯息，再由星宿仙尊统一推算。

眼下大阵毁去八成，天庭又被炸得支离破碎，旧阵自然无法重现。

星宿便退而求其次。

她不再计算中洲万物，只计算眼前这些活人。

每一位蛊仙都是一颗星辰。

他们遭遇何种攻势，产生何种情绪，伤势如何变化，下一刻会选择躲避还是抵抗，全部成为星宿仙尊推算方源的依据。

方源再杀一人，的确能削弱这座临时阵势。

但被杀者临死前承受的手段、产生的情绪，以及附近之人的反应，也会被星宿仙尊收集。

方源杀得越多，暴露的手段便越多。

他以群仙性命测量星宿的防线。

星宿也以群仙性命测量他的攻势！

“好一个星宿仙尊。”方源心中赞叹。

换作旁人，即便拥有智道手段，也很难在如此短暂的时间内，把一群重伤残兵组织成阵。

星宿却能做到。

并且她没有事先向群仙解释。

一旦解释，众仙便会刻意控制情绪和行动，采集到的情报反而失真。只有让他们按照本心逃亡、愤怒、恐惧，临时星图才能准确反映方源攻势的影响。

“可惜，你护得住他们一时，护不住他们一世。”

方源攻势骤然一变。

他不再追逐单独的仙蛊屋，而是催动魂道音波，令整幅星图同时震荡。

只要群仙的魂魄和念头一齐受到干扰，星宿收集到的情报就会变得混乱。

粉色音浪铺天盖地。

星宿仙尊伸手一点。

临时星图中的一座仙蛊屋忽然偏离路线，主动承受大半音浪。屋中数位蛊仙魂魄震荡，当场昏死过去，仙蛊屋也从空中坠落。

其余星位却因此保存下来。

方源神色平静。

星宿再次证明，她不怕牺牲。

只要牺牲能够换来更大的收益，她甚至会主动选择谁去承受。

此时，巨阳仙尊的金鸡已经啼鸣九次。

气功果核外层的星光接连出现九处薄弱。

巨阳仙尊等候已久，身形猛地消失。

下一刻，他出现在气功果核上方。

仙道杀招金镶玉运！

他的右手变得半透明，掌心金光流淌，五指却如白玉雕成。手掌没有爆发惊天威势，而是轻轻按向果核。

气功果核周围明明有重重星光阻拦，巨阳仙尊的手掌却总能恰到好处地避开最强之处，从九处薄弱点之间一路穿行。

星宿仙尊立即回身。

方源却同时加紧攻势，将她拖住。

“星宿仙友，你若再顾着元始，下面那些人可就一个都活不了了。”

星宿仙尊没有回应。

她一边抵挡方源，一边催动星光回援果核。

但是迟了一线。

巨阳仙尊的玉白五指，终于触碰到气功果核外的第一层封护。

没有爆炸，也没有轰鸣。

那层封护只是泛起一圈金色波纹。

巨阳仙尊眼中却闪过喜色。

他的手，已经搭上了气功果核的气运。

只要顺势一扯，就能令元始复活仅存的希望迅速衰败。

也就在这一刻，远处的秦鼎菱睁开双眼。

两行鲜血从她眼角流下。

她透过临时星图，看见了一条旁人无法看见的运道轨迹。

这条轨迹从巨阳仙尊掌心延伸而出，一端缠绕气功果核，另一端则没入遥远幽天。

轨迹尽头，有一点极其微弱、却始终不灭的光。

秦鼎菱缓缓抬起手掌。

她终于锁定了巨阳仙尊最不愿押上赌桌的东西。
