# 第三百七十八节：残庭新主

神帝城悬浮在天庭废墟上空。

城门大开。

一座座残破仙蛊屋依次进入，伤者被人道十子和城中蛊师迅速接走。

壁画世界中，原本宁静的街巷已经变成临时营地。凡人、蛊师、蛊仙分处不同区域，医疗、人手和仙材都由元莲意志统一调度。

天庭群仙进入神帝城后，终于有了片刻喘息。

但没有人感到轻松。

伤亡统计不断送到星宿仙尊面前。

中洲十大古派在天庭中的蛊仙，十不存一。

天庭成员依靠更强手段和更靠内的位置，存活者稍多，仍有数位彻底陨落。大量仙窍落地，形成福地、洞天，又在爆炸和尊者大战中遭受二次破坏。

仙蛊屋损失同样惨重。

有的只剩一个空壳，有的核心仙蛊自毁，有的勉强保住，却需要数十年才能修复。

更麻烦的是天庭洞天本身。

爆炸形成的裂口仍在扩大。

幽天气息从外界不断渗入，和残存的白天气息互相冲突。每时每刻都有洞天碎片脱落，向外漂流。

照此下去，即便方源等人不再进攻，天庭也会自行崩解大半。

“仙尊大人，应立即封闭所有门户，召回碎片！”一位天庭蛊仙提议。

另一人摇头：“门户损坏太重，强行封闭会让洞天内外压力失衡。届时崩裂得更快。”

“方源正在收取天庭碎片，再迟一些，损失只会更大！”

“眼下最重要的是救人。许多福地刚刚落成，地灵还未稳定，其中可能有幸存魂魄。”

“不，元始仙尊大人的意识根基才最重要。只要保住它，未来仍有复活希望！”

意见很快分成数派。

追敌，救人，守住资产，修补洞天，保护元始。

每一件都很重要。

天庭过去底蕴雄厚，可以同时调动人手解决。如今人员、仙元和仙材都接近枯竭，只能选择先后。

群仙最终看向星宿仙尊。

星宿仙尊面色依旧苍白。

她怀中悬浮着星光蚕茧，内部透明心脏缓慢跳动。每跳一次，气息都会衰弱少许。

星宿仙尊已经推算过所有选择。

追击方源，夺回战利品的可能不足一成。即便成功，也很可能令天庭主体继续崩毁，元始意识消散。

全力修补洞天，需要的宇道和气道仙材远超库存。向十大古派强行征调，只会把本就重伤的中洲各派一并拖垮。

保住所有落地仙窍，则要让大量蛊仙离开神帝城。方源、巨阳或幽魂只需折返一次，这些人就会成为新的损失。

没有完美选择。

她能做的，只是让天庭在最坏局面中保住未来价值最高的部分。

她先下令：“人道十子留在神帝城，救治伤者。诛魔榜负责搜寻仍有生机的仙窍，不得追击方源。”

古月方正欲言又止。

星宿没有停顿：“九灵仙姑、车尾带人回收距离最近的洞天碎片。只取可迅速收回者，不得深入幽天。”

“其余人清点绣楼、监天塔残骸和仙库。凡是无法移动之物，先做标记，不得为一处资源冒险。”

一连串命令迅速下达。

有人领命，有人却仍面露不甘。

“仙尊大人，难道就任由方源带走天庭重宝？”

“是。”星宿回答得十分平静。

群仙一怔。

星宿继续道：“方源已经离开天庭主场。追击他，需要我亲自出手。”

“我若离开，谁来稳定洞天？谁来保护师尊意念？谁来防备幽魂折返、巨阳去而复返？”

“以眼下天庭状态，追上方源也无法保证夺回战利品。”

“既然如此，就先记下这笔债。”

群仙沉默。

道理很简单。

只是要亲眼看着三百多万年的天庭被方源拆走，谁都难以接受。

赵怜云被人搀扶着经过大殿外围。

她半头白发，气息衰弱，仍坚持询问搜救者是否发现不真子残魂。

得到否定答案后，她没有说话，只继续向神帝城内走去。

另一边，残阳老君拒绝进入疗伤仙阵。他想先回到爆炸外围，寻找仙鹤门失踪蛊仙。

星宿的命令传到后，他站在原地良久，最终还是转身入城。

这些人的反应，都被星宿看在眼中。

强行压下不甘并不代表不甘消失。

新天庭若继续用过去的方式要求十大古派无条件牺牲，组织内部迟早会先于外敌崩溃。

所以收缩的不仅是洞天土地，也必须包括天庭能够直接控制的范围。

星宿仙尊却没有让情绪影响判断。

她抬头看向残破洞天。

过去的天庭，依靠吞并太古九天碎片不断壮大。广阔洞天、海量道痕和深厚仙库，让历代成员拥有天下第一的根基。

如今这些优势变成负担。

洞天越大，需要修补的位置就越多。

资产越多，需要守护的人手也越多。

天庭已经无力维持原本规模。

“放弃外围七成区域。”星宿仙尊忽然道。

群仙震动。

“以神帝城为人道核心，绣楼为智道核心。保留两者之间的洞天区域和自然智道道痕。”

“其余区域只回收仙蛊、核心传承和可移动资源。”

“三日之后，主动切割洞天。”

星宿又补充道：“所有被放弃区域的地图、资源记录和传承目录，全部复制入神帝城。”

“土地可以失去，知道自己失去了什么，同样重要。”

只要记录仍在，将来便有夺回或重建的可能。

若连记录都随废墟消失，三百多万年积累才是真正断绝。

切割洞天，意味着天庭将永久失去大片土地和自然道痕。

这是三百多万年来从未有过的决定。

“仙尊大人！”一位老蛊仙跪倒在地，“天庭乃人族圣地，岂能主动割弃？”

星宿看向他：“若为了保住一片空地，让剩余所有人一同陪葬，这片土地还算人族圣地么？”

老蛊仙无言以对。

星宿又看向神帝城。

元始意念苏醒时说过，人活着，天庭才在。

星宿不会因为师父一句话就改变决策。

但这句话和她的判断一致。

天庭眼下最重要的资产，不是破碎洞天，而是仍活着的人、神帝城中的人道成果、绣楼以及残余智道道痕。

只要这些还在，就有重新发展的可能。

秦鼎菱、赵怜云等人的位置被迅速安排。

星宿仙尊最后下令：“所有未领取任务者，进入神帝城。”

“接下来三个时辰，任何人不得擅自离城。”

群仙互相看了看。

这一刻，他们必须接受一个事实。

过去那个可以庇护整个中洲、号令十大古派的天庭，已经不存在了。

他们要守护的，是一个缩小到神帝城、绣楼和少数残地的新天庭。

也就在此时，神帝城外传来诛魔榜的轰鸣。

古月方正没有立即执行入城命令。

他驾驭诛魔榜停在星宿仙尊面前，单膝跪下。

“仙尊大人，方正请命。”

“追踪方源！”
