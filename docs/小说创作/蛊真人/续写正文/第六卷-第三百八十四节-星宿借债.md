# 第三百八十四节：星宿借债

天庭需要仙材。

大量仙材。

修补洞天需要宇道、气道仙材。

救治伤者需要人道、木道、光道仙材。

保存元始意识根基，则需要更珍贵的智道、魂道和气道资源。

过去的天庭不会为这些发愁。

三百多万年底蕴，中洲十大古派持续供养，还有遍布天下的影响力，足以解决绝大多数问题。

如今仙库接近枯竭，十大古派损失惨重，中洲资源点又被方源和四域蛊仙大肆搬走。

星宿仙尊只能向外求援。

她没有用天庭名义号召天下共抗魔尊。

这样的口号仍然有用，却换不来足够仙材。

方源刚在天庭展露疑似第四只九转仙蛊的底牌，又有大爱盟遍布五域。其他势力即便同情天庭，也不会无偿得罪方源。

星宿拿出了真正筹码。

第一项，是衍化大阵产生的部分成果。

丹道蛊方、兵道杀招、画道心得、人道治疗法门，按照价值分成不同层次。

第二项，是神帝城的学习名额。

各域势力可以派遣年轻蛊仙进入壁画世界修行。天庭不要求他们加入，也不强迫上交完整所得，只在特定成果上保留优先交易权。

第三项，是星宿仙尊本人的推算机会。

提供足够仙材者，可以请她推算一次灾劫、杀招缺陷或失踪仙蛊线索。

尊者亲自推算，价值极高。

条件传出后，天下各方立即重新评估。

南疆武家最先收到单独传讯。

武庸坐在武仪山大殿中，浏览条件，久久不语。

武家并不缺普通仙材。

他真正感兴趣的是神帝城名额和衍化大阵的兵道、人道成果。

南疆家族制度重视血脉，组织效率却始终比不上中洲门派和北原黄金部族。兵道、人道若能提高蛊师军队和家族凝聚，对武家扩张极有帮助。

“天庭也有低头借债的一日。”一位武家蛊仙感叹。

武庸摇头：“星宿不是低头，是在用已经无法继续独占的东西，换取眼下最缺的时间。”

衍化大阵毁去八成。

天庭就算想继续封锁成果，也难以保住绝对优势。

与其将来被方源盗走、被其他势力破解，不如趁现在主动出售，换取仙材和政治承认。

武庸看得清楚。

所以他没有压价太狠。

他提出三个条件。

天庭承认武家对中洲南缘三处资源点的临时占有；南疆蛊仙进入神帝城后不受强制征召；天庭向武家开放一部分兵道训练成果。

作为交换，武家提供一批宇道仙材和两座可移动资源点。

条件很重，却在星宿可能接受的范围内。

另一份传讯送往西漠林家。

林剑行看完之后，只问了一句话：“九灵仙姑呢？”

天庭围攻林剑行时，九灵仙姑曾被他俘虏。后来双方围绕薄青、剑道和气海布局达成暂时交换，她才得以返回天庭。

眼下九灵仙姑重伤，却仍活着。

星宿给林家的条件不是人道名额。

而是天庭研究薄青剑道时留下的一部分记录，以及对林剑行体内天外剑道道痕的分析。

林剑行是天外之魔。

他自创剑道体系，走到亚仙尊层次之后，每前进一步都极其艰难。天庭记录未必正确，却能提供另一个观察角度。

作为交换，星宿要求林家提供剑道仙材，并请林剑行在天庭切割洞天时出手一次。

不是保护天庭。

只是用剑道斩断最危险的洞天裂层。

林剑行没有立即答应。

他要求天庭先公开澄清此前对林家的指控，并承认林家不受天庭统辖。

天庭过去不会接受这种条件。

如今，星宿却在片刻推算后传回两个字。

“可谈。”

武家和林家只是开始。

东海沈家、西漠各族、南疆超级势力，甚至北原个别非黄金部族，都收到不同报价。

各方回应并不相同。

沈家愿意提供人道仙材，却要求沈伤可以自由查阅神帝城中的部分人道记录。

西漠数个家族提出共同援助，条件是天庭停止支持讨房联盟。星宿没有立即同意，只把条件列入下一轮交涉。

北原非黄金部族最为谨慎。

他们既怕巨阳认为自己勾结天庭，也怕方源通过大爱盟施压，只愿借商队匿名出售仙材，不接受神帝城名额。

星宿对这些选择一一记录。

谁愿意公开帮助，谁只愿秘密交易，谁趁机提出领土和政治条件，都是未来五域格局的重要情报。

借来的不只是仙材。

也是各方在天庭衰弱之后暴露出来的真实态度。

天庭不再以天下人族领袖的身份要求服从。

它用知识、推算和神帝城名额借取资源。

每一份契约都意味着天庭让出一部分过去的权威。

也让它在五域中重新织起一张更松散的关系网。

这种关系网远不如过去稳定。

天庭若继续衰弱，契约方随时可能退出。方源若开出更高价格，也会有人转投大爱盟。

但它不需要所有人忠诚。

只要契约能够让新天庭度过最缺乏仙材的数年，星宿就有机会重建阵法、培养人道十子，并继续保存元始意念。

神帝城中，元莲意志看着不断送来的契约，轻声道：“这些人不是天庭下属。”

星宿仙尊道：“不必是下属。”

“只要在方源吞并天下之前，他们仍愿意让天庭存在，就足够了。”

两道回复几乎同时抵达。

武庸愿意提供第一批仙材，但要先确认三个条件。

林剑行愿意斩出一剑，但要求天庭先还林家清白。

星宿看着两份回复，开始分别修改契约。

天庭第一次不是向天下发号施令。

而是在借债。
