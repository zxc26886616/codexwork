# 第三百一十八节：天机不可测

东海。

海面晦暗，浪潮在黑夜中起伏不休。

太阳毁灭之后，五域再无昼夜之分。远处偶有炎道仙材坠落，拖曳出赤红长尾，只能照亮一小片海域，旋即又被无边黑暗吞没。

方源盘坐云端，身形隐于重重手段之后。

他的心神大半沉入至尊仙窍。

四元方悔血炼池上空，一只九转仙蛊静静悬浮。它气息内敛，却令周遭天道道痕缓缓聚拢，仿佛天地之间的隐秘都在向它靠近。

九转天机蛊！

方源没有急着试用。

蛊虫炼成只是第一步。如何喂养，如何催动，如何编入杀招，才真正决定它的价值。

八转天机蛊能够询问天地，探查已经发生之事，甚至提前知晓灾劫内容。然而天地知道，并不等于蛊修一定能够得到答案。

天地混乱，答案也会混乱。

况且，尊者本身便能干扰天地。涉及星宿、巨阳、幽魂，天机蛊所得的结果必然残缺不全。

方源对此早有准备。

一份份天道仙材被调取出来。

两天混淆以来，沈伤四处搜集，至尊仙窍内部也在不断产出。如今为了尝试九转天机蛊，方源取用起来毫不吝惜。

黄杏仙元徐徐消耗。

九转天机蛊微微震动。

无形波澜从至尊仙窍中扩散，数息之后，又尽数收拢到蛊虫周围。

方源首先询问的，并非幽魂魔尊，也不是星宿、巨阳的底牌。

他选择的是至尊仙窍下一次灾劫。

这是天机蛊最擅长的领域，又直接关系自身，受到的干扰最少，正适合用来验证威能。

片刻后，一段模糊天机在方源心中展开。

黑云、残日、无数羽毛，以及一条从天穹垂落的苍白长河。

种种景象转瞬即逝。

方源面无表情，脑海中念头交汇，迅速推算。

“灾劫的规模有所上涨，与我炼成第三只九转仙蛊有关。”

“黑云和残日，应当受到两天混淆、太阳毁灭的影响。羽毛所指尚不明确，苍白长河或许和宙道有关，也可能只是天意故布疑阵。”

天机蛊只是揭露天地所知，并不会替蛊修完成推算。

所得天机越多，若无足够境界和智道手段梳理，反而越容易被纷杂表象误导。

但对方源而言，这不是问题。

他又接连尝试数次，从至尊仙窍中的资源点，到东海火雨的分布，再到两天融合的速度。

每一次所得都和既有情报互相验证。

九转天机蛊本身并无错漏。

真正的限制仍旧是使用者、天地现状，以及问题触及的层次。

方源随即将目标转向幽魂魔尊。

这一次，九转天机蛊沉寂了十几个呼吸。

天道仙材的消耗陡然加剧。

方源心念一动，立即中止催动。

他只得到三个极其破碎的景象。

第一幕，是火焰在漆黑海水中燃烧。

第二幕，是一只巨口吞咽火焰，却从口中飞出无数灰白魂魄。

第三幕最为模糊，仿佛无边黑夜裂开一道缝隙，缝隙之后既没有光，也没有火，只有难以言喻的深沉死寂。

“直接询问尊者，耗费果然庞大。”

“幽魂神志混乱，又吞下野生九转火蛊，自身状态不断变化。天意对他的了解，也并不完整。”

方源没有强求。

这次试探已经达到目的。

九转天机蛊能令他在情报上取得巨大优势，却并非无所不知。若是仗着此蛊肆意窥探尊者秘密，只会迅速消耗天道仙材和黄杏仙元，甚至惊动对方。

任何强大的手段，都有使用的边界。

边界同样可以被利用。

方源的注意力转向天机混淆杀招。

原版杀招以天网蛊为核心，消耗天道仙材，在身上覆盖渔网般的临时天道道痕。有人侦查推算时，道痕便自行变化，让对方得到错误结果。

方源先后将多只天道仙蛊掺入其中，早已把杀招改得面目全非。

如今有了九转天机蛊，一切又不相同。

九转天机蛊不只可以成为核心，更能提前感知天地变化，令这张“渔网”顺应外界情报，自行编织出更加合理的假象。

过去的天机混淆，是让敌人看错。

方源现在要做的，则是让敌人看到他们最相信的答案。

大量念头升腾碰撞。

一只只蛊虫被调动，形成繁复轨迹。方源先拆解原有杀招，再把九转天机蛊嵌入核心，天网蛊退居辅助。

这个过程并不艰难。

天机蛊方本就是方源亲自改良，他在炼蛊时便积累了充足成果。半个时辰之后，新版杀招已有雏形。

但方源并未因此喜悦。

他身上如今已有三只九转仙蛊。

天元宝皇莲、升炼蛊、天机蛊，任何一只暴露，都足以改变三尊对峙的格局。需要天机混淆遮掩的秘密越多，临时天道道痕便消耗得越快。

九转天机蛊能够增强杀招，却不能凭空消除代价。

“还需要继续改良。”

“不仅要误导侦查，还要让三只九转仙蛊在天机中互相遮掩，避免各自形成独立异象。”

方源心中逐渐有了方案。

九转仙蛊越多，遮掩负担越重。但若将三蛊在天机中伪装成一个整体，消耗便能削减许多。

天元宝皇莲提供仙元，升炼蛊辅助炼蛊，天机蛊遮掩秘密。

三者本就因炼道而联系紧密。

方源要让天地以为，这些异象全部来自他炼化东海自然炼道道痕时的失败和停滞。

如此一来，星宿和巨阳每一次侦查，都只会更加确信他仙元不足。

当然，这只是第一层假象。

若敌人识破这一层，还要有第二层、第三层，甚至需要留出一处故意暴露的破绽。

方源从不指望一项手段永久有效。

他只需要比敌人更早一步。

中洲。

漫天星辰在黑暗里越发耀眼。

失去太阳之后，中洲上空的星海成了五域最壮观的光源。无数凡人因此向星辰跪拜，天庭和十大古派的声势随之高涨。

星宿仙尊仍在绣楼中。

漫天繁星精算阵送来海量情报，经过分类、筛选，最终汇成数百条需要她亲自处理的事项。

其中一条，正与方源有关。

东海炼道道痕的炼化速度依旧缓慢。

天地一家大爱盟仍在收购资源，并以贡献兑换炼蛊机会。方源虽然借火雨大肆获利，但从宝黄天的交易规模推算，所得大半又被投入至尊仙窍。

几项结果互相印证。

漫天繁星精算阵给出的结论十分清晰：方源仙元不足，只能优先恢复仙窍底蕴，短时间内无力大规模炼化自然道痕。

这与星宿仙尊原本的判断完全一致。

她却没有立即略过。

“太过顺利了。”

星宿仙尊眼中星芒微闪。

方源一直擅长遮掩。疯魔窟中，他直到最后关头才暴露炼道无上大宗师境界，瞒过了所有尊者。

眼下这些情报没有任何矛盾，但“没有矛盾”本身，并不能证明方源毫无隐瞒。

星宿仙尊分出数股念头，从另一方向重新推算。

她不再推算方源拥有多少仙元，而是推算方源接下来最可能做什么。

答案很快出现。

幽魂魔尊。

方源是炼道尊者，九转火蛊对他的吸引力不言而喻。即便仙元短缺，他也绝不会错过这个机会。

“那么，就看他愿意付出多少了。”

星宿仙尊暂时压下疑虑，向巨阳、方源分别传出一道消息。

她提议三尊联手，共除幽魂。

同一时刻。

北原与西漠交界处，黑暗凝聚成一头庞大巨人。

左夜灰摊开手掌。

陆青冥、苏光二仙立在掌心，脸色难看至极。

“长生天入口并无定处，外人若无黄金血脉接引，几乎不可能潜入。”陆青冥沉声道，“我们只是散仙，知道的都已经说了。”

左夜灰猩红双眼俯视二人。

“那就去找有黄金血脉的人。”

苏光心头一寒，连忙开口：“如今巨阳仙尊坐镇北原，黄金部族都受长生天庇护。前去捉拿，无异于主动暴露。”

左夜灰没有回答。

它抬起头，望向北方。

那里没有太阳，也看不到长生天。只有深沉夜色笼罩茫茫草原。

忽然，太古两天深处传来一声凄厉嘶吼。

声音跨越遥远距离，震动天地。

左夜灰浑身怪发猛地扬起。

两天之中，幽魂魔尊身上的火焰原本胡乱翻腾，此刻却像受到无形牵引，齐齐偏向北方。

幽魂三个头颅同时停下哀嚎。

六只猩红巨眼，缓缓转向北原。
