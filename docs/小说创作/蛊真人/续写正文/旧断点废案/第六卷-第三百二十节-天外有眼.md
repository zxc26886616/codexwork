# 第三百二十节：天外有眼

华文洞天门户缓缓开启。

数位信道蛊仙鱼贯而出。

李小白位于队伍中段，既不靠前，也不落后。他一身白袍，腰间悬着数只信道凡蛊，七转诗壁仙蛊则藏在仙窍深处。

洞天之外，星光如水。

华文洞天被天庭转移之后，便高悬中洲上空，成为漫天繁星精算阵的一处阵眼。此刻洞天门户开启，阵中星光立即汇聚过来，在众仙脚下铺成一条狭长星路。

领队的七转蛊仙取出令牌。

令牌吸收星光，表面浮现出一幅简略星图。

星图中标注了火雨、魂兽群和两天天脉的最新变化，也标出了十余处已经探明的危险区域。

“这便是漫天繁星精算阵的好处。”一位老蛊仙感叹道，“过去我等离开洞天，全凭各自侦查。如今中洲群仙情报相通，许多危险都能提前避开。”

其余蛊仙纷纷点头。

李小白也露出敬佩神色，心中却保持警惕。

漫天繁星精算阵的确强大，但最强之处在于汇总和调度，并非无所不见。

大阵主要覆盖中洲。两天中的情报，仍需要华文洞天这些阵眼和外派蛊仙主动上报。

况且星宿仙尊为了安抚新近投靠的两天势力，并未要求他们将仙蛊、杀招、仙窍等隐秘全部交出。

这就是李小白眼下最大的生机。

一旦星宿将来整合完毕，开始收集每一位蛊仙的完整情报，他即使有方源本体帮助，也会变得十分危险。

必须在此之前，为自己添上一层九转天机混淆。

群仙沿着星路前行。

数千里之后，星光逐渐稀薄，四周重新被黑暗占据。

这里已经远离中洲上空。

太古黑天与太古白天融合之后，原本稳定的地形几乎全部改变。黑白颠倒云四处游荡，两天碎片互相碰撞，时常形成大小不一的虚空裂隙。

太阳毁灭，又令局势更加混乱。

群仙不敢分散，合力催动一记信道杀招。

无数细小文字从他们身边飞出，向四面八方扩散。文字碰到云层、火焰、魂兽或者两天碎片，便会自行记录形状、气息和移动方向，随后飞回众仙手中。

李小白负责整理火雨。

他催动诗壁仙蛊，一面半透明墙壁在身前展开。飞回来的文字落入墙中，按照火焰种类、规模、速度和方位自行排列。

七转诗壁仙蛊用在这里，远比六转信道手段高效。

众仙看在眼里，对李小白更加满意。

“小白虽然年轻，做事却十分稳妥。”

“他的才情本就惊人，如今有诗壁仙蛊相助，将来成就不可限量。”

李小白谦逊回应，没有丝毫自满。

他知道，表现太差会被排斥，表现太好又会引来关注。眼下最安全的做法，就是符合众人对“诗仙后辈”的期待。

片刻后，诗壁上的记录忽然变化。

原本向五域分散的火焰，逐渐出现了共同偏向。

越靠近北方，火雨数量越多。

一些本该坠往西漠、中洲的炎道仙材，也在两天中途改变轨迹，向北原上空移动。

“情况不对。”李小白主动禀报。

领队蛊仙立即上前查看。

众仙又扩大侦查范围，很快发现更多异常。

大量魂兽正在逃离北方。

魂兽没有整齐秩序，但它们避开的方向高度一致，仿佛那里存在一个令它们本能恐惧的庞大存在。

火雨向北，魂兽南逃。

两项情报互相印证。

领队蛊仙脸色凝重，立即催动令牌，把结果传回华文洞天。

华文洞天身为阵眼，又将情报送入漫天繁星精算阵。

绣楼中，星宿仙尊很快得到消息。

类似情报不只来自华文洞天。

中洲北部、北原边境和太古两天中的多支队伍，都观察到了相近变化。

经过漫天繁星精算阵汇总，一条清晰轨迹逐渐成形。

幽魂魔尊正在向北原移动。

速度不算快，却始终没有改变方向。

星宿仙尊将推算结果直接送给巨阳、方源。

这一次，巨阳沉默了更久。

幽魂距离北原越近，对长生天的威胁就越大。即便幽魂最终没有找到长生天，只要他在北原肆虐，黄金部族和北原生灵都会损失惨重。

长生天是九转洞天，却不是一座能够随意迁移的仙蛊屋。

巨阳可以借助大本营防守，但无法让整个北原都进入长生天。

“我可以本体出战。”巨阳终于松口，“但战场必须远离长生天，星宿仙友也不得在北原布置大阵。”

星宿回答：“幽魂正向北原而去，若无手段引导，战场如何远离北原？”

巨阳没有被难住。

“方源乃是炼道尊者。他既然声称能够干扰九转火蛊，想必也能用炎道仙材引动火蛊反应，将幽魂引往别处。”

一转眼，压力便落到方源身上。

方源早有预料。

“要影响九转火蛊，至少需要九转炎道仙材。太阳崩毁后，中洲所得的光明华轮火尽入天庭，数量必定不少。此事自然要由星宿仙友出资。”

星宿立即反驳：“东海虽然所得火雨最少，但天地一家大爱盟广收天下炎道仙材。大爱仙友手中岂会没有光明华轮火？”

方源叹息：“我若仙元充沛，自然愿意为天下出力。可惜先前争夺光蛊，我消耗太大。如今还要炼化东海自然道痕，实在力不从心。”

巨阳听到这里，心中冷笑。

星宿也不相信方源会完全出力。

但二尊没有证据。

三方又是一番交涉，终于勉强确定第一步计划。

天庭拿出一批光明华轮火，方源负责改造，使其能够短暂吸引幽魂体内的九转火蛊。巨阳则以运道手段干扰幽魂前路，引导其转向北原西侧的混淆两天。

那里远离天庭、长生天和东海，也没有任何一方炼化自然道痕，勉强算是一处公平战场。

三尊并未约定如何分配九转火蛊。

现在谈这个，谁都不会满意。

只有先让幽魂改变方向，证明计划可行，接下来的合作才有基础。

星宿仙尊立即调动漫天繁星精算阵。

数十支侦查队伍收到新命令，从不同方向赶往北原西侧的两天，绘制天脉和魂兽分布，为之后的尊者行动提供情报。

李小白所在的队伍也在其中。

令牌上的星图再次变化，一条新路线向西北方延伸。

“任务有变。”领队蛊仙沉声道，“我等需要继续深入两天，沿途记录幽魂留下的魂道痕迹。”

有蛊仙面露难色。

新路线比原定范围危险数倍，距离幽魂也更近。

但这是天庭调令，更是星宿仙尊亲自调度，没有人敢拒绝。

李小白注视星图，心中迅速计算。

新路线中途会经过一片白天碎片群。

那里地形复杂，黑白颠倒云密集，漫天繁星精算阵难以直接监察。只要出现一场不大不小的意外，他便有机会暂时脱离众仙视线。

当然，他不会主动制造意外。

那样太容易留下痕迹。

他相信方源本体也能看到这个机会。

东海上空。

方源收起三尊联络手段，缓缓起身。

他仍旧没有炼化东海自然炼道道痕，身上的气息也显得虚弱。

这些都是给另外两尊看的。

天庭很快就会送来光明华轮火。他亲自进入两天，勘察幽魂、改造仙材，完全合乎三尊刚刚达成的计划。

没有人能从这条明路中挑出问题。

至于他真正要做的事情，则在前往战场的途中。

方源迈出一步，离开东海。
