# 第三百一十九节：尊者之价

星宿仙尊的消息，同时抵达东海和长生天。

方源浏览一遍，便将其放在一旁。

星宿提出三尊联手，趁九转火蛊削弱幽魂，将这个失去神智的尊者彻底铲除。

理由十分充分。

幽魂魔尊已经毁灭太阳，又接连破坏两天洞天。只要他仍旧存在，五域生灵便始终受到威胁。三尊若继续坐视，将来不论哪一方遭殃，其余两方也未必能够独善其身。

星宿甚至主动表示，天庭可以先行布阵，承担侦查和困敌之责。

言辞诚恳，处处以天下大局为重。

方源当然一个字都不信。

天庭最想除掉幽魂，是因为天庭位于太古白天。幽魂能感知天脉节点，一旦星宿的遮掩出现破绽，天庭就会首当其冲。

所谓主动承担，不过是星宿最擅长智道、阵道，正好借此掌握战场情报和行动节奏。

她愿意先付出，是因为天庭从幽魂身上承担的风险最大。

“合作可以。”

方源很快回应。

“不过幽魂到底是尊者之躯，纵然神志不清，也绝非寻常手段可以对付。况且九转火蛊在他体内反抗，局势随时可能变化。”

“我可以负责干扰火蛊，设法分离炎道和魂道道痕。但炼道手段耗费庞大，所需仙材应由天庭提供。”

方源列出一份清单。

天道、炎道、魂道仙材密密麻麻，数量惊人。其中还夹杂几份元境，分别涉及炼道、天道和魂道。

星宿仙尊看到清单，神色没有变化。

她早就预料到方源会趁机索取利益。

但这份清单仍旧远超她的估算。

“大爱仙友。”星宿回应道，“只是联手除魔，并非请你为幽魂升炼仙蛊。如此多的仙材，未免有失公允。”

方源微笑：“星宿仙友误会了。我仙元短缺，若无充足仙材，又如何能在尊者交锋中维持炼道手段？天庭家大业大，此事又是为天下除害，总不至于还要让我独自承担吧？”

星宿暂时没有答复。

她转而联络巨阳仙尊。

长生天中，巨阳仙尊盘坐在血池上空。

一道道血气化为细丝，缠绕他的伤口。星道、智道和炼道道痕被运道道痕包裹，缓慢排斥出去。

他的伤势远比表面严重。

尤其是方源的炼道道痕，最为难缠。

方源的残炼杀招不仅伤了光蛊，也有一部分威能落到巨阳身上。这些炼道道痕时聚时散，似乎随时都要炼化周围其他道痕。

巨阳每清除一分，都要耗去不少黄杏仙元。

更令他忧虑的是幽魂。

幽魂忽然望向北原，身上的火焰也偏转过来。

这种变化绝非无因。

“莫非是九转火蛊感应到了光蛊？”

巨阳首先想到这个可能。

火焰能够产生光明，光明亦常常伴随热力。两者并非同一道，却存在天然联系。

但这只是一种猜测。

也可能是幽魂感应到了长生天这个庞大天脉节点，或者两天融合导致新的变化。

巨阳没有向另外两尊透露光蛊的异状。

他只是回应星宿：“幽魂确实应当除去。不过我伤势沉重，正在炼化方源遗留的炼道道痕。若强行出战，只怕力有未逮。”

“我可以留在长生天，催动运道手段影响幽魂，为二位仙友增添胜算。”

星宿立即拒绝。

巨阳身处长生天，只需耗费仙元远程施展手段。她和方源却要亲身面对幽魂，承担绝大多数风险。

即便巨阳真的尽力，运道手段的效果也难以准确衡量。

到时巨阳暗中做些手脚，让星宿、方源和幽魂三败俱伤，他便能坐收渔利。

这样的合作毫无诚意。

星宿再度传讯：“幽魂正望向北原。巨阳仙友才得到九转光蛊，便有如此异变，难道不应当给我和大爱仙友一个解释吗？”

巨阳心头一沉。

星宿的反应比他预料中更快。

漫天繁星精算阵虽然只覆盖中洲，却让星宿从许多琐碎情报中解放出来，能将更多念头用于观察天下大局。

“幽魂神志不清，行止无常。星宿仙友仅凭他看向北原，就要将此事归到光蛊身上，未免太过武断。”

巨阳并不松口。

三尊隔空交涉，谁都没有急着行动。

幽魂仍在两天深处燃烧。

时间拖得越久，他的魂道道痕就被九转火蛊消磨得越多。表面看来，三尊都能获利。

然而幽魂转向北原的异常，又让他们无法真正安心等待。

最先改变条件的还是星宿。

她同意提供方源清单中的三成仙材，元境则只给极少一部分。剩余报酬要按照困住幽魂、分离火蛊、削弱魂道道痕等实际成果逐步交付。

同时，她要求巨阳本体离开长生天，至少进入太古两天参战。

作为交换，天庭会率先布置战场，且不主张九转火蛊的最终归属。

这最后一个条件，立即让方源和巨阳警惕起来。

天庭不争火蛊，并不意味着星宿毫无所求。

幽魂本体、魂道成果、生死门线索，任何一项都价值巨大。星宿如此轻易放弃九转火蛊，只能说明她另有更加看重的目标。

方源催动智道手段，不断推算。

巨阳也察看自身气运。

隔了片刻，两人不约而同，要求星宿先公开战场杀招的详情，并说明天庭打算如何处置幽魂遗留的魂道道痕。

谈判再次陷入僵局。

中洲上空。

华文洞天高悬在中洲上方的两天之中，本身便是漫天繁星精算阵的一处阵眼。

洞天之中，华语老仙召集数位信道蛊仙。

李小白也在其中。

“幽魂魔尊出现异动，火雨和魂兽群的分布随之改变。”华语老仙神情肃然，“天庭传来调令，需要我等派遣蛊仙前往两天，记录天脉、火雨以及魂兽迁徙。”

“这些情报会送入漫天繁星精算阵，为星宿仙尊大人推算幽魂动向提供助力。”

群仙纷纷应命。

华文洞天本就是信道洞天，众仙虽然战力不算出众，但在收集、整理情报方面颇有优势。

华语老仙环视一圈，开始点将。

李小白赫然在列。

“小白，你曾参与清剿天残犬，对两天环境已有经验。这一次由你负责记录火雨变化，并将沿途所见编纂成册。”

李小白连忙行礼：“晚辈领命。”

他表面恭敬，心中却骤然一紧。

不久之前，方源本体才秘密联系过他，叮嘱他设法离开华文洞天，但绝不能刻意求取外派任务。

若是主动争取，极可能留下痕迹。

所以李小白一直安分守己，没有做出任何异常举动。

没想到太阳毁灭、幽魂异动，竟令机会自行落到了他的头上。

李小白没有丝毫喜色，反而主动开口：“晚辈修为浅薄，只有六转。此事关系幽魂魔尊，是否让其他前辈负责更为稳妥？”

华语老仙抚须而笑。

“你不必过虑。此次只是外围侦查，不会靠近幽魂。况且你有七转诗壁仙蛊护身，又是我华文洞天最出色的后辈，也该多经磨砺了。”

其余蛊仙纷纷赞同。

李小白这才露出一丝迟疑，最终应下。

散会之后，他独自回到住处。

确认周围没有异常，李小白取出一只信道凡蛊。

这只凡蛊没有传讯之能，只能记录一段文字，并在数个时辰后自行毁灭。

李小白将任务路线、同行人员和出发时间记入其中，随后把凡蛊收入仙窍。

他不会直接传递消息。

等离开华文洞天，抵达两天中的预定地点，自然会有更加安全的手段接应。

东海。

方源率先结束了这轮谈判。

星宿开出的价码还不够，巨阳也没有被逼出长生天。此刻动手，只会让他替另外两尊承担风险。

但他并非毫无收获。

至尊仙窍中，一只信道蛊虫忽然有所感应。

这并非李小白直接传讯，而是双方早已约定的警示手段：只要李小白得到离开华文洞天的机会，蛊虫便会在一定时间后产生变化。

方源看了一眼，神色平静。

“机会已经有了。”

“接下来，就要看幽魂能否将这场动乱闹得更大一些。”
