# 第三百八十七节：新天庭

三日之期已到。

天庭外围切割正式开始。

神帝城悬于中央，绣楼紧随其后。两座仙蛊屋之间，残存的自然智道道痕被星宿仙尊全部调动，形成一条深蓝星河。

星河所过之处，洞天裂纹暂时稳定。

外围区域则在仙阵作用下缓缓分离。

第一块被切下的土地足有千里。

上面残留数座宫殿和一处木道资源点。天庭已经取走核心仙蛊与传承，却没有足够时间搬走全部资源。

土地脱离洞天主体后，立即受到幽天侵蚀。

白天气息和幽天气息激烈冲突，形成大片灰雾。

天庭群仙站在神帝城墙上，沉默观看。

有人曾在那片土地修行数百年。

有人负责经营那处资源点。

也有人知道宫殿地下还埋着前辈遗物。

如今只能一并放弃。

接下来是第二块、第三块。

每切下一片土地，天庭洞天都会剧烈震动。神帝城中的伤者也能感到脚下摇晃。

切割进行到一半，最危险的裂层出现。

裂层贯穿数万里，一端连接洞天主体，另一端缠绕残余太古白天碎片。若直接斩断，白天气息会瞬间爆发，可能把神帝城也卷入其中。

星宿仙尊没有亲自出手。

一道剑光从西漠方向飞来。

剑光细若发丝，跨越遥远距离，准确落入裂层。

没有惊天爆炸。

裂层内互相纠缠的空间道痕和白天道痕，被剑光一缕缕分开。最危险的连接处迅速变薄，最终无声断裂。

林剑行履行了契约。

他没有进入天庭，也没有为天庭提供更多帮助。

一剑之后，气息便彻底消失。

与此同时，南疆武家的第一批宇道仙材送到神帝城。

星宿仙尊也按照契约，把兵道训练成果和神帝城名额交付出去。

新天庭尚未稳定，和五域势力的交易已经开始运转。

最后一片外围土地脱落后，整个洞天规模只剩原本不到三成。

自然智道道痕也损失大半。

星宿仙尊在这里的主场增幅远不如前。

代价巨大。

好处也十分明显。

洞天裂缝数量锐减，渗入的幽天气息被仙阵逐步排出。天庭不再需要把有限人手分散到广阔区域，神帝城和绣楼能够互相支援。

星宿仙尊将元始意识根基送入绣楼最深处。

透明心脏已经极其黯淡。

元始意念最后苏醒一次。

他没有询问天庭损失，也没有要求星宿继续寻找复活方法。

“新的天庭，很小啊。”

星宿仙尊道：“暂时如此。”

元始意念笑了笑：“当年刚刚建立天庭时，也只有一点地方。”

“那时候，异人比人族强得多。我们能保住的，不过是几座山、几处福地，还有一群愿意相信未来的人。”

“后来才慢慢有了今日。”

星宿仙尊安静听着。

元始意念的声音越来越微弱。

“不要为了让我醒着，耗尽天庭最后的资源。”

“我先睡一会儿。”

透明心脏停止跳动。

它没有消散，只是进入极深沉眠。

星宿仙尊亲手封闭仙阵。

随后，她召集中洲十大古派的幸存者。

神帝城大殿中，人数比过去少了太多。

许多位置空着。

星宿仙尊没有掩饰损失，也没有用鼓舞人心的言辞粉饰。

“天庭已经无法继续保护整个中洲。”

第一句话，就让群仙心头沉重。

“十大古派从今日起，各自负责所属区域。资源调度、弟子招收、和其他势力的交涉，不必事事上报天庭。”

“天庭仍会提供神帝城、人道成果和必要支援。但无法保证每一处资源点、每一个门派都不受侵犯。”

一位古派蛊仙问道：“仙尊大人，若各派之间因为资源发生冲突呢？”

“先自行协商。无法解决，再由神帝城仲裁。”

“若有门派不接受仲裁？”

“那就由你们自己决定，是开战、退让，还是另找盟友。”

群仙神色复杂。

这意味着十大古派获得了前所未有的自主权。

也意味着他们失去了天庭始终在背后兜底的安全。

十大古派之间的差距很快显现。

仙鹤门损失较轻的资源点仍在，却缺少能够坐镇的高阶蛊仙。灵缘斋保住赵怜云和爱情蛊，门中其他强者却死伤惨重。战仙宗拥有石磊等战力，伤势又一时难以恢复。

过去这些差距可以由天庭统一调度抹平。

现在，每一派都要决定有限仙材先救谁、哪些资源点值得守、是否接受外域势力援助。

有人担心十大古派因此分裂。

也有人意识到，继续维持表面一致，只会让所有门派一起衰弱。

星宿没有给出统一答案。

她只保留三条底线：不得主动屠戮中洲凡人获取资源，不得把中洲核心地脉卖给外域尊者，不得破坏神帝城的人道征集。

底线之外，各派自行选择。

星宿仙尊最后道：“天庭仍在。”

“但从今日起，它不再有能力替整个中洲做所有选择。”

神帝城缓缓移动。

它离开最危险的洞天残层，带着幸存者、绣楼和不足三成的天庭土地，进入一处相对稳定的幽天区域。

旧天庭在身后继续崩解。

新天庭则第一次没有固定在原本的位置。

移动同样需要成本。

神帝城每跨越一段幽天，都会消耗大量仙元。绣楼和残存洞天土地更要依靠星河牵引，速度远不如单独仙蛊屋。

它不可能永远漂泊。

星宿计划先避开幽魂活动最频繁的区域，再寻找一块仍保留白天气息、又不易被方源炼道自然痕迹影响的落脚点。

在找到之前，新天庭既是移动核心，也是一支携带大量伤者的缓慢队伍。

它比过去更灵活，也比过去更脆弱。
