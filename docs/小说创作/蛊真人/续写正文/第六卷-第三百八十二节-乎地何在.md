# 第三百八十二节：乎地何在

方源没有立即进入天庭外围。

星宿主动放弃的区域太过干净。

没有回收队伍，没有侦查蛊虫，也没有用于稳定洞天的仙阵。

仿佛天庭真的已经无力顾及。

但星宿仙尊最擅长的就是让敌人根据真实情报，得出她想要的结论。

天庭确实人手不足。

外围也确实必须放弃。

这不代表她不会在放弃前留下手段。

方源心念一动。

至尊仙窍中，气海魂魄周围的一只七转气道仙蛊飞起。

这只仙蛊原本属于气海老祖。

元始爆炸时，它从镇压仙阵中飞出，又被方源收取天庭碎片时顺手所得。蛊中仍有气海意志，只是极其微弱。

方源没有将其完全炼化。

他取出一团气海魂魄气息，裹住仙蛊，再通过宝黄天送入一位大爱盟成员手中。

这位蛊仙只有六转修为，正身处中洲北部。

他收到的命令很简单。

把仙蛊送入幽天，沿指定方向放飞，然后立即返回。

大爱盟成员不知道仙蛊来历，也不知道目标是乎地。

他只看到任务报酬极高，足以换取一次七转仙蛊代炼机会。

半日后，七转气道仙蛊进入幽天。

气海魂魄立即产生感应。

仙蛊像是归巢飞鸟，自行向天庭废弃外围靠近。

方源则隔着遥远距离观察。

星宿仙尊同样察觉到了。

她没有立刻阻拦。

她已经认出这只仙蛊。

它曾属于气海老祖，被镇压在元始复活仙阵中。爆炸后失踪，如今重新出现，至少说明方源已经收取一部分气道战利品。

仙蛊本身也可能被方源做过手脚。

若直接收入天庭，炼道手段或许会借它渗入新阵。若当场摧毁，又会白白损失一只七转仙蛊。

星宿决定让它继续前进。

她要看的不是仙蛊，而是方源通过何种方式感应乎地。

气道仙蛊一路深入，穿过数片漂浮残土，距离感应中的乎地越来越近。

就在它即将进入一片白色气流时，周围忽然浮现出点点星光。

星光组成一座小型仙阵。

阵势并不攻伐仙蛊，而是切断它和外界的所有联系。

方源通过气海魂魄感受到的方向，顿时变得混乱。

白色气流中同时出现三处乎地气息。

一处向上，一处向下，还有一处则快速飞向天庭主体。

“果然有埋伏。”

方源并不意外。

星宿若完全不布置，他反而不会轻易相信。

七转气道仙蛊在仙阵中四处冲撞。

星宿没有毁去它。

一只仙蛊价值不低。更重要的是，她想借仙蛊反向追踪气海魂魄和方源所在。

星阵开始炼化蛊中残余气海意志。

只要沿着意志联系向外推算，就可能找到方源遥控手段的落点。

方源早有准备。

气海道仙蛊中的意志忽然自毁。

自毁的只有意志，不是仙蛊。

方源特意保留蛊虫本体，让星宿面对和他刚才相同的选择：要么花费时间反复检查、炼化一件可能藏有后手的战利品，要么将它继续留作无主鱼饵。

无论哪种选择，星宿都要支付成本。

仙蛊失去操控，在星阵中安静下来。

与此同时，包裹仙蛊的那团气海气息炸开，化作数千道细流。

每一道细流都携带相同感应，沿星阵内部不同节点流动。

星宿制造三处假方向，必须让仙阵对真正感应进行扭曲。

扭曲本身，就会留下痕迹。

方源不再寻找仙蛊传回的方向，而是观察哪一部分星阵承担了最多扭曲。

“左下第七阵眼。”

他很快锁定关键。

方源立即让所有气流同时冲向左下。

星阵反应迅速，数十道星光落下，将气流全部击散。

但在那一瞬间，气海魂魄和乎地之间的真实感应恢复了一息。

一息已经足够。

方源脑海中显现出一幅模糊景象。

天庭洞天主体和一块巨大残片之间，有一道不断开合的漆黑裂缝。

乎地就卡在裂缝深处。

它一半仍和天庭气道布置相连，另一半已经暴露在幽天之中。冷蓝气息沿着边缘不断渗入，正缓慢同化天地秘境外围道痕。

星宿留下仙阵，不只是为伏击方源。

她也在用星阵延缓乎地被幽天吞噬。

星宿仙尊的声音通过宝黄天传来。

“大爱仙友，为试探一处陷阱，便舍弃一只七转仙蛊，果然财大气粗。”

方源微笑回应：“星宿仙友误会了。此蛊本就是天庭战利品，如今物归原主，何来舍弃？”

“既然物归原主，乎地也曾在我天庭镇压，自当一并留下。”

“乎地原属气海老祖。气海乃我分身，星宿仙友已经知晓。你再强占他人之物，实在有损天庭名声。”

两人言辞平和，谁都没有真正谈判的意思。

方源已经得到位置。

星宿也通过这次试探确认，方源的确夺回了气海魂魄，并能利用魂魄感应乎地。

双方各有所得。

星宿仙尊重新检查整座星阵。

方源能够通过气海魂魄和一只七转仙蛊，在极远距离测出阵眼负担。这种利用既有联系反推阵势的方法并不新奇，难的是他对炼道、气道和智道反制同时有所准备。

她若继续沿用原阵，方源下一次就不会只试探。

星宿当即改变三处阵眼，又把真正负责延缓幽天侵蚀的节点移到元始意念附近。

这样做会增加仙元消耗，却能避免方源直接复制这次结果。

方源同样知道位置还会变化。

他得到的不是一张永久地图，而是一次接近乎地的机会。

至于那只七转气道仙蛊，星宿没有立即炼化，而是继续留在仙阵中。

它是战利品，也是下一枚鱼饵。

天庭裂层深处。

乎地在黑白气流中缓慢震动。

属于幽天的冷意，正一点点侵入其中。
