# 第一卷：没有外挂的穿越者

## 卷目标

预计 45 章左右，每章约 6000 字，总字数约 27 万字。

核心推进：

- 主角被天灾召唤拉入西幻世界。
- 主角以为自己是天命主角，等待系统、面板、新手礼包，结果什么都没有。
- 主角在矿镇灰石镇靠装傻充愣活下来。
- 主角结识艾伦、米娜、巴洛，第一次建立本土关系网。
- 外来觉醒者经营型 Boss 把灰石镇当资源点经营，引发土著秩序崩坏。
- 主角发现外来觉醒者多数把土著当 NPC。
- 卷末外来 Boss 被另一名天灾者追杀，混乱中主角被天灾者误杀。
- 主角第一次触发寄命，在凶手身体里醒来，获得双外挂体系，但原身份死亡，旧友认为他被凶手杀死。

## 第一卷主要人物

- 主角：暂名林恩，来自现代世界，穿越后没有系统和面板，靠装傻活命。
- 艾伦：灰石镇巡夜人，最早救下主角，正直但不天真。
- 米娜：药剂学徒，敏锐、谨慎，对主角“失忆外来者”身份半信半疑。
- 巴洛：灰石镇治安官，务实、严厉，讨厌外来觉醒者。
- 罗曼：经营型外来觉醒者 Boss，外挂“领地面板”的低配形态，把灰石镇当资源点。
- 血猎者：卷末登场的天灾者，外挂“血迹追踪”，误杀主角，成为主角第一次寄命对象。

## 第一卷避撞重点

本卷不写成单纯“死而替身”。

重点差异：

- 主角前期没有外挂，长期经历“主角模板失败”。
- 寄命必须依赖天灾者载体。
- 主角不是替代某个人享受身份，而是被迫继承凶手的债务、仇恨和关系后果。
- 双外挂体系是寄命唯一实际好处。
- 主角第一次寄命不是爽点，而是情感灾难。

## 战斗化修订补丁

### 新版核心外挂与神器

- 罗曼：`领主战争台`，可瞬建箭塔、拒马、石墙、矿工傀儡和爆破地道；四根界桩闭合后，无主物资会被强制拆解。神器`黑铁领主印`可引爆任一建筑。
- 凯德：`血迹追踪`升级为血线自动修正、血钉封路与短距血刃。神器`寻血牙`会沿血标自动追心。
- 魔狼首领：`影跃`，可在相连阴影间瞬移；连续三次扑击同一目标后，第四击从目标影子内部发动。
- 罗曼护卫：`伤害均摊`，四人结阵后平分伤害；阵眼护腕被同时破坏则累积伤害一次返还。
- 矿井寄生者：`借尸钻行`，可在尸体和岩层之间高速穿梭，以骨刺从地底突袭。

### 战斗章节加码

- 第12—16章冬猎不只调查资源点，增加魔狼影跃围猎与雪坡矿车追逐。
- 第25—27章灰石镇升级改为箭塔、石墙和矿工傀儡现场成型，镇民第一次遭遇建筑战争。
- 第29—33章地下仓库加入寄生者借尸突袭、爆破地道和领主印争夺。
- 第35—37章魔狼夜袭扩为镇门、屋顶、矿道三线防守，艾伦和米娜各有独立战术作用。
- 第38—42章凯德追猎加入血钉封路、血刃修正与寻血牙必中判定，林恩必须污染血标。
- 第43—45章卷末形成罗曼失控建筑、凯德猎杀和镇民撤离三方大战，林恩之死来自明确的神器必杀。

### 战斗配额

- 完整动作章不少于20章，中大型战斗不少于9场。
- Boss阶段战：罗曼矿井战、罗曼镇战、凯德血猎终战。
- 无外挂贡献：米娜污染血标，巴洛设计建筑承重陷阱，艾伦破坏界桩阵眼。
