# CAD 自动挂机控制台设计文档

## 一句话概念

为 `D:\code\cad_client\cadclient3.0` Unity 项目提供一个独立的本地 Web 控制台，通过授权的正式服后台/API 适配器执行自动登录，并逐步扩展到合规挂机任务。

## 核心体验

- 开发者启动本地服务器后，用浏览器查看当前挂机参数。
- Web 界面可以保存自动登录参数，并发起一次自动登录命令。
- 本地服务器直接调用正式服适配器执行自动登录流程。
- 第一阶段只做自动登录闭环，后续再扩展挂机任务。

## 操作方式

- 在 `projects/cad-auto-bot/` 执行 `node server.js`。
- 打开 `http://127.0.0.1:17830`。
- 调整账号、服务器、角色选择、重试等自动登录参数。
- 点击“执行自动登录”。
- Mock 模式只演练参数和命令；正式服模式需要实现 `adapters/officialAdapter.js`。

## 规则

- 自动挂机工具作为独立项目放在 `D:\code\codexwork\projects\cad-auto-bot`。
- 不直接改动 `D:\code\cad_client\cadclient3.0`，正式服执行通过授权服务端接口适配器接入。
- 本地服务器只监听 `127.0.0.1`，默认端口 `17830`。
- 参数保存到本地 `data/config.json`。
- 不实现客户端外挂、反作弊绕过、验证码绕过、支付绕过或隐蔽输入模拟。
- 正式服执行必须使用白名单账号、bot token、限流和审计日志。

## 自动登录能力

| 项目 | 当前设计 |
| --- | --- |
| 登录模式 | 最近角色、指定角色 ID、指定角色序号、仅账号登录 |
| 参数面板 | Web 表单显示并保存当前自动登录参数 |
| 命令触发 | `POST /api/login/request` 创建自动登录命令 |
| 执行适配器 | Mock 适配器演练，official 适配器按配置调用正式服授权 HTTP API |
| 状态记录 | 本地服务器记录最近命令、最近执行结果和事件日志 |

## 主要数值

| 数值 | 默认值 |
| --- | --- |
| 本地端口 | 17830 |
| 登录延迟 | 2 秒 |
| 重试次数 | 3 |
| 重试间隔 | 5 秒 |
| 执行限流 | 10 秒 |

## 后续想法

- 实现 `adapters/officialAdapter.js`，接入你们正式服允许的登录、选服、选角和进入游戏接口。
- 增加账号组、区服列表、角色列表缓存。
- 增加挂机任务队列，例如每日任务、战斗关卡、资源领取。
- 增加正式服执行队列，支持任务排队、暂停、恢复和失败重试。
- 增加操作日志导出和异常截图记录。
