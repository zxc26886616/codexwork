# 海盐折纸桌面助手

## 一句话概念

在独立 Windows 窗口里让规则策略操作 BGA《海盐折纸》的基础版测试桌，并积累逐桌战绩。

## 核心体验与操作

在牌桌页打开互动教程或指定测试桌，点击「启动自动出牌」。右侧「操作日志」按本机时间显示摸牌、选牌、配对、等待和结算过程。可随时暂停，切到「对局统计」按玩家查看成绩，或通过桌号补录已结束的比赛。

## 规则与胜负

「连续对局」可设置 1–1000 局。后台在玩家站为房主和指定的同屏客席逐桌开双人友谊赛，读取官方名次及分数并保存后再开下一桌。每批分别计算两席的独胜率和平均分，并列第一单列。中断时保留桌号，恢复后优先接回原桌。

可选择 BGA 官方回合制进行同屏验证。中途切换会保留先前的即时制成绩，并记下切换前已经结算的局数。后台在出牌前核实当前游戏框的官方速度，回合制验证使用单独的运行锁。

每次读取当前回合及可用操作，只在当前受控座位行动时执行一步。普通牌桌重连后核对桌号和座位，切换座位需要重新启动。友谊赛中若能确认全部席位都是本机热座，助手会按 BGA 提示交接，并读取新行动方的手牌。提交后长时间未收到回执时重载原桌；若座位和行动阶段仍与提交前相同，暂停以避免重复操作。

择牌时优先考虑能否与手牌配对、是否增加收藏价值，以及颜色。正常喊停优先选择“再给一次机会”（最后机会），让对手再行动一次。若该选项不可用而“立即结束”可用，才选择立即结算。普通游戏依据 BGA 的最终名次统计独胜、并列第一和其他名次。教学回放不计入战绩。

## 主要数值

| 项目 | 口径 |
| --- | --- |
| 基础版人数 | 2–4 人 |
| 宣布结束本轮的基础门槛 | 7 分，以牌桌允许的操作为准 |
| 常规终局分数门槛 | 2、3、4 人分别为 40、35、30 分 |
| 独胜率 | 独占第一局数 ÷ 该玩家已收录局数 |
| 战绩唯一键 | BGA 环境与桌号 |

## 技术与后续验证

C# WinForms 承载 WebView2。桌面助手和后台进程使用相同的出牌循环、右侧日志和战绩库。后台用 UTF-8 JSON 行接收命令，可查询大厅、选择已显示的控件、启停出牌及读取日志。教程使用旧版牌桌和指定动作，与普通桌的自由决策分别处理。后续可在获准测试桌上对比不同喊停时机的胜率，再决定是否加入扩展牌策略。[项目运行说明](../../projects/bga-seasaltpaper/README.md) · [BGA 规则页](https://boardgamearena.com/gamepanel?game=seasaltpaper)
