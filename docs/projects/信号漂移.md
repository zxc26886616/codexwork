# 信号漂移设计文档

## 一句话概念

玩家驾驶小飞船在高速漂移的信号通道中收集绿色碎片，并躲避红色闸门。

## 核心体验

- 快速移动和微调走位。
- 收集碎片带来的连击增长。
- 红色障碍带来的压迫感。
- 发光、粒子和屏幕震动增强反馈。

## 当前玩法

| 项目 | 设计 |
| --- | --- |
| 玩家目标 | 尽可能获得高分。 |
| 操作方式 | 键盘方向键、WASD、移动端触控摇杆。 |
| 奖励 | 收集信号碎片获得分数并提升连击。 |
| 危险 | 撞到红色闸门会损失护盾并重置连击。 |
| 失败条件 | 护盾降到 0。 |

## 主要数值

| 数值 | 当前值 |
| --- | --- |
| 初始护盾 | 3 |
| 初始连击 | x1 |
| 单个碎片基础分 | 10 |
| 最高连击 | x9 |
| 飞船半径 | 17 |
| 受击无敌时间 | 1.1 秒 |

## 反馈设计

- 飞船、碎片、闸门使用同色光晕。
- 收集碎片时产生绿色粒子。
- 撞击闸门时产生红色粒子和短暂屏幕震动。
- 暂停和游戏结束使用覆盖层提示。

## 后续想法

- 加入音效和背景音乐。
- 增加不同形状的障碍。
- 增加磁吸道具、护盾道具、减速道具。
- 加入最高分记录。
- 增加难度曲线可视化调试面板。
- 后续可把公共输入、碰撞、粒子等逻辑抽成可复用模块。
