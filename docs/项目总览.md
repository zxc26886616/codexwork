# 项目总览

## 定位

这个仓库主要用于开发独立小游戏、玩法原型、可直接运行的浏览器游戏，以及围绕游戏项目的本地开发工具。

当前技术路线以 HTML、CSS、JavaScript、Canvas 和轻量 Node 本地服务为主，优先保证项目能快速运行、调试和迭代。

## 长期方向

- 建立一套可复用的小游戏项目结构。
- 积累常用玩法模块，例如移动、碰撞、生成器、计分、暂停、触控控制。
- 为复杂 Unity 项目补充独立本地工具，例如挂机控制台、调试面板、配置检查器。
- 形成统一的中文文档模板，方便每个新项目快速开工。
- 后续新增项目放在 `projects/` 下，例如 `projects/signal-drift/`、`projects/cad-auto-bot/`。

## 新项目立项检查

- 一句话描述是否清晰。
- 用户输入或操作目标是否简单明确。
- 30 秒内是否能体验到主要价值。
- 是否有明确的运行入口和验证方式。
- 是否能用现有技术在少量文件内做出第一版。
