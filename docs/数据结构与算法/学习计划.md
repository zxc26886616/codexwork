# 数据结构与算法学习计划

这份文档用于记录数据结构与算法的学习路线、练习安排和复盘方式。目标不是背题，而是逐步建立“看懂问题、选择结构、分析复杂度、写出稳定代码”的能力。

## 学习目标

- 能用清楚的话解释常见数据结构的用途和限制。
- 能判断一段代码的大致时间复杂度和空间复杂度。
- 能独立完成基础算法题，并写出可读、可调试的代码。
- 能把算法思路迁移到小游戏开发中，例如寻路、碰撞检测、状态管理和排行榜统计。

## 推荐路线

### 第一阶段：基础与复杂度

重点理解程序运行成本。

- 数组、字符串、函数、循环、条件判断。
- 时间复杂度：`O(1)`、`O(n)`、`O(log n)`、`O(n log n)`、`O(n^2)`。
- 空间复杂度：额外数组、哈希表、递归栈。

练习题：

- 找数组最大值和最小值。
- 反转数组。
- 删除有序数组中的重复项。
- 合并两个有序数组。
- 两数之和。

### 第二阶段：线性结构

重点理解数据的进入、移除和访问顺序。

- 栈：后进先出。
- 队列：先进先出。
- 链表：节点和指针。
- 哈希表：用空间换查找速度。

练习题：

- 有效括号。
- 用栈实现队列。
- 用队列实现栈。
- 判断链表是否有环。
- 第一个只出现一次的字符。

### 第三阶段：常用算法技巧

重点训练“看到题目能想到套路”。

- 双指针。
- 滑动窗口。
- 二分查找。
- 前缀和。
- 排序。
- 递归。

练习题：

- 判断回文串。
- 最长无重复字符子串。
- 搜索插入位置。
- 和为 K 的子数组。
- 快速排序或归并排序。

### 第四阶段：树与图

重点理解层级关系和连接关系。

- 二叉树。
- 二叉搜索树。
- 堆。
- 图的邻接表。
- 深度优先搜索。
- 广度优先搜索。

练习题：

- 二叉树最大深度。
- 二叉树层序遍历。
- 翻转二叉树。
- 岛屿数量。
- 迷宫最短路径。

### 第五阶段：进阶算法

重点训练拆问题和做决策。

- 回溯。
- 贪心。
- 动态规划。
- 并查集。
- 拓扑排序。
- 最短路径。

练习题：

- 全排列。
- 子集。
- 买卖股票的最佳时机。
- 零钱兑换。
- 课程表。
- Dijkstra 最短路。

## 每周节奏

建议每周安排 3 到 5 次练习，每次 45 到 90 分钟。

1. 学一个知识点，用自己的话写下定义。
2. 看一题简单例题，手写输入输出过程。
3. 独立写一题，不急着看答案。
4. 跑测试用例，记录错误原因。
5. 复盘复杂度和是否有更简单的写法。

## 和游戏开发的连接

- 数组：保存敌人、子弹、道具、地图格子。
- 栈：实现撤销、状态回退、递归搜索。
- 队列：实现事件队列、BFS 寻路。
- 哈希表：保存资源索引、碰撞分组、排行榜。
- 树：管理场景节点、行为树、技能分支。
- 图：地图寻路、关卡连接、任务依赖。
- 动态规划：路径代价、资源分配、关卡评分。
