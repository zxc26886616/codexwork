# 素材规范

## 视觉风格

当前项目偏向轻量霓虹科幻风：

- 背景使用深色空间感。
- 主要可交互物体使用高亮色。
- 发光效果通过 Canvas `shadowBlur` 或 CSS `box-shadow` / `text-shadow` 实现。
- 危险物体优先使用红色或橙红色。
- 奖励物体优先使用绿色、黄色或青色。

## 素材目录建议

后续如果加入图片、音效或字体，可以按下面结构扩展：

```text
assets/
  images/
  audio/
  fonts/
  sprites/
```

## 图片素材

- 优先使用透明背景 PNG 或 WebP。
- 小图标和粒子可以用 Canvas 代码绘制，避免过早增加资源管理复杂度。
- 同一游戏内保持统一线条粗细、色彩饱和度和发光强度。

## 音效素材

- 收集、受击、开始、失败至少各准备一个短音效。
- 音量默认偏低，避免打开页面时吓到玩家。
- 循环背景音乐需要提供静音按钮。

## 命名建议

```text
player-ship.png
signal-shard.png
gate-hit.wav
collect-01.wav
theme-loop.mp3
```
